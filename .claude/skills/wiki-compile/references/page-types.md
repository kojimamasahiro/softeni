# page type と frontmatter の仕様

[ADR-024](../../../../docs/adr/ADR-024-llm-wiki-operating-model.md) の決定。機械は `scripts/lib/wiki-meta.mjs` と
`npm run check:wiki -- --strict` が検査する（値の定義はそちらが正）。

## 型は6つ

型は「エージェントがそのページに何を問うか」で決める。

| 型 | 問い | 必須の節 |
|---|---|---|
| `entity` | X とは何か・どう識別するか・どこにあるか | 定義 / 識別子 / 置き場 / 形（要点）/ 関連 |
| `concept` | どう判定するか・なぜその規則か | 規則（結論を先頭）/ 適用先 / 例外・棄却済み |
| `feature` | 何を出すか・どこにあるか | 概要 / 入口（ルート）/ 読むデータ / 適用する概念 / 未対応 |
| `procedure` | どうやるか・どう確かめるか | 契機 / 手順 / 完了条件（検算）/ 落とし穴 |
| `overview` | 全体の構成と境界 | 構成 / 境界 / 守ること |
| `index` | どこにあるか | 一覧と1行説明のみ |

ADR は wiki 層の「決定記録」という page type。置き場は `docs/adr` のままで、frontmatter は付けない（ディレクトリが型を決め、Status は節で機械検査される）。

### 判定の順（上から当てはめる）

1. 順に実行する手順 → `procedure`
2. 利用者が見る画面・出力の説明 → `feature`
3. 複数のページ・機能にまたがる規則やアルゴリズム → `concept`
4. 特定の対象の定義・ID・置き場 → `entity`
5. 全体の構成・基盤 → `overview`
6. 一覧・集約 → `index`

混在しているページは**主な役割で1つに決める**。書き換えのついでに分けず、圧縮・追記が大きくなったときに分ける。

### 運用の原則

- **1ページ1型**。
- **事実の所有者は1つ**。ID の形式と置き場は entity ページだけが書く（Player / Team の薄い entity ページは P5 で作る予定）。
- 型と `status` は別軸。検討中の提案も、型は `feature` で `status: draft`。

## frontmatter

ファイルの先頭に `---` で挟んで書く。形は `key: value` と、`code:` の下の `  - "path"` の並びだけ（YAML の全機能は使わない）。
値は `"…"`（JSON 形式）か、Prettier が書き換える `'…'`、素の文字列。

```yaml
---
type: feature
scope: 混在
status: current
summary: "そのページを開く理由が分かる1行"
code:
  - "lib/example.ts"
  - "src/pages/example/"
---
```

| キー | 必須 | 値 |
|---|---|---|
| `type` | ○ | `entity` / `concept` / `feature` / `procedure` / `overview` / `index` |
| `scope` | ○ | `汎用`（どの競技でも）/ `学校`（日本の学校スポーツ共通）/ `固有`（ソフトテニス固有）/ `混在`（節によって違う） |
| `status` | ○ | `current` / `draft`（検討中・未実装の仕様）/ `deprecated` |
| `summary` | ○ | 1行・160字以内。`index.md` の説明と、意図で選ぶときの手がかりになる |
| `code` | 任意 | `code:` を付けるなら1件以上。リポジトリ基準の相対パス。実在しないパスはゲートで落ちる |

- `scope` の正は frontmatter。本文の「適用範囲」の行は任意で、あるなら `scope` と一致させる（食い違うとゲートで落ちる）。
- 未知のキーはゲートで落ちる。

### `code:` の書き方

- **そのページが定義・決定している対象**だけ。ディレクトリ〜モジュール粒度で、ディレクトリは末尾 `/`。
- 言及しているだけのパス、対比のために名前が出ただけのパスは入れない。本文を機械的に拾うと、こういうパスを拾ってしまう
  （実例: 「〜とは別物」と断っている相手を `code:` に入れていた）。
- 引き方: `npm run wiki:for -- <パス>`。`一致`・`配下`・`含む` が `code:` による一致、`本文で言及` は本文がそのパスを書いているページ。
- 索引型（`index`）と検討中のページは `code:` を持たなくてよい。
