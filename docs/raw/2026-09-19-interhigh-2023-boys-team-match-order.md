## 様式の違いは3つだけ（数値の列は 2024 と完全に一致）

列の x 座標（左ポイント274.2 / 「－」297.6 / 右ポイント321.0 / 左本数227.4 / 右本数367.9 /
氏名 113-166・431-484）は 2024・2026 と同一。違うのは次の3点。

1. **氏名が1文字ずつの語**（`赤 羽  蒼 空`）。`pair_names` を「行ごとに欄の中の語を x 順に連結」に
   一般化した。**姓と名は欄の境界（x=141・456）で分ける**。どちらの欄も均等割り付けなので
   **文字の間隔では分けられない**——`國 松 樹 人` は姓の中の間隔 18.3pt ＞ 姓と名の間隔 16.5pt。
   2024 男女で再実行して**出力が1バイトも変わらないこと**を確認した（1語形式も同じ経路で通る）。
2. **打ち切りの対戦の本数を印字しない**。2024 は `2-2` のように印字されるが、2023 は
   「打ち切り」とゲームだけで本数が空。ADR-020 の `unfinished` は「途中の本数」を持つので、
   **印字が無いときだけゲームから数えて埋める**（印字がある年度は印字を正とし、数え直しは検算に使う）。
   該当2件は表示して人が見られるようにした。
3. **1回戦・2回戦は3対戦すべて実施**（`③-0` がある）。打ち切りは3回戦以降。

### p26 上宮(37)-松江工(38) の本数

PDF の詳細ページは **③ － 0** で、3対戦すべて上宮が ④ で取っている（内部で整合）。
トーナメント表（p11）の 2回戦の列（セル x≈358）も上宮の行に **③**。**2つの読みが一致**する。
47試合のうち46試合は details と一致していたので、これは取り込み時の転記誤り。
`scores` を `{"37": 3, "38": 0}` に直した（勝者は変わらない）。

### 佐藤直輝（中京 2 / 羽黒 7）

別人。中京の佐藤直輝はペアが**前田英貴**（1回戦 p12・2回戦 p21）、羽黒の佐藤直輝は**木皿璃夢斗**
（2回戦 p21・3回戦 p28）。どちらも複数回戦で同じペアなので塊の取り違えではない。
取り込みは `--same-name 佐藤直輝`、prebuild の検査は
`check-team-match-details.mjs` の `SAME_NAME_DIFFERENT_PEOPLE`（ファイル＋氏名を明示）で通す。
**氏名だけで緩めない**形にした。
