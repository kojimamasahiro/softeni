## 2. 決めたこと

### 収録 と 掲載

意味が近く、どちらでも通るので割れていた。以下で固定した（glossary に draft 登録済み）。

- **収録** = サイトがデータとして持っている**範囲・母数**
- **掲載** = そのページに**表示している／公開している**という行為・状態

「掲載」に寄せる案もあったが、既存の使用数が 収録 60+ に対し 掲載 20+ で、
かつ「掲載しています／掲載中／結果未掲載」という**表示の意味の掲載は正しく使われていた**ため、
母数の側を収録に寄せる方が churn が小さく、意味の切り分けも自然だった。

### 断り文（scope note）を1箇所に

同じ意味の断りが6通りに割れていたので `lib/uiText.ts` を新設して定数化した。

| 定数 | 用途 |
|------|------|
| `SCOPE_NOTE_SHORT` | バッジ・カード脇の最小注記（体言止め・句点なし） |
| `SCOPE_NOTE_MATCHES` | 試合データ由来の集計 |
| `SCOPE_NOTE_TOURNAMENTS` | 大会成績由来の集計 |
| `SCOPE_NOTE_RANKING` | ランキング（非公式・年度間比較不可まで言う） |

`lib/**` 側の `scopeNote`（careerRecord / milestones / playerStats）も
「収録」＋文末句点に揃えた。これらは SSG 時に算出されるので生成データの作り直しは不要
（`当サイト掲載大会分の集計に基づく` が `data/`・`public/` に焼かれていないことを確認済み）。

### 空状態の型

**状況 → 理由 → 次の行動**。理由と次の行動は一段小さい文字。
次の行動はリンク／ボタンで出す。無ければ「いつ出るか」を書く。
助詞は `〜がありません` に統一（`〜はありません` は対比のときだけ）。

## 4. 残っていること

- **`/beta/**` は未着手**（オーナー判断でスコープ外）。`alert()` 33 箇所、`Loading...` 4 箇所、
  用語「マッチ」30 箇所が残る。内部ツールの使い心地を上げたくなったらここから
- **見出し・リード文の再設計は未着手**（スコープ外）。トップの h2「ソフトテニス情報」など、
  何が並ぶのか読めない見出しが残っている
- **機械強制は無し**。絵文字だけが eslint で守られていて、収録/掲載・半角括弧・`...` は
  レビュー任せ。再発するようなら `no-restricted-syntax` を足す余地がある
- `docs/ui/glossary.md` の 収録／掲載 は **draft**。オーナー承認で approved にする（rules.md R6）
