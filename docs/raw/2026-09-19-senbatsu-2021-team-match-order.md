`information` の `sourceUrl` どおり。既存の `highschool_senbatsu_team_matches.py` が
**様式の改修なしで通った**（2022・2024・2025 と同じ）。

男子は一発で通った。女子で3つのことが起きた。

## 1. 未実施を `0 － 0` と印字する（女子のみ・7件）

**同じ PDF の中で男女の書き方が違う**。男子は 2-0 で決着した試合の第3対戦を**空欄**にし、
女子は **`0 － 0`** と印字する。**男子の空欄7件と女子の `0 － 0` 7件がちょうど対応**し、
女子の7件はすべて「2-0 で決着した試合の第3対戦」だった（1ゲームも行われていない）。

`0 － 0` を素直に読むと ADR-020 の `unfinished`（打ち切り時点の途中の本数）になるが、
それでは男子の同じ対戦と別の状態になる。**人に確認して `not_played` に倒すと決めた**。

倒すのは `--zero-as-not-played` で、**出典ごとの性質**なのでフラグにした（既定は off。
他の年度は影響を受けない）。歯止めとして **「他の2対戦だけで既に勝敗が付いている試合」に限る**——
決着していない試合の `0 － 0` は**本当に 0-0 で打ち切られた対戦**かもしれないので、
1つでもあれば止まる。倒した対戦は毎回表示する。

## 2. 勝者の丸数字の抜け（女子 match-24・1件）

3回戦 尽誠学園 対 京都光華 の第1対戦が `2 － 4` で両側に丸が無い。
4ゲーム先取なので決着済み。トーナメント表の本数が 尽誠学園 0 － ② 京都光華、
第2対戦も京都光華が取っていて第3対戦は未実施なので、**京都光華の2本のうち1本はこの対戦**と決まる。
`highschool-senbatsu-2021-corrections.json` の `rubbers` へ（2024 男子と同じ形・通算2件目）。

## 3. 既存データの誤り（女子 match-12）を1件直した

2回戦 旭川実 対 京都光華 の本数が `0 － 2` で入っていたが、**出典は `0 － ③`**。
500dpi で拡大して確認した（同じ縦線の次の段にある `②` は京都光華の3回戦の本数で、別物）。
対戦の内訳も京都光華の3勝（`3 － ④` / `2 － ④` / `0 － ④`、すべて丸あり）で一致する。
`scores` の `"18": 2` → `"18": 3` だけを直した（勝者は変わらない）。

**和が4以上の検査には引っかからない誤り**（0+2=2 も 0+3=3 も4未満）。
2024 女子の `1 － 3` とは逆で、**勝者の本数が少なく入っていた**。
和の検査だけでは足りず、**オーダーの勝ち数との突き合わせが要る**という実例。
