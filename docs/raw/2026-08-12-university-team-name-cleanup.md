# 大学カテゴリ: チーム名データの下ごしらえ（棚卸しと修正案）

2026-08-12 実施。[大学カテゴリの公開ページ検討](./2026-08-12-idea-university-category-pages.md)の
前提条件として、大学大会データのチーム名を全数点検した。**修正はまだ適用していない**（本ファイルは
レビュー用の提案）。

## 対象と規模

対象は大学専用大会3種（`zennihon-university` 2023–2025 / `zennihon-university-indoor` 2025 /
`zennihon-university-ouza` 2026）の `participants[].team`。

- 生のチーム名 **186種 / 延べ 5,959件**
- **要修正 67件（1.1%）／ 26種**
- 修正後のユニーク校は **約160校**

**当初「表記ゆれはほぼ0」と評価したのは誤り**だった。単純な正規化（括弧除去・語尾除去）で
突き合わせると0件に見えるが、実際の壊れ方が「**先頭1〜2文字の脱落**」なので、
`岡大学`（← 福岡大学）のように**正規化後も別キーのまま残る**。中学の表記ゆれ（出典差による
略称 vs 正式名称）とは壊れ方が違い、検出方法も違う。

## 校名の分裂（誤りではないが、ページ化の前に判断が要る）

`神戸松蔭女子学院大学` は **2025年に `神戸松蔭大学` へ改称**しており、データにも両方が出る
（本間友里那・石原愛菜など複数の選手が両方に出現）。上記1・3の誤りを直しても
**正しい表記が2つ残る**。

- 1校1ページにするなら「改称は同一エンティティ」として統合が要る
- 高校カテゴリには同型の前例が無い（高校の改称は収録期間に発生していない）
- 大学ページを作るなら**改称の扱いを最初に決める**べき論点。他大学でも今後起きる

## 統合してはいけない組み合わせ（検出の偽陽性）

語尾一致で機械的に拾うと候補に出るが、**実在する別の学校**なのでマージ禁止:

| 片方 | もう片方 | 理由 |
|---|---|---|
| 成蹊大学（42件） | 大阪成蹊大学（66件） | 東京と大阪の別大学。**両方とも正しい** |
| 近畿大学（44件） | 近畿大学工業高等専門学校（2件） | 大学と高専は別校 |
| 日本大学（21件） | 日本大学工学部（13件） | 学連では学部単位で別チームの可能性が高い（要確認） |
| 佛教大学 / 立教大学 / 文教大学 | — | `教大学` の親候補として並ぶが互いは別大学 |
| 城西大学 / 関西大学 | — | `西大学` の親候補として並ぶが互いは別大学 |

## 適用の手順（案）

既存の仕組みがそのまま使える。

1. `data/tournaments/team-name-aliases.json` の `teamAliases` に上記1・2・3の
   1対1で直せるぶん（23種）を追加する
2. `node scripts/normalize-team-names.mjs --scope=zennihon-university --dry-run` で確認 →
   本適用。indoor / ouza も同様に scope 指定で回す
3. `教大学` の2ペアは alias では直せないので、**先に手で直す**（位置指定）。
   alias 表に `教大学` を入れてはいけない
4. 取り込み側に **NFKC 正規化**を入れる（異体字の根治）
5. 選手名がチーム名になっている5組は**出典確認まで保留**。暫定で埋めない
6. `淑徳大学` `日本大学工学部` も出典確認まで保留
7. 適用後に `scripts/build-team-master.mjs` を回して `teams.json` を再生成し、
   `scripts/check-identity-health.mjs` で健全性を確認する

## 再現方法

集計はワンショットのPythonで実施し未保存。再現するには
`data/tournaments/details/{zennihon-university,zennihon-university-indoor,zennihon-university-ouza}/{year}/*.json`
の `participants[].team` を集め、

- 「他のチーム名の**末尾一致の断片**になっている名前」を探す（先頭欠落の検出）
- 「他のチーム名の**先頭一致の断片**になっている名前」を探す（末尾欠落の検出）
- `unicodedata.normalize('NFKC', name) != name` を探す（異体字の検出）
- 各候補について**同一選手が他の年に所属している正準名**を突き合わせて確定する

とすればよい。**選手照合が決め手**で、名前の一意性だけでは `西大学` `教大学` `淑徳大学` を
誤って寄せてしまう。
