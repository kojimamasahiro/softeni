# 高校の学校ページ「メンバー」検索の強化（2026-09-14）

## 経緯

大学カテゴリの実装の続きで、ユーザーから「SEO観点で。他のカテゴリも考慮して。
『メンバー』を含む検索も高校のチームではよくされているので、そこも強化できるならしたい」。

Claude が全カテゴリの title・見出し・メンバー節・パンくずを棚卸しし、候補を提示した
（高校①②③・中学生・小学生・大学・年度別ページ・大学のパンくず）。

ユーザーの決定:

- **地区大会の出場選手をメンバーに入れてよい**
- **①②③を実装**（下記）
- GSC で「メンバー」を含む検索がされていたのは**高校もしくは社会人**（中学生・小学生・大学ではない）

## 棚卸しで分かったこと

- 高校の学校ページは title・h1・メンバー節（`{学校名} ソフトテニス{男子}の年度別メンバー`）・FAQ に
  「メンバー」が既に入っていた。**足りなかったのは中身と、年つき検索への手当て**
- メンバーの出典は `data/highschool/prefectures/*/summary.json` の playerIds。
  summary に入っている大会はインターハイ・ハイスクールジャパンカップ・選抜・全日本系などで、**地区大会は入っていない**
  （高校カテゴリは地区大会を成績・ランキング・卒業生に統合しない方針。highschool.md）
- title 表示幅（`{学校名} 高校男子 全国大会成績・メンバー | ソフトテニス情報`）: 1,102ページで中央値28.5全角、
  **30全角超が129ページ**、最大31.5。Google の表示枠は概ね28〜32全角（seo.md「title の字数超過」）
- 中学生・小学生のチームページは title・見出しに「メンバー」が無い（「収録大会に出場した選手」）。
  大学（`/teams/[teamId]`）は title に「メンバー」はあるが「ソフトテニス部」が無い。年度別ページは description が1行

## 実装

### ① 地区大会の出場選手をメンバーに足す

- `lib/highschoolBlockMembers.ts`: `highschool-*-block`（9地区）と `highschool-tokai-senbatsu` の details から
  `学校名\t都道府県\t性別` → 出場選手（年×氏名）の索引をビルド時に作る。団体戦のチーム単位エントリー（氏名 null）は除く
- 学校ページの getStaticProps で pid を summary と同じ `姓_名_学校名_都道府県` 形式にして渡し、
  既存の年度別メンバー集計（同一年の同姓同名を1件に・リンク可能な pid を優先）に乗せる
- **集計パイプラインは触らない**。入れると成績サマリー・分析・ランキングにも地区大会が混ざるため
- 学校名は地区大会の `participants[].team` と完全一致で引く

実測（2026-09-14、ts-node で全ページに当てた）:

| | 値 |
|---|---|
| 学校ページ（学校×性別） | 1,102 |
| メンバーが増えるページ | **361** |
| 増えるメンバー（年×氏名） | **1,383**（2026年 1,299 / 2025年 84） |
| 最新年のメンバーが地区大会からしか取れないページ | **155** |

提案時の見積もり（366ページ・1,441名）との差は、見積もりが性別 mixed の扱いと
「全国大会に既に載っている選手」の重複除去を粗くしていたため。

### ② 最新年と人数を description・FAQ に出す

- description（開催中でないとき）: `{学校名}の高校男子の出場メンバー（2026年は17名）と全国大会成績を掲載。…`
- 開催中の description にも `年度別メンバー（2026年は17名）` を足した
- FAQ「{学校名}のソフトテニス部のメンバーは確認できますか？」の回答に「最新は2026年の17名」
- **title には入れない**（30全角超が既に129ページあり、年を足すと切られる）

### ③ メンバー節へのページ内リンク

- 導入文の直下に「2026年のメンバー（17名）を見る」→ `#members`
- メンバー節の説明文を「全国大会・主要大会・地区大会（ブロック大会）の結果に掲載された選手」に変更

dev サーバーで `/highschool/boys/kagawa/jinseigakuen/` を取得し、description・ページ内リンク・`id="members"` を確認。

## 見送ったもの

- 中学生・小学生のチームページに「メンバー」を足す — GSC で需要が確認できたのは高校と社会人のみ。
  小学生は子どもの氏名を「メンバー」検索で集める形になるので、需要があっても慎重に扱う
- 大学のチームページ title に「ソフトテニス部」、年度別ページの description 強化、大学のパンくずを「大学生」配下に — 未決定（提案のみ）
