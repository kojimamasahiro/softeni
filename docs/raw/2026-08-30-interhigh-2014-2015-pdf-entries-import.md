# 2015年・2014年インターハイ結果PDFからのエントリー抽出（団体戦ページの座標修正・文字二重化の修正）

## 背景

[2016年](2026-08-30-interhigh-2016-pdf-entries-import.md)・[2017年](2026-08-30-interhigh-2017-pdf-entries-import.md)
に続けて、同じセッションでユーザーから2015年（`2015_C05_40.pdf`=男子、`2015_C06_40.pdf`=女子）・
2014年（`2014_C05_40.pdf`=男子、`2014_C06_40.pdf`=女子）の記録PDFを渡され、同じ運用
（`tools/highschool-championship-<year>/` に initialPlayers.json のみ配置）で依頼された。
どちらもページ構成は2016年と同じ（個人戦ダブルス p1-8、団体戦概況 p10）。

2016/2017年では座標しきい値を変更せずに通ったが、2015年・2014年では
`scripts/pdf/highschool_championship_entries.py` の**団体戦ページ**でそれぞれ異なる
座標ずれが表面化し、スクリプト本体の修正が必要になった。個人戦ダブルスの座標
（DBL_LEFT/DBL_RIGHT）は2014〜2019年まで一貫して無修正で通っている。

## 見つかった不具合と対処

### 1. 団体戦ページのヘッダー除外しきい値（2015年で発覚）

`parse_team_page` は `c["top"] > 115` でヘッダー行を除外していたが、2015年PDFは
entryNo=1の行が top=114.0 に来るため、この1行がまるごと除外されていた
（entryNoが1つずれて以降全部が汚染され、`min=0`のような壊れた結果になった）。
ヘッダーの最終行はどの年度でもtop<=97程度のため、しきい値を`top > 100`に
下げても本体行を誤って含めない。2016/2017年で回帰確認済み。

### 2. TEAM_RIGHTのentry_no列の左端（2015年で発覚）

2015年PDFの右段entry_no列は実測x0=547.2ptから始まるが、既定の`entry_no: (549, 570)`
では549未満が切り捨てられ、2桁番号の1桁目が失われる（`30`→`0`のように化け、
entryNo重複の原因になった）。下限を`544`に広げて解消。2016/2017年で回帰確認済み
（2016年の実測は552.2pt、2017年も549以上に収まる）。

### 3. 団体戦ページ全体の座標が別水準（2014年で発覚）

2014年PDFは団体戦ページのentry_no/team/area列が2015年以降と別の座標に位置しており
（左段: entry_noが従来の(25,46)ではなくx0=53.5〜、team開始がx0=65.0。右段:
teamの開始がx0=399.7〜で従来の(400,483)の下限400に僅かに満たず先頭文字が欠落）、
単純な閾値の拡張では2015年以降の設定と両立できなかった。`parse_team_overview_page`に
`team_left`/`team_right`の上書き引数を追加し、CLIから`--team-left-cols`/
`--team-right-cols`で年度ごとに指定できるようにした（例:
`--team-left-cols "entry_no=45-63,team=63-140,area=137-192"`
`--team-right-cols "team=395-465,area=466-533,entry_no=533-550"`）。
これにより既定値（2015年以降）を変更せずに2014年だけ別設定で解ける。

### 4. 文字の二重描画による氏名・都道府県の二重化（2014年で発覚）

2014年PDFの個人戦ダブルスページ（男女とも）で、一部の選手（各ページ数名、
必ずペアの1人目＝playerA側）の氏名と、その行が共有する都道府県セルが
「猪猪本本拓拓己己」「徳徳島島」のように**1文字ずつ二重化**していた。
原因はpdfplumberが同一座標(x0,top,text)の文字を2回返していたこと
（`ncs`がDeviceRGB/DeviceGrayで1回ずつ、恐らく作成ソフト側の太字表現に由来）。
2015年以降のPDFにはこの重複が存在しない（実測でdupe数0）ことを確認済み。
`_dedupe_chars`（(x0,top,text)が完全一致する文字を1つにまとめる）を追加し、
`parse_doubles_page`・`parse_team_page`の両方で文字読み込み直後に適用した。
無害な防御のため、既存年度（2015-2019）の結果には影響しない（回帰確認済み）。

## 実施結果

- 2015年: 男子ダブルス318・団体48、女子ダブルス316・団体48。entryNo重複・欠番・
  空欄いずれもゼロ。
- 2014年: 男子ダブルス316・団体48、女子ダブルス312・団体48。同上、ゼロ。
- 両年とも都道府県は個人戦・団体戦とも省略形だったため、2016/2017年と同じ接尾辞補完を
  一時ファイルに適用（`participants[].id`と`entries[].playerIds`を両方張り替え）。
- 出力は`tools/highschool-championship-{2014,2015}/{doubles,team}-none-{boys,girls}.initialPlayers.json`
  のみ。`data/tournaments/details`へは書いていない。
- 抽出結果を画像と無作為抽出で照合（各年10件前後）し、全件一致を確認した。

`--team-right-cols`の存在、文字二重化の既知の不具合と対処を追記）。

  （ヘッダーしきい値・entry_no列の左端・座標系そのものが別水準）と、それぞれの対処
  （今後別の年度で同種の崩れに当たったときに、まずどこを疑うべきかの手がかりとして）
- `--team-left-cols`/`--team-right-cols`という逃げ道が存在すること
- 文字二重化のバグと`_dedupe_chars`による対処（2014年固有の既知の問題として、
  今後さらに古い年度を処理する際に同じ症状が出たら疑うべき原因として）

  デバッグの過程であり、対処（重複除去）だけが今後の実装に意味を持つため。
