# 2013年インターハイ（男子）スキャンPDFからのエントリー抽出

## 背景

ユーザーから2013年度全国高等学校総合体育大会ソフトテニス競技（北部九州総体）の記録報告書
PDF（`2013_C05_40.pdf`、13ページ）を渡された。ページ指定はユーザーから
「2-9が男子ダブルス / 11が男子団体」。実際にページ見出しをOCRして
p2-p9=「男子個人戦(1)〜(8)」、p10=男子個人戦（決勝ラウンド）、p11=「男子団体戦」、
p12/13=団体戦準決勝・決勝であることを確認した。今回は女子ページの指定は無く、男子のみ。

2014-2017年（[2026-08-30-interhigh-2017-pdf-entries-import.md](2026-08-30-interhigh-2017-pdf-entries-import.md)
ほか）と決定的に違う点は、**2013年PDFにはテキストレイヤーが無い**こと。全13ページが
2152x3035px・300dpi・1bpp（CCITT）のスキャン画像1枚ずつで構成されている。
ユーザーからも「画像をスキャンしたものをPDFにしている。また、少し傾いている。
どこまで精度が出るか確認してから反映したい」と、**精度確認を先にする**依頼だった。

## 実施したこと

### 傾きの実測 — 実害なし

「傾いている」という前提を最初に検算した。回転角を-2.0〜+2.0度で0.05度刻みに振り、
行方向射影の一階差分二乗和が最大になる角度を全13ページで探索した結果、**最大でも0.25度**
（p2/p3/p8/p9/p10は0.00度）。300dpiで文字高は約30px、ページ幅2150pxに対して0.25度は
端から端で約9pxのドリフトにすぎず、行・列クラスタリングを壊さない。**deskew処理は不要**と
判断した。「傾いている」という見た目の印象は、ページ端の黒枠や罫線の歪みによるもので、
本文組版そのものはほぼ水平だった。

### レイアウト解析 — 氏名は「姓3枠+名3枠」の固定グリッド

長い横線・縦線をモルフォロジーで除去してから連結成分を取り、行ごとの投票でX方向の
占有帯を出したところ、氏名欄が**6つの独立したスロット**に分かれていることが判明した
（ページ2・左ブロック実測）:

| | 姓1 | 姓2 | 姓3 | | 名1 | 名2 | 名3 |
|---|---|---|---|---|---|---|---|
| 左ブロック | 218-248 | 264-289 | 306-335 | （空白帯 335-399） | 399-427 | 444-471 | 488-516 |
| 右ブロック | 1335-1362 | 1379-1406 | 1422-1450 | （空白帯 1450-1513） | 1513-1541 | 1556-1585 | 1601-1630 |

スロット中心の間隔は左右とも約43-44px、姓3枠目と名1枠目の間だけ約93pxの明確な空白帯がある。
文字数に応じた入り方は:

- 3文字 … 3枠すべて（例: `大久保`／`優之介`／`聡一郎`）
- 2文字 … 両端の枠（例: `立木`→姓1と姓3、`雅也`→名1と名3）
- 1文字 … 中央の枠（例: `籬`→姓2、`英`→名2）

つまり**姓と名の境界はX座標だけで確定する**。2018/2019の「姓2枠+名2枠」で必要だった
「そのページ・その列で実際に使われた氏名文字のX最小/最大の中点をしきい値にする」
（`highschool_championship_entries.py` のパターン2）ような動的計算は不要で、
空白帯の一点で切ればよい。**2013年の様式のほうが姓名分割は簡単**だった。

行位置も安定していて、エントリー間ピッチ約106.7px、ペア内の2行間は約41px。

### OCRの精度検証 — tesseract単体は不採用

`tesseract -l jpn` を試した。ページ見出し（`男子個人戦(2)` 等）は問題なく読めるが、
**氏名は使い物にならない**。1文字ずつ切り出して `--psm 10` にかけるより、姓・名それぞれを
1つの画像にまとめて `--psm 7` にかけるほうが明確に良い（漢字は文脈が効く）が、それでも
ページ2左ブロックの先頭8行で:

| 正 | tesseract(psm 7) |
|---|---|
| 立木 / 雅也 | 立木 / 雅**包** |
| 浦川 / 将希 | 浦**月** / 将**。帝** |
| 矢壁 / 諒樹 | 矢壁 / **詠**樹 |
| 杉谷 / 昂平 | 杉谷 / **昌**平 |

姓名単位の正答率で6〜7割。氏名データとしては使えないため、**tesseractは採用しなかった**。

### 採った方式 — 座標セグメンテーション + LLMの視覚読み取り + 既存データ機械照合

1. 300dpiでページをPNG化し、`No.`列・氏名6スロット・都道府県/学校名列を含む
   帯（左ブロック x=140-800 / 右ブロック x=1320-2040）をエントリー10件ずつに切り出す。
   1枚あたり660-720px × 1080px、等倍で読める解像度。
2. その画像をLLMが直接読む。文字高30pxの明朝体印刷なので、判読はtesseractより大幅に良い。
   スロットのX位置で姓/名の切れ目が決まるため、読み取り時に姓名分割で迷う余地が無い。
3. 判読に迷った字は、その文字だけを6-8倍に拡大して個別確認する
   （実際に確認した例: `髙`と`高`の判別、`鬚川`、`鴈金`、`毅城`、`漠`、`繪上`、`靑豊`）。
4. 全件を機械照合にかける（下記）。

**この方式の肝は3の拡大確認より4の機械照合**。読み取り結果を独立した既存データと
突き合わせることで、視覚読み取りの誤りが自己申告に頼らず顕在化する。

### 機械照合の結果

照合スクリプトは、(a) `tools/highschool-championship-2014〜2017/` の
`doubles-none-boys.initialPlayers.json`（テキストレイヤー由来の正データ）に対する
「姓+名」完全一致、(b) `data/teams/teams.json`（4860件）に対する学校名×都道府県の整合、
(c) 47都道府県辞書との照合、を行う。

- **姓名完全一致で180名が確認できた**（314エントリー＝628名中）。2013年に1・2年生だった
  選手が2014-2017年の大会に再登場するため照合が効く。うち学校名まで一致しないのは9件で、
  すべて同姓同名の別人か、後述の校名変更・統合で説明がつく。**矛盾する一致はゼロ**。
- id 1-314に欠番・重複なし。47都道府県すべて出現（31県が6ペア、16都道府県が8ペア）。
- 氏名・学校の空欄ゼロ。
- 学校名が `teams.json` に無い/県が違うのは25件だが、**すべて実在校**と確認:
  `神埼`(佐賀) `吹上`(鹿児島) `善通寺一`(香川) `石岡一`(茨城) `杵島商`(佐賀)
  `西舞鶴`(京都) `那須清峰`(栃木) `延岡工`(宮崎) `多久`(佐賀) `赤穂`(兵庫)
  `茅ケ崎北陵`(神奈川) `鹿児島中央`(鹿児島) `伊勢原`(神奈川) `広島山陽`(広島) ほか。
  `城北`(徳島・徳島市立城北)と`高田`(奈良県立高田)は、teams.jsonの同名校
  （高知県の城北 / 岩手県の高田）と別校。

照合が校名変更を裏付けた例（読み取りの正しさの傍証にもなっている）:

- `三島`(静岡) … 望月元貴・岡本哲明が2014年は `知徳`。三島高校は2014年4月に知徳高校へ改称。
- `貞光工`(徳島) … 阿部瑞紀・大谷広夢・秋山晃羽が2014/2015年は `つるぎ`。
  貞光工業は2014年につるぎ高校へ統合。

団体戦48校も、46校が「2013年個人戦に同校が同県で出現」または「2014-2017年の団体戦データに
存在」で裏取りできた（裏取りできないのは `浜名`(静岡) と `新田`(愛媛) の2校のみ、いずれも実在校）。

### 異体字の扱い

**このスキャンは`高`と`髙`を明確に描き分けている。** 画素レベルで拡大比較して確認した
（entryNo 5「髙橋佑二郎」、18「髙木泰佑」は`髙`、32「高橋元希」は`高`）。しかし
entryNo 18の髙木泰佑（岡崎城西）は、同一人物が2014年の正データでは `高木泰佑` になっており、
**原典どうしが食い違う**。ユーザーに (a)スキャン通り`髙`を残す / (b)既存データに合わせて`高`に
寄せる を提示し、**ユーザーの判断は(b)**。よって `髙→高`（および同じ理由で `﨑→崎`）を
正規化してから出力した。`tools/highschool-championship-2014〜2017/` の実データには
`髙`と`﨑`が1件も無く（`高`1498件・`崎`1248件）、姉妹年度と結合可能な状態を優先した形。

一方 `濱/濵` `邉/邊` `澤` `齋` `德` `桒` は既存データにも実際に混在しているため、
スキャンの見たままを採用している。

### 出力

`tools/highschool-championship-2013/` に、2014-2017年と同じステージング形式で置いた。

- `doubles-none-boys.initialPlayers.json` … 314エントリー
- `team-none-boys.initialPlayers.json` … 48チーム（優勝は高田商（奈良））

`data/tournaments/details/highschool-championship/2013/` には書いていない。理由は
2014-2017年と同じで、予選ラウンドの勝敗は自動判定できず、`tools/tournament3` で人手
入力する運用を想定しているため。

# 追記: 女子（2013_C06_40.pdf）

## 男子PDFとの関係

**男女は完全に別ファイル**（男子 `2013_C05_40.pdf` / 女子 `2013_C06_40.pdf`）で、
