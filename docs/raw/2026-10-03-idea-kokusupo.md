# アイデア: 国民スポーツ大会（国スポ・旧国体）の収録

## 状況

Idea Backlog。P0 の前半（大会情報・エントリー）を投入済み（2026-10-03）。残は会期中の結果取り込み。

## 目的

国スポのソフトテニス競技を大会として収録する。毎年の注目大会なのに未収録で、高校カテゴリの
「主要4大会」（`lib/highschool.ts` の `highschool-kokutai`、優先度1）だけが定義済みで中身が空という
矛盾が続いている（[強豪校ランキングのアイデア](./2026-07-17-idea-highschool-strong-school-ranking.md)）。

## ユーザーが興味を持った点

徳島県連盟のページ（参考文献）を貼って「国民スポーツ大会が開催されるらしい。大会としてどうするのがいいか検討したい」。
選択肢から次を選んだ（2026-10-03）:

- 種別: **4種別すべて**（成年男女・少年男女）
- 学校ページ・強豪校ランキングとの連携: **当面つなげない**
- 時期: **2026年を会期に間に合わせる**（過去年度は後回し）

## 想定運用 / なぜこのスコープか

| 段階 | 内容 |
|---|---|
| P0 | 第80回（2026-10-16〜19）の大会情報＋4種別の組み合わせ・結果を、**都道府県を1チームとして**大会ページにだけ載せる。会期中に結果を更新 |
| P1 | 選手名簿（氏名＋所属）とオーダー（[団体戦のオーダー](./2026-09-18-idea-team-match-order.md)）を入れ、選手ページに出場歴、学校ページに「〇〇県代表として出場」 |
| P2 | 過去年度（第77回 2023鹿児島・第78回 2024佐賀・第79回 2025滋賀 など）の遡り |

- 学校につなげないのは、出場単位が学校ではなく都道府県だから。`highschool-*` の id にすると
  `scripts/build-team-master.mjs` が先頭一致で「高」ジャンルと判定し、「青森県」が学校ページとして生える。
- 1大会に4種別をまとめる（成年と少年は同じ大会なので）。少年を学校につなぐのは P1 で名簿が揃ってから。

## わかっていること

- 第80回 青森国スポ: 2026-10-16〜19、青森県総合運動公園テニスコート。少年男子 10/16-17、成年男女 10/18-19
  （JSTA 年間行事 `data/local-sources/jsta-yearly-events/2026.json` にも「共催」で掲載）。
- 形式は都道府県対抗の団体戦。1試合は3対戦（ダブルス・シングルス・ダブルス）。2025年の徳島のスコア
  （例: 2-1 で 4-1 / 2-4 / 4-3）から確認。
- 徳島県連盟ページにある組み合わせ PDF は成年男子・成年女子・少年男子の3本だけ（少年女子は徳島が不出場のためか無い）。
  出場数は PDF の番号から成年女子16・成年男子24前後・少年男子は33超（**Assumption**: 全体を読んで確定させる）。
- 少年は1校単独で組む県が多い（2025年の徳島少年女子は5人とも脇町高）が、混成の県もある。
- X で「国スポで3回戦から配信してほしい」という声がある（[X調査](./2026-09-17-x-posts-user-problem-findings.md)）。

## 課題・未解決

- **一次ソース**: 4種別の組み合わせ・結果の公式な出どころ（JSTA／あおもり国スポ公式）。少年女子の組み合わせが必要。
- **tournamentId と categoryId**: 新しい id（例 `kokutai`）にするか。成年／少年を categoryId の age でどう表すか
  （既存は `team-none-*`。少年の値は未定）。空の `highschool-kokutai` を残すか消すかは P1 で決める。
- 表記: 第78回までは「国民体育大会（国体）」、2024年の第78回佐賀から「国民スポーツ大会」。年度ごとの label で持つ。
- 参加者の `team` を「青森県」とした場合、teams.json・チームページにどう出るか（県チームが「成」ジャンルのチームとして混ざる）。

## 目指したい方向性

まず P0。少年女子を含む組み合わせの一次ソースを確保し、id・カテゴリ名を決めてから大会情報を入れる。

## 追記（2026-10-03・一次ソースと categoryId）

- **一次ソース**: JSTA「第80回 国民スポーツ大会について」（2026-09-07）に4種別の組合せ PDF がある。
  https://jsta.or.jp/news/2026/09/07/第80回-国民スポーツ大会について/
  （`wp-content/uploads/2026/09/{少年男子,少年女子,成年男子,成年女子}.pdf`）。出場数は少年男子47・少年女子21・成年男子24・成年女子16。
  下段に順位決定の枠がある。
- **categoryId の真ん中（age の位置）で成年と少年を分けられる**。値はカテゴリ定義の `age` に入れるだけで、
  既存にも `team-upper-boys` / `team-qualifying-girls` のような年齢以外の値がある（全日本中学クラブの予選）。
  表示名は information の `label`、URL は `/tournaments/<世代>/<大会>/<年>/team/<age>/<性別>`。
  - `parseCategoryId` は値を見ずに切り出すだけ。`check-duplicate-placements.mjs` の `STAGE_AGES`（同じ種目の段階分け）には**入れない**
    （成年と少年は別の種目なので、入れると同じ人の順位の重複として誤って扱われる）。
  - 出生年の推定（`check-identity-health.mjs` / `build-player-homonyms.py` の birthBand）は知らない値だと広い成年扱いに落ちるだけで、壊れない。
    少年を高校の範囲（y-19〜y-14）にするのは任意の改善。
- 案: `team-adult-*`（成年）/ `team-youth-*`（少年）。ユーザー確認待ち。

## 追記（2026-10-03・P0 前半を投入）

- ユーザー決定: categoryId は `team-adult-*` / `team-youth-*`、tournamentId は `kokutai`（空の `highschool-kokutai` と揃え、
  2023年以前の「国体」も同じ大会として扱えるため）。エントリーの `name` は県名だけ（「青森県（青森県）」と重ねない）。
- `data/tournaments/index.json` に `kokutai`（`generationId: all`）、`data/tournaments/information/kokutai.json` に第80回を追加。
  種目別日程は組合せ PDF の日付欄。会場は JSTA に記載が無く要項も未確認なので `venues` は持たず note に書いた。
- エントリー: JSTA の組合せ PDF（テキスト層あり）を `pdftotext -layout` で行ごとに「番号＋県名」として読み、
  47都道府県辞書で照合。少年男子47・少年女子21・成年男子24・成年女子16、欠番・重複・辞書外なし。
  徳島県連盟の組合せ（別の PDF）と徳島の1回戦の相手3件が隣の番号で一致することを確認。
  汎用 CLI（`extract_tournament.py`）は使っていない（県名だけの表で、字間の空いた県名と番号の対応だけ取れば足りるため）。
- `tools/kokutai-2026/*.initialPlayers.json` にステージング。ローカルで `/tournaments/all/kokutai/` が開催予定として表示されることを確認。
- ランキングの除外設定は入れていない。参加者が都道府県で選手 id を持たないため、選手のランキングに入る経路が無い
  （**Assumption**: 結果を入れる段で details の participants が県だけであることを再確認する）。
- 結果を details に入れると `build-team-master.mjs` が県名のチームを作る（ジャンルは「成」）。その扱いは結果取り込み時に決める。
