## 様式の見極め（Excel 様式との違い）

スキルの「読む順序」4つに沿って。

1. **1対戦の印字**: ペアの行と本数の行が**別の行**。氏名（高さ約10.1pt）の**約2pt下**に
   本数（高さ約6.5pt）。Excel 様式は同じ行（差 1.6pt 未満）なので、既存スクリプトでは1つも読めない。
   **左右は本数の行の「－」の x で分ける**（氏名の行だけでは切れ目が無い）。
2. **勝者**: 丸数字（④）。Excel 様式と同じ。
3. **塊と試合の対応**: Excel 様式と同じ（初戦は2校のエントリー行の中間、以降は選手の重なり）。
   **塊の x が回戦を表す**。左ページは深いほど右（1回戦 x≈153 →準決勝 x≈343）、
   **右ページは鏡像**（1回戦 x≈445 →準決勝 x≈260）。塊の中では「－」の x が揃う。
4. **左右**: 左＝エントリー番号の小さい学校。**男女・全70塊で成立**（勝ち数の一致で裏が取れる）。

そのほか、この様式でだけ効いたもの:

- **1種目が左右2ページに分かれる**。Excel 様式は1ページ（または1冊）に左右の山が収まる。
  `--pages 左,右` の2ページを読んで塊を連結し、どちらのページから来たかを「山」として持つ。
- **決勝は右ページの左上**に「決勝 <学校> ② － 0 <学校>」の見出しつきで置かれる。
  Excel 様式の「ページ中央の塊」に当たる手がかりが無いので、
  **左右の山をまたぐ試合は右ページの残った塊から選手の重なりで選ぶ**。
  見出しの本数は検算になる（男子 尽誠学園 2－0 高田商、女子 京都光華 0－2 東北。どちらも一致）。
- **縦の位置は行の中心で比べる**。氏名の行は高さ10.1pt・エントリー番号は14.9pt なので、
  上端どうしを比べると約7pt ずれて**初戦の中間判定が35件全部外れる**（最初の実行がこれで、
  「割り当てられない試合」が全件出た）。
- **学校名も都道府県も1文字ずつ別の語**（均等割り付け。`尽@69 誠@93 学@117 園@140`、`香@171 川@189`）。
  Excel 様式は都道府県名でエントリー行を見つけていたが、**この様式では使えない**。
  代わりに**高さ13pt超の数字**で見つける（左ページ x≈50・右ページ x≈538）。
- **ページ下端の柱（ノンブル）も高さ13pt超の数字**。y<800 で捨てないとエントリーが19件になる。
- **学校単位の本数（高さ約9.7pt の裸の数字）が氏名の行に紛れ込む**。氏名から数字を捨てる。
  捨てないと `小坂井天詩 0` のような選手ができる。
- **氏名の `・` は語の中に含まれる**（`大翔・豊田` が1語）。Excel 様式は `・` が独立した語。
  側ごとに語を空白でつないでから `・` で割ると、姓名の空白の有無どちらにも効く
  （`塚本 大翔・豊田 祐冴` → `塚本 大翔` / `豊田 祐冴`、`坂田真咲斗・中村翔太朗` → 2人）。

| 検算 | 男子 | 女子 |
|---|---|---|
| 塊（p左17＋p右18＝35）＝試合35件・各3対戦 | 一致 | 一致 |
| エントリー行 18＋18＝36＝details のエントリー数 | 一致 | 一致 |

| 決勝の見出しの本数 | 2－0 一致 | 0－2 一致 |
| `not_played` の数＝2-0 で決着した試合の数 | 12＝12 | 10＝10 |

`npm run check:team-match-details` は投入後 645試合 / 1935対戦 問題なし。

`not_played` と 2-0 決着の一致は**この様式で新しく効いた検算**。未実施の第3対戦にも
ペアだけは印字されるので、数が合わなければ塊の対応か行の切り出しが崩れている。

選手の結び付け: 男子は延べ420のうち記録あり377・名前だけ43（実人数31）、
女子は記録あり393・名前だけ27（実人数16）。学校名の表記違いは見当たらない。
姓名が続けて印字されて空白が入らないもの: 男子4名（`佐々木修雅` `小坂井天詩` `松尾真太郎`
`牟田琉之介`）・女子2名（`横山友佳子` `長屋百合乃`）。長い氏名に多く、この様式では通常。
