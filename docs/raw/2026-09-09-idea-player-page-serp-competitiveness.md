# アイデア: 選手ページの検索競争力（選手名クエリの掲載順位）

## 状況

**2026-09-09 に P2a（所属歴のメタデータ化）のみ実装**。出発点は「選手名クエリで表示回数は多いが
平均掲載順位が10位前後で、クリックが少ない」という問題提起だったが、調査の過程で**前提が2回覆り**、
実施範囲は当初案よりかなり小さくなった。残りの候補は効果が見込めないと判断して不採用。

## 目的

選手ページを、ソフトテニス選手について検索したユーザーにとって最も有用なページの一つにする。
当初の焦点は「表示回数が多く平均5〜15位にいる選手ページを上位へ押し上げる」ことだった。

## ユーザーが興味を持った点

- 「グループBを攻めたい」（＝Wikipedia・公式SNS等の本人資産を持たない選手層）
- 「代表所属は最新だけがいい」（過去の所属を title の主役に据える案を明確に不採用）
- 「P3は根拠なく決めれないので却下」（読み仮名データ整備）
- 「P2a だけ入れて、他はあまり効果が出ないのでやらない」

## わかっていること

### 1. 選手は2つのグループに割れる（SERP 実測・2026-09-08）

| 選手 | GSC 平均順位 | SERP の顔ぶれ |
|---|---|---|
| 船水颯人 | 11.78位 | ナレッジパネル / Wikipedia / Instagram(4.2万) / X(2.9万) / YouTube(4.6万) / YONEX公式 / JOC / 選手名鑑 / Facebook |
| 廣瀬礼衣 | 1.30位 | Instagramタグ / 誉ノート / SOFT TENNIS Naviタグ / 地方局ニュース（**Wikipedia も公式SNSも無し**） |

**グループA（本人資産あり）**: 1〜10位が本人所有プロパティで構造的に埋まっており、当サイトの
11位は「公式・SNS を除いた最初の枠」で実質天井。さらに「他の人はこちらも検索」は
年収 / 引退理由 / 現在 / 結婚 / ラケット / 兄弟 と**100%が伝記的意図**で、当サイトが扱わない情報。
仮に順位を上げても CTR は上がらないと考えられる。

**グループB（本人資産なし）**: 当サイトがその人物についてウェブ上で最も構造化された情報源になれる。
実際 1〜4位・CTR 10〜25% を取れている。

代表例5人のうち下位3人（船水颯人・黒坂卓矢・片岡暁紀）は**全員 curated 23選手**、
上位2人（廣瀬礼衣・塚本七海）は curated ではなかった。

### 2. GSC の順位分布は「攻めるべきか」の判断に使えない（構造上）

ユーザー提示の分布（選手名クエリ 55件）:

| 掲載順位 | 件数 | 割合 |
|---|---|---|
| 3位以内 | 15 | 27.3% |
| 5位以内 | 35 | 63.6% |
| 10位以内 | 53 | 96.4% |
| 10位超 | 2 | 3.6% |

一見「順位は既に良い」と読めるが、**GSC は表示回数0のクエリを行として出さない**ので、
圏外のページは分布に入りようがない。母集団が「既に表示されているクエリ」に条件づけられており、
96.4% は構造上そう見える。これは [seo.md](../wiki/seo.md)「計測の原則」が 2026-08-28 に
自分で書いた罠と同型。

**55クエリ ÷ index対象の選手ページ 1,723枚 = 3.2%**。残り 1,668枚が「需要が無い」のか
「圏外」なのかは、この表からは読めない。

### 3. GSC に出ていない選手を SERP で直接見た（n=3）

| 選手 | count | 結果 |
|---|---|---|
| 庭田咲月 | 16 | ウェブ結果 2位。1位は `softtennishitting.com`「プロフィール・戦績まとめ」 |
| 廣瀬礼衣 | 13 | 常用字体「広瀬礼衣」でも1位 |
| 木原恵菜 | 19 | **圏外**。需要は明確（引退報道・U-20ナショナル・実業団ナガセケンコー） |

3件中1件が圏外。**圏外率はゼロではない**が、n=3 では何も決められない（→ 未実施の P0）。

### 4. 棄却した仮説2つ（実測で否定）

- **異体字（廣→広 等）**: 結果ページを持つ 1,959人中 **140人（7.1%）**が氏名に旧字体を含む
  （澤28・髙22・﨑17・齋11・嶋11・濱10…）。しかし Google は同一視していた——「広瀬礼衣」で
  検索して当サイトが1位を取り、SERP に「含まれない: 広瀬 / 必須にする: 広瀬」と明示された。**対策不要**。
- **所属名の表記ゆれ**: index対象 1,723枚中 **2枚**のみ（木原恵菜「サンワxエナジークラブ/
  サンワエナジークラブ」、簗田亮「道後・八千代クラブ/道後八千代クラブ」）。誤差。

### 5. title が字数超過で Google に書き換えられている（既存 Open Question への回答）

seo.md の Open Question「#3（2026-08-06 追記）title 変更後の SERP タイトルが書き換えられずに
出るか」に対する実測回答。**書き換えられていた**。

```
実際の <title>: 船水颯人（One） 全日本選手権優勝5回・全日本インドア優勝2回ほか全国優勝計12回｜試合結果・戦績 | ソフトテニス  （59全角）
SERP の表示  : 船水颯人 選手の試合結果（One） - Softeni Pick   （＝H1 + サイト名）
```

対して廣瀬礼衣（26全角）は `<title>` がそのまま出ている。ビルド済み `out/` の実測:

- index対象 1,723枚、title 表示幅の中央値 26.5全角
- **30全角超が245枚（14.2%）**、32超187枚（10.9%）、40超75枚（4.4%）
- 超過しているのはほぼ全て 2026-07-20「全国大会優勝 literal」施策の対象者
  = **最も押し上げたいページだけが title を捨てられている**

原因は [lib/nationalTitles.ts](../../lib/nationalTitles.ts) の `TWO_LABEL_MAX = 26` が
**実績フレーズだけ**を予算にしており、`{選手名}（{所属}）` と `｜試合結果・戦績 | ソフトテニス`
（14全角）を数えていないこと。**未修正**（本セッションの実装スコープ外）。

### 6. title / description が「最新の所属」しか持っていない

圏外だった木原恵菜のページの解剖から出た、一般化できる欠陥。

```
title: 木原恵菜（サンワxエナジークラブ）の試合結果・戦績 | ソフトテニス
所属別成績(本文): 高田商 2017〜2019 15勝7敗 / ナガセケンコー 2021〜2025 39勝23敗 / サンワ系 2026
ページ内の「高田商業」出現回数: 0
競合 soft-tennis.jp POCKET: 経歴 = 橋本ジュニア/九度山中学校/高田商業高校
```

世間が彼女を指すときの名前（ナガセケンコー・高田商業）が title にも description にも無い。
`byTeam` ベースで数えると **index対象 1,723枚のうち 1,547枚（89.8%）が2つ以上の所属を持つ**。

勝っている競合の形は「戦績」ではなく**人物プロフィール**だった
（softtennishitting.com は 氏名・読み・所属・学年・学部学科、soft-tennis.jp POCKET は
ポジション・生年月日・出身地・経歴）。

## 実施した改修（P2a のみ）

`byTeam`（所属名・期間・勝敗・優勝数）は `getPlayerStatistics(id, {}, root)` が全セクションを
読んでいるため**データ配線は不要**だった。

- 新規 [lib/playerCareerAffiliations.ts](../../lib/playerCareerAffiliations.ts):
  所属歴の抽出（古い順・表記ゆれ正規化・最新所属を除外）、description フレーズ、
  JSON-LD ノード、表示幅計算、末尾の予算配分
- [src/pages/players/[id]/results.tsx](../../src/pages/players/[id]/results.tsx):
  description 末尾に `これまでの所属は◯◯・◯◯。` を追加、JSON-LD `Person` に
  `alumniOf` / `memberOf` を追加（`affiliation` は最新1件のまま変更なし）
- テスト [lib/__tests__/playerCareerAffiliations.test.ts](../../lib/__tests__/playerCareerAffiliations.test.ts)
  （`npm run career:test`・12件）、CI の `checks.yml` にゲートとして追加

### description の予算配分

Google のスニペット表示は概ね全角120字で、改修前から既に **166枚（10%）が超過**していた。
そこへ足すので、末尾2要素の取捨規則を置いた（`composeDescriptionTail`）:

1. 予算内なら「主なペア」＋「所属歴」の両方
2. 入らなければ**所属歴を優先し主なペアを落とす**——ペアの相手は本文の「関連選手」から
   相互リンクされていて相手自身の結果ページもあるが、所属歴は本ページにしか出ない語だから
3. どちらも入らなければ改修前と同じ「主なペアのみ」（**既存文言は削らない＝非破壊**）

### 実測（ビルド済み out/・1,723枚）

| 指標 | 改修前 | 追記のみ案 | 採用（入れ替えあり） |
|---|---|---|---|
| description に所属歴が入った | 0枚 | 907枚（候補の58.6%） | **1,329枚（候補の85.9%）** |
| うち主なペアを落として入れた | ― | ― | 407枚 |
| JSON-LD `alumniOf` / `memberOf` | 0 / 0 | ― | **749枚 / 1,325枚** |
| description 表示幅 中央値 | 100全角 | 112 | **114** |
| 同 >120全角 | 166枚(10%) | 166枚(10%) | **166枚(10%)**（＝非破壊を確認） |

`npm run build` 完走、`npx tsc --noEmit` クリーン、`npm run career:test` 12/12 pass。

## 課題・未解決

- **発端の木原恵菜は description に入らなかった**。head（実績＋直近＋通算＋最高ランキング）
  だけで約103全角あり、所属歴26全角を足すと予算を超えるため規則3へ落ちる。JSON-LD には
  入っている（`memberOf` にナガセケンコー）が、そちらは効果を測れない側。
  `DESCRIPTION_MAX_WIDTH` は export 済みの定数なので、上げる判断をするなら1行で変えられる。
- **効果は測れない**。`alumniOf` / `memberOf` に Google のリッチリザルトは無く、
  2026-07-20 の `award` 追加とまったく同じ位置づけ（Assumption）。
  description 側も、足した語は**ほぼ全部すでに本文の所属別成績表にある**ので、
  新しい literal を足したのではなく**既にある語の重み付けを上げた**にすぎない。
  単独で圏外を覆す施策ではない、という前提でユーザーが採用を決めている。
- **略称の学校は `memberOf` 側へ落ちる**（「高田商」は学校マーカーに掛からない）。
  誤りではないが不正確。→ 下記 P2b が前提。
- **P0（圏外率の実測）が未実施**。GSC に出ていない index対象から30〜50人サンプルして
  SERP を直接見る。これが無いと、今後どこへ投資すべきかが決められない。

## 不採用にしたもの（2026-09-09・ユーザー判断）

| 案 | 理由 |
|---|---|
| **P1 代表所属**（最新ではなく最も知られた所属を title に） | 「代表所属は最新だけがいい」 |
| **P2b 学校の正式名**（高田商 → 高田商業高校） | ユニーク所属名 1,203件に対し `data/teams/review-decisions.json` の merge 済み学校グループは105件（8.7%）。しかも identity の名寄せ判断であって略称→正式名の対応表ではない。全体では1,100件規模の新規人手データが要る |
| **P3 読み仮名** | 「根拠なく決めれない」 |
| 異体字対応 / 表記ゆれ対応 | 実測で不要と確認（上記4） |

## 目指したい方向性

グループBを攻める方針は維持。ただし本セッションで分かったのは「順位を上げる」より
**表示が発生する母数を増やす**ほうが総量が大きい可能性があること。次の一歩の候補:

1. **P0（圏外率の実測）** — 投資先を決める材料そのもの。これが先
2. **title の名乗りを人物寄りにする** — 圏外だった木原恵菜のSERPで上位は全て「人物として
   名乗っているページ」で、当サイトだけが「試合結果として名乗っている」。代表所属は最新固定と
   決まったので、動かせるのは `の試合結果・戦績` の側。ただし1,723枚全部に影響するので別テーマ
3. **title 字数予算の修正**（上記5）— 245枚が対象、`TWO_LABEL_MAX` 周辺の1関数
