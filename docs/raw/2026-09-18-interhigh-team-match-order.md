# インターハイ 2026 女子団体のオーダー取り込み（2026-09-18）

ユーザーの依頼「インターハイの読み取りも試作して」。高校選抜（[ADR-020](../adr/ADR-020-team-match-rubber-details.md)）の
次の様式として、インターハイの公式記録PDFに対応した。**投入まで実施**。

## 様式（令和8年度 女子団体・ユーザー提供の `pref2_st0911_jyosidantaikekka.pdf`）

- p1 入賞校一覧 / p2 トーナメント表（学校単位の本数のみ）/ **p3・p4 準々決勝 / p5 準決勝 / p6 決勝**。
  詳細があるのは**ベスト8以降の7試合だけ**。1〜3回戦は本数のみ。詳細ページは1ページに最大2試合。
- 見出し行に**左右のエントリー番号**が印字されている。details の試合とは**番号で直接対応**するので、
  高校選抜のような位置・選手の重なりからの推測が要らない（そのぶん実装は単純）。
- 1対戦 = ゲーム行が最大7行（左ポイント・「－」・右ポイント）。丸数字がそのゲームを取った側。
  行の中ほどに両ペアの氏名（姓と名が別の語・「・」無し）と、対戦の本数（丸数字＝勝者）。
- 列の x 座標: 左 姓112 / 名146 | 左 本数223-226 | 左ポイント270-279 | 「－」293 |
  右ポイント316-325 | 右 本数360-364 | 右 姓425 / 名459。

## 踏んだ落とし穴

1. **ポイントの丸数字が10以上になる**（`⑩ － 8`）。変換表が⑨までだったため、そのゲームの左ポイントが
   欠落し「印字された本数 2-4 / 数え直すと 1-4」で止まった。**検算が効いた実例**。
2. **「打ち切り」の印字はあてにできない**。印字がある対戦（明豊-須磨学園 第3対戦）と、
   `3-3` のまま印字が無い対戦（文大杉並-須磨学園 第2対戦）が混在する。
   勝者は**本数の丸数字の有無**で決めるのが正しい。

## 結果

- 7試合・21対戦。完了17・打ち切り4・未実施0。
- 検算はすべて一致: 見出しの本数＝details、対戦の勝ち数＝details、
  **印字された本数＝ゲームごとのポイントの数え直し**、ペアは全て2人、2校に割り当てられた選手なし。
- 選手は**延べ84人すべてが姓・名で結び付いた**（同じ大会の個人戦に出ているため。高校選抜より高い）。
- ゲームごとのポイントは `games`（ADR-020 追記2）として保存。**表示はしない**（ユーザー判断）。
