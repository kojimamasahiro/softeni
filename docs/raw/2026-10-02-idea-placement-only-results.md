# アイデア: 対戦表のない大会を「順位だけ」で掲載する（世界ジュニアを起点に）

## 状況
Idea Backlog。発散フェーズ（2026-10-02）。公式の出典を確認済みで、データの形は未決。

## 目的
トーナメント表（対戦表）が公開されていない大会でも、公式の順位だけを選手ページの経歴へつなぐ。
起点は第5回世界ジュニア（2026-10-26〜11-01・中国 京山市）の日本選手団発表。

## ユーザーが興味を持った点
- 「トーナメント表のようなものがなさそう。zutto-sports のように結果だけのようにするかどうか検討したい」
- 「他の大会も最低限の情報で掲載するかどうか」
- 「zutto-sports はソフトテニス特化ではないことと、速報が重視されてそうなので真似はできないと思っている」

## 想定運用 / なぜこのスコープか
- 狙いは結果ページで検索上位を取ることではなく、**選手の経歴の穴を埋めること**（高校・大学の選手ページに
  「世界ジュニアU-18優勝」が付く、勲章カードの国際大会欄、高校の「主な卒業生」の条件の「国際大会出場」）。
  速報型の汎用サイトは選手単位の記録を持たないので、ここは真似されにくい。
- [seo.md](../wiki/seo.md) の「速報クエリでは量産サイトと正面勝負しない」と整合させる。会期中の速報はやらない。
- 範囲はまず**国際大会**に絞る。国内大会一般に「最低限の掲載」を広げるのは勧めない
  （全試合があるというデータの質の約束が崩れ、ランキング・通算成績に混ぜられないため）。

## わかっていること
- 公式の出典（JSTA）:
  - 第4回（2024-11-03〜06）の報告記事に、日本選手全員の成績（優勝〜ベスト8、所属つき）と団体の順位。
  - 添付の `WJ4_result.pdf`（6ページ、主催者作成、英中併記）は**全種目の上位8（全ての国）**:
    個人12種目（U15/U18/U21 × 男女 × シングルス/ダブルス）は 1・2・3（2）・5（4）、団体は男女とも 1・2・3（2）。
    **対戦カード・スコアは無い**。本ページは載っていない。
  - 第5回の派遣者一覧PDF: 各年代（U-21/U-18/U-15）男女2名ずつ計12名、所属つき。種目別の割り当ては無い。
  - 第3回（2018）の記事も JSTA にある（未確認）。
- 結果PDFの読み取りの罠:
  - 順位の数字は行の縦中央にあり、`pdftotext -layout` だと 3位（2名）と5位（4名）の境界がずれて見える。
    JSTA の記事（日本選手の成績）で照合すると「3位は2名、5位は4名」で読むと一致する。
  - 見出しの誤り: U21シングルスのページが「Doubles results」、団体のページが「単打成绩」。
  - ローマ字の誤記: 橋場柊一郎が `HASHIBA TOICHIRO`。
- 第4回の結果は JSTA の記事と結果PDFで食い違いなし（日本選手分）。
- 既存の仕組みとの関係:
  - 代表名簿 `data/tournaments/delegations/` は実装済み（アジア競技大会2026）。第5回の派遣者一覧はこの形で入る見込み
    （種目の割り当ては「年代×性別×シングルス/ダブルス/団体」の推測になるので要確認）。
  - 「過去の国際大会は遡らない。前回1件だけ例外」の方針（[ランブック](../wiki/upcoming-tournaments-runbook.md)）。
    第4回はちょうど「前回」。
  - `details/**` は entries と matches が前提。**結果（順位）だけを持つ前例は無い**
    （`zennihon-senior/2026` は進行中の「出場」で別物）。
  - 外国選手は国際大会では `participants` に入る（アジア競技大会の前例。ローマ字・国名・`prefecture: null`）。

## 課題・未解決
- データの形: `details/**` に matches 空で results だけを入れるか、別の置き場（delegations のような転記データ）にするか。
  ADR 相当の判断。
- 外国選手まで持つか、日本選手だけか（PDF には上位8の全ての国が載っている）。
- 選手ページ・勲章カード・主な卒業生への載せ方（順位だけの大会を勝敗の集計から外す仕組み）。
- 第5回の会期中の扱い（日本選手団の名簿だけか、結果も会期後に入れるか）。
- 第3回（2018）を入れるか（「前回1件」の例外を広げることになる）。

## 目指したい方向性
まだ発散フェーズ。第4回の順位（全ての国の上位8）＋第5回の代表名簿を最小の単位として、
データの形を決めてから実装する。

## 追記（2026-10-02）: 第5回の代表名簿を入れた
- `index.json` に `world-junior`（`generationId: international`、`isMajorTitle: false`）を登録し、
  `information/world-junior.json` に2026年の回（試合日10/28〜30・中国・団体の日程10/30）、
  `delegations/world-junior-2026.json` に選手12名を入れた。`ranking-config.json` の `excludeTournaments` にも足した。
- **種目は団体だけ**（ユーザー判断）。発表は年代（U-21/U-18/U-15）を示すが個人種目の割り当ても年代別かどうかも無いため。
  年代は持つ欄が無いので名簿の `note` に記録した（公開されない）。
- `大𣘺玲雨` は選手ページの表記 `大橋` に揃えた。12名とも選手ページに解決（`check:upcoming` [4] で0件）。
- 大会ハブと選手結果ページ（例: 塚本光琉 `/players/159/results/`）に代表ブロックが出ることを dev で確認。
- 残: 年代を公開ページに出すか（名簿の型に欄が要る）、個人種目の categories を組み合わせ発表後に足すか、第4回の順位の扱い。
