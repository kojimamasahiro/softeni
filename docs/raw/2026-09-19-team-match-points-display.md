# 団体戦の対戦詳細にゲームごとのポイントを出す（2026-09-19）

[ADR-020 追記2](../adr/ADR-020-team-match-rubber-details.md)で `games`（ゲームごとのポイント）を
データに入れたとき、**表示はしない**と決めた。その「見せ方を別途決める」をここで決めて実装した。

## 出発点の実測

- `games` を持つのは **1,191 対戦のうち 749 対戦**。大会別: インターハイ 2022〜2026 男女団体、
  アジア競技大会2026 男女団体。**高校選抜（2022・2025）は 210 対戦すべてが 0**（元資料が本数まで）。
- **同じページで有無が混ざる**: インターハイ2025 は 21 対戦中 18。
- ページには届いていなかった。`lib/packedPageData.ts` の `PackedTeamMatch` が7要素で、`games` を落としていた。
- 追加の転送量（`games` の raw JSON）: インターハイ2023 男子 **4,585 バイト**（135対戦・全試合ぶん）、
  同2024 男子 685 バイト（21対戦）、アジア大会2026 男子 1,523 バイト（47対戦）。
  増えるのは団体戦の年度別結果ページだけ。

## 検討した案（モックで比較）

| 案 | 内容 | 判断 |
|---|---|---|
| A | 対戦行の直下に全幅で1行（`5-3 5-7 5-3 5-3`） | **採用**（ユーザー確定） |
| B | 本数セル（`w-16`）の下に縦積み | 却下。セルを広げるとペア名が潰れ、1対戦が5〜7行の高さになる |
| C | 本数を押すと開く | 却下。同日に「上位の組は開いた状態で出す」で減らした操作を対戦単位でまた増やす。閉じている間はページ内検索に出ない |

細部のユーザー判断: **ファイナルゲーム（3-3 の第7ゲーム・7点先取）に印は付けない**（何ゲーム目かは位置で分かる）。

勝ったゲームの示し方は**太字**。公式記録の丸数字（`④ － 1`）は、`⑩` 以上の字形と読み上げが
フォント・環境で揺れるので使わない（[ux-writing.md](../wiki/ux-writing.md) は丸数字自体は許可している）。

## 実装

- `src/types/tournament.ts`: `TeamMatchRow.games`（**この行の組から見た向き**）。
- `lib/packedPageData.ts`: `PackedTeamMatch` の8番目の要素。**記録がある対戦にだけ** push する
  （高校選抜のページを重くしない）。unpack 側は `games?.length` で分岐。
- `src/components/Tournament/MatchResults.tsx`:
  - `orientTeamMatches` で B 側なら `[a, b] → [b, a]`。
  - `TeamMatchGames`（`<ol>` を `flex flex-wrap`・`pl-16` で 第N対戦 ラベルぶん寄せる）。
    多いほうに `font-bold text-text`。読み上げは `sr-only` の「第Nゲーム」「対」。
  - `<li>` を「行の `<div>` ＋ ポイントの `<ol>`」に組み替えた（元は `<li>` 自体が flex 行）。
  - 節の冒頭の注記は、`hasTeamMatchGames`（ポイントを持つ対戦があるページ）のときだけ1文足す。
- `lib/__tests__/packedTeamMatches.test.ts`: 往復のケースを追加。**`[12, 10]` を混ぜて**2桁が潰れないこと、
  記録の無い対戦（`unfinished` / `walkover`）に `games` が湧かないことを見る。

## 検証（dev・1024×768 と 375px）

| ケース | 結果 |
|---|---|
| インターハイ2024 男子団体 尽誠学園（勝った側のカード） | 決勝 第1対戦 `1-4` の下に `3-5 4-0 2-4 2-4 3-5`。取った側が太字 |
| 同 高田商（負けた側のカード） | 同じ対戦が `4-1` ＋ `5-3 0-4 4-2 4-2 5-3`。**左右が反転している** |
| 375px | 6ゲームでも1行に収まり、横スクロールは出ない（`scrollWidth == innerWidth`） |
| アジア大会2026 男子団体 韓国 | 7ゲームの対戦も1行。シングルス（第2対戦）も同じ形 |
| 同 棄権の対戦 | `3-2 棄権` の下に決着した5ゲームだけ（中断された `0-0` は元から `games` に無い） |
| 同 不戦勝・未実施の対戦 | ポイント行を出さない |
| 高校選抜2025 女子団体（`games` なし） | ポイント行ゼロ。冒頭の注記も**ポイントの1文が出ない** |

`npm run bracket:test` 5件パス（うち新規1）。`tsc --noEmit` / eslint クリーン。
