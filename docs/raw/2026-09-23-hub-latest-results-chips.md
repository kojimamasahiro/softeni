# 大会ハブの冒頭に最新年度の結果チップを出す

適用範囲: 汎用

## 状況

2026-09-23、アジア大会2026 の X 投稿を考える中で「大会ハブ（全体まとめページ）をシェアして各結果へ
遷移してもらいたいが、年度別結果が一番下なのはなぜか」という問い。

## 調べたこと

- 年度別結果を最下部に置く判断の記録は wiki / ADR に無い。git 履歴では、2026-06-16 のハブ新設時は
  「大会名 結果」クエリの受け皿として歴代優勝者の表が先頭で、その後 開催前ブロック・関連する大会（8/26）、
  代表名簿（9/8）、記録（9/22）が上に積まれて押し下げられていた
- アジア競技大会ハブ（スマホ幅 375px）で、年度別結果は約5,100px 中の約3,900px（画面5枚ぶん下）
- 会期中は開催前ブロックの実施種目チップが結果ページへリンクしているが、`endDate` を過ぎると
  ブロックごと消える（`lib/upcomingInternational.ts`）。会期後は、1画面目から結果ページへの導線が無くなる。
  個人種目の優勝者セルは選手ページへのリンク

## 決めたこと（ユーザー判断: 案A）

- H1 直下に「{最新年度}年度の結果」と、その年の種目チップを出す（年度別結果と同じリンク先・同じラベル）。
  「過去の年度は年度別結果へ」のページ内リンクを添える
- 開催中で、開催前ブロックの実施種目が同じ年の結果へリンクしている間は出さない（同じチップが2段並ぶため）
- 棄却した案B「年度別結果を歴代優勝者の上へ移す」: 年度の多い大会（天皇賜杯など）で歴代優勝者の表が大きく下がる

## 確認

tsc / eslint。プレビュー（375px）で天皇賜杯ハブ（開催予定 2026・最新結果 2025）の冒頭に「2025年度の結果 男子 女子」、
全日本シングルスに「2026年度の結果」、アジア競技大会ハブ（開催中）では出ないことを確認。
