# 全日本社会人2026 男子ダブルス一般の確定版インサイト（2026-08-30）

## やったこと

大会2日目に男子ダブルス一般（`doubles-none-boys`）が決着したので、
[1日目に公開した進行中版](./2026-08-29-zennihon-workers-2026-day1-insight.md)を確定版に差し替えた。
**同一大会で進行中版→確定版の差し替えを社会人カテゴリで初めて実施**した回。

```bash
npm run check:orphans -- -t zennihon-workers -y 2026     # 手順0
npm run story:generate -- -t zennihon-workers -y 2026 -c doubles-none-boys --no-records -o <yaml>
npm run story:verify  -- -t zennihon-workers -c <6種目> draft.md
node scripts/check-tournament-insights.mjs
```

- 生成 **12件**（`title-won` 1 / `pair-rematch` 1 / `best8-streak` 9 / `self-best` 1）
- 照合 **一致39 / 不一致0 / 未検証0**
- `check-tournament-insights.mjs` … 公開34件すべて照合済み（件数は増減なし＝差し替えなので）

wiki のとおり `state` は `published` のまま本文だけ差し替えた。公開時にその場で照合し直されるので
運用は二重にならない。

## 6種目のうち決着したのは1種目だけだった

「大会が終了した」と受け取ったが、実データ上で全試合が決着していたのは
**男子ダブルス一般の1種目のみ**。残り5種目は未決着の試合が残っている。

| 種目 | 試合数 | 未決着 | 順位の状態 |
|---|---|---|---|
| doubles-none-boys | 397 | **0** | 優勝1・準優勝1・ベスト4/8で6 |
| doubles-none-girls | 130 | 7 | `ongoing` 14 |
| doubles-over35-boys | 145 | 20 | `ongoing` 43 |
| doubles-over35-girls | 35 | 4 | `ongoing` 8 |
| doubles-over45-boys | 103 | 15 | `ongoing` 32 |
| doubles-over45-girls | 49 | 2 | `ongoing` 4 |

そのため確定版に差し替えたのも1種目だけで、**残り5種目は進行中版のまま**。
結果が入り次第、同じ手順で個別に差し替える必要がある。

`story:generate` は `-c` で種目を絞れるので、種目ごとに決着した順に回せる。
（`--in-progress` を付けない＝完了版モードで、未決着種目に対して回すと経年kindが立たない）

## 進行中版と確定版で材料がまったく入れ替わる

同じ種目・同じ大会で、生成される kind が総入れ替えになった。

| | 進行中版（1日目・3回戦終了時点） | 確定版（決着後） |
|---|---|---|
| 件数 | 13（eliminated 1 / advancing 8 / school-progress 4） | 12 |
| kind | `watched-*` のみ | `title-won` / `pair-rematch` / `best8-streak` / `self-best` |
| 共通の kind | **0** | |

ADR-007 の `ongoing` があるので当然ではあるが、**進行中版の本文を部分的に手直しして使い回すことはできない**
（根拠にした storyId が1つも残らない）。差し替えは常に書き直しになる。

## 進行中版で書いた「NTT西日本の4組が全員勝ち残り」の後始末

進行中版の第2段落は「勝ち残っている4組がいずれもNTT西日本」を軸に書いていた。
これは skill が警告する**集計値（照合の対象外）**にあたる。確定後の実際は以下。

| 成績 | 組 | 所属 |
|---|---|---|
| 優勝 | 内本隆文・上松俊貴 | ＮＴＴ西日本 |
| 準優勝 | 上岡俊介・丸山海斗 | UpＲise / oneteam（混成） |
| ベスト4 | 矢野颯人・内田理久 | ＮＴＴ西日本 |
| ベスト4 | 長江光一・林佑太郎 | ＮＴＴ西日本 |
| ベスト8 | 本倉健太郎・広岡宙 | ＮＴＴ西日本 |
| ベスト8 | 御手洗友哉・榊原健太 | CROSSTYHOLDINGS |
| ベスト8 | 阪本崚・星野雄慈 | ワタキューセイモア |
| ベスト8 | 仲川晴智・石灘蒼瑛 | 東邦ガス |

確定版でもこの筋は残したが、扱いを変えた。

- **単年の事実に限定**した（「ベスト8に残った8組のうち4組が」）。
  進行中版にあった「NTT西日本はこの種目で4年連続で優勝している」のような**所属の経年集計は落とした**。
  wiki の「年をまたぐ本文に所属を書かない」に反するうえ、生成YAMLに所属単位の経年 kind が無く、
  自分で数えた値になるため。
- 数えた根拠を `scopeNote` に明記した（全中2026の前例と同じ形）。
- 準優勝の上岡俊介・丸山海斗は**所属の異なる混成ペア**なので、所属を主語にできない好例だった。

## 照合を通すために語順を変えた1箇所

初稿の「2025年に続く2年連続の優勝です。」は **未検証1件**（主語を特定できず）になった。
`上松俊貴・内本隆文はこの種目で2025年も優勝しており、2年連続の優勝です。` に直して
**未検証0**。抽出パターンが「主語＋(\d{4})年＋成績」なので、主語を省いた「〜に続く」は網に掛からない。

wiki に既に書かれている落とし穴だが、**実際に踏んで初めて具体形が分かった**ので記録しておく。
