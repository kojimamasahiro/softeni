## 同じ大会でも年度でレイアウトが違う

ページ指定はユーザーから提示された（男子 p1-8 / 女子 p10-17）。p9/p18 は準々決勝以降の一覧。

| | 2019年度 | 2018年度 |
|---|---|---|
| 氏名フィールド | **7スロット**（姓0-2 / 名4-6） | **5スロット**（姓0-1 / 名3-4） |
| 1ページのエントリー | 47〜48 | 22〜24 |
| ページ下部 | なし | **奇数ページに「準々決勝戦」の再掲**（本体と同じ列・番号つき） |
| エントリー番号の位置 | 括弧行 | 括弧行。**ただし女子 p16/p17 の右ブロックだけ1人目の行**（括弧行より11pt上） |

3行で1エントリー・括弧行が共通値、という骨格は同じなので
`scripts/pdf/zennihon_championship_entries.py` を両対応に拡張した。
**2019年度の出力がバイト単位で変わらないことを、改修のたびに確認している。**

## 改修で潰した落とし穴

### スロット数を出現数だけで決めると壊れる

はじめ「出現数の多い上位N本をスロットとみなす」で書いたところ、**2019年度 p6 右ブロックの
5番目のスロットだけ出現数が低く**（そこに文字が入る氏名が少ない）、頻度で切ると氏名欄が
4スロットで打ち切られ、名が丸ごと所属列へ流れた。
**基準位置とピッチは高頻度の2本から取り、あとは文字の有無で伸ばす**のが正しい。

### 再掲ブロックは「文字の段階で」捨てる

アンカー（氏名行・括弧行）だけ y で落としても、**再掲の県・所属の行が生き残って
直上のエントリーにくっつく**（`日本学連東京東京` のような連結になった）。
見出し（準々決勝/準決勝/決勝戦/3位決定）より下の文字を最初に捨てる。

### エントリー番号は括弧行に無いことがある

女子 p16/p17 の右ブロックは番号が1人目の行に印字される。番号はエントリー単位の値なので、
括弧行に無ければ選手の行から拾う。気づいたのは `id_range` の計算が `None` で落ちたため。

### 枠に入りきらない氏名は文字が落ちる（実バグ）

`ミヒニャック　瑠偉` は9文字を5スロットに詰めるためフォントを5.8ptに縮めており、
最終スロットを0.68スロットぶん超えた `偉` が「スロット範囲外」として**捨てられていた**。
氏名欄の中にある文字は捨てず両端のスロットへ寄せる。全16ページを走査して影響はこの1行のみ、
2019年度は0行と確認した。

## 姓名の分割 ― 5スロットは中央が埋まると決まらない

フィールドは「姓を左詰め・名を右詰めにし、中央のスロットを空ける」組み方なので、
**中央スロットが境界**になる。ところが5スロットでは中央が埋まる行が714行中100行あり、
`小田島｜俊介`（3+2）と `加藤｜健太郎`（2+3）が**座標上まったく同じ形**になる。
7スロットの2019年度で問題にならなかったのは、中央が埋まるのが4文字姓の1件だけだったため。

そこで既知データで決める。優先順は

1. 姓名ペアの完全一致
2. 姓・名それぞれの既知度（姓の一致を重く見る。名は表記の幅が広いため）
3. 決まらなければ**姓2文字で仮置きし、警告に出す**

語彙の出典は `data/tournaments/details/**`（一次情報）＋ `--reference` で渡した隣接年度の
ステージング。100件のうち自動で決まったのが94件、残り6件を人が確認した。

### `data/players/index.json` を語彙にそのまま使ってはいけない

**index.json には誤った分割が162件混ざっている**（`小茄子 / 川湊` 等、いずれも `count: 0` の
履歴レコード）。これを語彙に入れると `小茄子` が既知の姓として振る舞い、
**2019年度で正しく割れていた `小茄子川｜夏月` が `小茄子｜川夏月` に退行した**。
`data/players/name-split-aliases.json` に人手判断で「誤り」と確定した分割が蓄積されているので、
それを除外リストとして使う。

### 人手判断は `--name-split` で受け取る

座標でも既知データでも決まらない行は残る。`--name-split '姓名=姓|名'` で指定でき、
**一度も一致しなかった指定は警告に出す**（紙面や綴りが変わったときに黙って無視されないため）。
2018年度で使ったのは2件。

```
--name-split 'ミヒニャック瑠偉=ミヒニャック|瑠偉'   # 男153
--name-split '矢多部美弥=矢多部|美弥'              # 女56
```

残る要目視3件（`若田｜実友子` `三隅｜はすは` `竹崎｜加奈子`）と男12の `稲積｜京之介` は
仮置きのままだが、いずれも読みとして自然でユーザー確認済み。
