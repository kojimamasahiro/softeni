# アイデア: 団体戦のオーダーを SEO に繋げる

## 状況

**実装済み**（2026-09-19）。オーダー（[ADR-020](../adr/ADR-020-team-match-rubber-details.md)）は
データも表示も入ったが、**検索から辿り着ける形になっていなかった**。この日に 2 つを入れた。

1. 学校ページの年度別メンバーに、オーダーに出た選手を足す（`lib/highschoolTeamMatchMembers.ts`）
2. 団体の年度別結果ページに「オーダー」の literal と FAQ を出す（`lib/teamMatchOrderSummary.ts`）

## 目的

ユーザーの問い「最近色々機能を追加したが、SEO の強化に繋げられるものはないか」（2026-09-19）から、
直近の追加機能（オーダー・競技方式 `format`・大学カテゴリ）を棚卸しした結果。

## わかっていること（2026-09-19 実測）

- オーダーを持つのは **28ファイル＝28ページ**（年度別結果の団体のみ）。785試合 / 2,355対戦、
  うち 1,051 対戦がゲームごとのポイントを持つ。
- 選手は実人数 2,688 人。うち **934 人**が選手ページに結び付く（`count>=5` の姓名完全一致）。
- 学校×年は **551 組**、延べ 3,948 名。そのうち **約 1,286 名（33%）はその年の個人戦の
  `participants` に出てこない**＝学校ページのメンバー一覧に載っていなかった層。
- **`grep -rn "オーダー" src lib` は 2 件だけ**だった（型定義のコメントと `st-league/about.tsx` の
  「標準的なオーダー順」）。画面の文言は「対戦ごとの記録」「第N対戦」で、X で使われる語
  （[X投稿の調査](./2026-09-17-x-posts-user-problem-findings.md) B）がサイトに無い。
  [seo.md](../wiki/seo.md) の「missing literal」と同じ型。
- **年度別結果ページには FAQ が1つも無かった**（大会ハブ・学校ページ・選手ページにはある）。

### 棄却した打ち手（再調査しない）

- **「オーダーを選手ページに出すと noindex が index に変わる」は誤り**。オーダーに出る 934 人の
  選手ページを実測すると **933 人が既に index、noindex は 1 人**だけだった（全選手ページでは
  1,961 中 232 が noindex）。全国大会の団体に出る選手は、そもそも個人戦の記録で閾値
  （`PLAYER_INDEX_MIN_MATCHES` / 全国高校大会の出場歴）を超えている。
  選手ページに出す価値は「厚み」と「{選手名} 団体」系のロングテールであって、掲載数ではない。
- **title に「オーダー」を足す**のは今回は見送り。団体の title は既に
  `全国高等学校総合体育大会2025 男子団体 結果・組み合わせ`（表示枠 28〜32 全角を超過）で、
  枠を奪い合う語を増やす判断は字数予算の見直しとセットにする必要がある。

## 入れたもの

### 1. 学校ページのメンバー（`lib/highschoolTeamMatchMembers.ts`）

地区大会のメンバー（`lib/highschoolBlockMembers.ts`、2026-09-14）と同じ形にした。
ビルド時に details を直接読み、`学校名\t都道府県\t性別` で引く。集計パイプラインは触らない。

- **対象は高校の大会だけ**（`index.json` / `local_index.json` の `generationId === 'highschool'`）。
  国際大会はエントリーが国名で都道府県を持たないので、その判定でも落ちる。
- **「名前だけ」の選手も入れる**（ユーザー判断 2026-09-19）。空白で姓・名に割り、
  空白が無いもの（実測 27 枠）は割らずに姓へ入れる。リンクは張らない。
  pid の名の位置が空になるので、表示側は `parts[1]` が空なら姓だけを出す。
- 確認: 尽誠学園（男子）でオーダー由来 79 件・新規に 2020〜2024 の 12 名以上が加わる。
  鹿児島実（女子）2022 で、割れない「眞川涼花」がそのままの表記で出る。

### 2. 年度別結果ページの literal と FAQ（`lib/teamMatchOrderSummary.ts`）

- description に「各試合のオーダー（第1対戦からの出場ペアと本数）も{n}試合ぶん掲載。」を足す。
- 「オーダーについてのよくある質問」節と **FAQPage** を、オーダーを持つ種目だけに出す。
  - Q1「{大会}{年}{種目}の決勝のオーダーは？」→ 決勝の第1〜第3対戦を実際のペア名と本数で答える。
    決勝の記録が無い大会（会期中のアジア大会など）では Q1 ごと出ない。
  - Q2「オーダーはどの試合まで分かりますか？」→ 収録試合数・対戦数、ゲームごとのポイントの有無。
- **画面に出している文面をそのまま FAQPage に入れる**（表示していない答えを構造化データにだけ
  持たせない。[seo.md](../wiki/seo.md) の `offers` を付けない判断と同じ側）。
- 対戦詳細の注記を「オーダー（対戦ごとの出場ペア）」という言い方に変えた。

## 課題・未解決

- **効果の計測**。GSC で「オーダー」「{学校名} メンバー {年}」の表示回数を見る。平常期のチェックは
  [highschool.md](../wiki/highschool.md) の 9 月末の計測とまとめられる。
- **選手ページに団体戦の出場を出すか**（934 人が対象）。ADR-020 の追記で「通算成績には数えない」と
  決着しているが、集計とは別の「出場記録」節を出すかは未決。同 ADR に
  「この解釈はユーザーに確認中」が残っている。
- title の字数予算（seo.md の「選手ページ（未修正）」と同じ問題が団体ページにもある）。
- 名前だけの選手とリンク付きの選手が同一人物でも別行になりうる（`中川心` と `中川 心`）。
  取り込みの再実行で姓・名に置き換われば解消する。

## 目指したい方向性

次は計測。オーダーは 28 ページ（＋551 の学校×年）にしか無いので、効果が出るとすれば
「{学校名} メンバー」「{大会}{年} オーダー」のロングテール。順位を追うより、
**圏外だった語が表示回数を持つようになったか**を見る。
