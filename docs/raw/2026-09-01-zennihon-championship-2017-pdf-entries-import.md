## この年で新しかったもの

### 都道府県欄に「県・連盟」が入り、折り返す

```
花 岡 忠 寿      奈良・
7 ( 高田商業高校 )      ← 括弧行を中心に上下へ折り返し
増 田 祐 太      高体連
```

全8ページで33件、すべて `<県>・高体連`（一部 `中体連`）。**`prefecture` には県の側を採る**
（ユーザー判断。`participants[].prefecture` は正準な47都道府県を持つのが原則で、連盟は
「県が分からないときに県の代わりに入る値」という位置づけのため。既存の
`関東・埼玉県`→`埼玉県` と同型）。

折り返しの判定は**末尾の `・`** で足りる（座標の推測が要らない）。ただし
**結合した行のyは構成文字全体の中心にし直す**こと。1行目のyのままだと1人目の行へ
吸い寄せられ、2人目の県が空になる。

なお出典側は元々ゆれており、同じ高田商業でも2018年度は奈良県4件・高体連10件、
2019年度は奈良県10件・高体連4件が混在している。

### 圧縮された氏名がスロットの左へはみ出す

`ミヒニャック　瑠偉` は9文字を7スロットに詰めるためフォントを縮めており、
`ミ` がスロット0より1.3pt左にあって氏名欄の外と判定され落ちていた。
2018年度は同じ人物の `偉` が右へはみ出して落ちていた（[2018のノート](2026-09-01-zennihon-championship-2018-pdf-entries-import.md)）。
**両端を0.4スロットぶん広げる**。番号列・スコア列とは20pt以上離れているので混ざらない。

### 所属欄の折り返しは座標では選別できない

2017年度は所属名が2行に折り返される例が6件ある。

| 折り返し | 正しい名前 |
|---|---|
| `青森県高体連` + `・教員クラブ` | 青森県高体連・教員クラブ |
| `東洋大学附属` + `牛久高校` / `牛久高等学校` | 東洋大学附属牛久高校 |
| `広島修道大学附属` + `鈴峯女子高校` / `鈴峯女子中学校` | 広島修道大学附属鈴峯女子高校 |
| `八戸工業大学` + `第一高校` | 八戸工業大学第一高校 |

**幾何条件（行送りが中央値の55%未満 かつ 直上の行が列幅をほぼ使い切っている）だけだと
2017年度で60件、2019年度で42件が候補に挙がり、本物の6件を選別できない**
（`関西学院大学` + `親和銀行` のような正当な隣接ペアが同じ条件を満たす）。
そこで意味的な条件に切り替えた:

1. 次の行が `・` で始まる
2. 直前の行が `附属` / `付属` で終わる
3. **連結した文字列が既知のチーム名**（`data/teams/teams.json` ＋ `team-name-aliases.json`
   ＋ `details/**` の実表記）
4. 次の行が1文字（既知データに無い新チームの折り返しの保険。2019年度の
   `神戸松蔭女子学院大` + `学` はこれで拾っていた）

条件3が効くのがこの方式の要で、`八戸工業大学` のように**単体でも実在する名前が
折り返しの前半になる**ケースを拾える。誤結合には気づけないので結合は必ず警告に出す。

結合部の空白除去も要る（`東洋大学附属　牛久高校` のように全角空白が残る）。

### 異体字は「既存データに寄せる」

2017年度の紙面は `髙橋臣` `岡﨑聡太` `髙瀬沙里` `髙本侑加` `髙橋柚圭` `黑木瑠璃華`
`髙梨春花` `髙栁千佳` `德田玲奈` と異体字で刷られており、そのままだと2018/2019年度の
同一人物と別人になる。ユーザー判断で**寄せる**ことにした（`--fold-name-variants`）。

**一律の正規化はしない。** `岩﨑拓斗` `川﨑海奈` のように異体字が正しい人が実在するため、
「紙面の表記が既存に無く、かつ異体字を畳んだ表記がちょうど1つ既存にある」ときだけ寄せる。

この方針は既に確定した年度にも及ぶので、2019年度1件（`髙野渉`）と2018年度6件
（`矢﨑健太` `髙場姫菜` `髙栁千佳` `髙梨春花` `德田玲奈` `髙内佑来`）を再生成した。
**既定では寄せずに候補を警告に出すだけ**にしてあり、`--fold-name-variants` を渡した
ときだけ実際に寄せる（確定済みの出力を黙って書き換えないため）。

（`scripts/normalize-prefectures.mjs` の Tier B と同じ考え方だが、ステージングの時点で
正しくしておく）。
