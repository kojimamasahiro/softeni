# 全国中学校ソフトテニス大会 2019年度（第50回）エントリー取り込み

日付: 2026-08-30
入力: `2019_C09_40.pdf`（ユーザー提供、6ページ）
出力: `tools/secondaryschool-championship/2019/{doubles,team}-none-{boys,girls}.initialPlayers.json`
手順: skill `tournament-pdf-to-players` の「スキャンPDF経路」

## 入力の性質

- **テキストレイヤー無し**（`pdfplumber`で全6ページ 文字数0）→ `extract_tournament.py` は使えない。
- ただしインターハイ2012/2013のスキャン（300dpi・1bpp CCITT）とは質がかなり違う:
  埋め込み画像は **1653×2338 の DeviceRGB JPEG（≒200dpi カラー）**。赤ペンで
  スコアが手書き（というより印刷）されており、カラーで保存されている。
- ページ構成（ユーザー指定と見出しOCRで一致を確認）:
  p1/p2=男子個人戦1/2、p3/p4=女子個人戦1/2、p5=男子団体戦、p6=女子団体戦。
- 個人戦は1ページ32ペア（左1-16・右17-32）×2ページ＝**男女とも64ペア**。
  団体戦は**男女とも25校**（左1-13・右14-25）。全中2024と同じブラケット様式。

## 判断したこと

- **deskew 不要**。罫線が水平で、半分縮小の全景でも行がまっすぐ。
  インターハイ2012で必要になった `cv2.warpAffine` は使っていない。
- **座標での姓名分割ロジックが要らない**。この様式は姓と名が広い空白で分離して
  印字される（`長谷川　美波` `五十嵐　響紀`）ため、クロップ画像をそのまま読めば
  分割位置が自明。skillの「パターン1〜3」のどれを当てるかを悩む必要が無かった。
- **連結成分やモルフォロジーによる列検出も書いていない**。300dpiレンダリング
  （`fitz`, 2480×3505）から固定オフセットで4件ずつクロップ（720×635px）すれば
  等倍で十分読める。エントリーのピッチは 158.75px、左列 x=260-980、
  右列 x=1470-2270、1件目の中心 y≈475。
- **tesseractは使っていない**（見出しの裏取りも目視で足りた）。
- 判読に迷った字は6-8倍拡大で個別確認した: `反保 皐聖`(男43)、`須藤 漱太`(男51)、
  `西内 舜敬`(男57)、`佐藤 昴琉`(男61)、`與川 賢樹`(男62)、`大威 寧々`(女54)。
  すべて第一印象どおりで確定。
- **異体字はスキャンどおり残す**（インターハイと逆の判断）。`髙﨑 陽佑`(男24)、
  `髙橋 ひかる`(女4)、`長﨑 あき`(女30)。理由: 既存の全中データ
  （`data/tournaments/details/secondaryschool-championship/2021/`）に
  `髙橋` `髙澤` `村﨑` が実在し、正規化すると逆に姉妹年度と繋がらなくなるため。
  ユーザー承認済み。
- **学校名はPDFの印字どおり**（`芝東` `日野`）。既存2021データは `芝東中学校` のように
  「中学校」付きと無しが混在しているが、寄せずに原典どおりにした。ユーザー承認済み。
- **ブロック名は捨てて県名だけ採る**（`中国 ・ 鳥取` → `鳥取県`）。`開催地 ・ 京都`（男2,
  男63, 女31, 女63, 男子団体15, 女子団体15）も同様に `京都府`。
- 各ページ下部の再掲枠は除外した。p1=`野口・黒坂（芝東）`(No.12)、
  p2=`相澤・赤津（芝東）`(No.64)、p3=`西村・大畑（下山門）`(No.27)、
  p4=`岩元・岩元（榛原）`(No.41)。いずれも本体に同一エントリーがあるので、
  重複チェックで検出できる形にはせず読み取り段階で落とした。
- 原典の表記ゆれ: 女子団体12 `大社` が `中国 ・ 島根県`、同22 `就実` が `中国 ・ 岡山県` と
  **県名に「県」が付いている**（他は全て付いていない）。正式名称へ展開する処理を通すので実害なし。

## 検証（すべてクリア）

- id連番: 4ファイルとも重複・欠番ゼロ（64/64/25/25）。
- 47都道府県辞書: 全件一致。空欄ゼロ。ダブルスの2人目欠落ゼロ。
- 姓4文字以上/名が空（`review_name_split` 相当）: ゼロ。
- 同一ペア・同姓同名の重複: ゼロ。
- **既存の全中データ（2021-2026, 参照名簿1282名）との「姓+名」完全一致照合**:
  - 男子 2/128、女子 6/128。全中は3年で完全に入れ替わるので、2019年の1年生が
    2021年の3年生として出る分しか当たらない。件数の少なさは想定どおり。
  - 学校まで一致: `前田英貴（多治見）`、`溝上明璃`/`大橋玲雨（磐田豊田）`、
    `林美桜`/`宮本涼（東浦北部）`。
  - **校名変更を検出**: `馬島沙英`/`辻田莉夢` が2019年 `山陽女子`(岡山) → 2021年
    `山陽学園`(岡山)。ペアごと一致しているので読み取りの正しさの傍証になる。
  - 矛盾する一致は1件のみで、`村田優斗` 丸森(宮城) vs 2023/2025 上青木(埼玉)。
    年次的に同一人物ではありえず、同姓同名。
- 学校名×都道府県の照合: `data/teams/teams.json` は高校中心のため中学校名は
  ほとんど載っておらず、この大会では有効な検証にならない（`大谷`(神奈川)が
  teams.jsonでは富山、`高田`(福岡)が岩手、等はすべて同名の別高校）。
  代わりに既存の全中データ401校を参照した照合が有効で、
  男子個人26/56・女子個人21/55・男子団体14/25・女子団体15/25が既知校と一致、
  県の食い違いは `大谷`（2019年は神奈川、既存データは富山）1件のみ。
  PDFに `関東 ・ 神奈川` と明記されており、同名の別校。
