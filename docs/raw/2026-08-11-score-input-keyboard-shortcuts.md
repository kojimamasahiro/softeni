# score 入力のキーボードショートカット（修飾なし単キー）

日付: 2026-08-11
状態: 実装済み（`/beta/matches/[matchId]/input`）

## きっかけ

「キーボードショートカットを作りたい」。割り当ては本人指定:

- `s` = 開始時刻
- `a` = サービスエース
- `d` = ダブルフォルト
- `f` = 1stフォルト

## 実装前の状態

`useMatchInputController` の keydown ハンドラに動画操作のみ存在した。

- `Ctrl+S` 開始時刻 / `Ctrl+E` 終了時刻 / `Ctrl+D` 再生 / `Ctrl+F` 動画時刻クリア
- `←` `→` 5秒シーク
- **入り口で `!getActiveYouTubeVideoId()` なら全部 return** していたため、
  動画が無い試合ではショートカットが一切効かない構造だった。

## 実装

1. keydown ハンドラを「Ctrl系」「修飾なし単キー」「矢印キー」に整理。
   - `metaKey` / `altKey` 併用時は何もしない（OS・ブラウザのショートカットを潰さない）
   - 動画が要る操作だけ `hasVideo` を確認するようにし、**動画の有無で入り口ごと落とすのをやめた**。
     これでポイント入力系のキーは動画の無い試合でも効く。
2. 追加した単キー:
   - `s` / `e` = 動画の開始／終了時刻を記録（`Ctrl+S` / `Ctrl+E` は従来どおり残す）
   - `a` = サービスエース、`d` = ダブルフォルト、`f` = 1stフォルト
     （入力フォームが出ている＝`isPointInputActive` のときだけ）
   - `e` は指定に無いが、`s`（開始）と対で `Ctrl+E` とも一致するので追加した。
   - `g` = ポイント記録（編集中は更新）。後から追加指定。ボタンの disabled 条件と同じく、
     勝者チーム未選択・送信中は無視する。
3. サービスエース／ダブルフォルト／1stフォルトの更新ロジックを `PointInputForm` の onClick から
   コントローラの `selectServiceAce` / `selectDoubleFault` / `toggleFirstServeFault` へ移動。
   ボタンとキーの実装が二重にならないようにした。
   移動にあたり、選手・勝者チーム・ラリー数の決定は `inferPointData` に任せる形に置き換えている
   （関数側は「何をリセットするか」だけを決める）。挙動は従来と同じ。
4. 対応するボタンの右肩に割り当てキーを小さく併記（`ShortcutKeyHint`、`aria-hidden`）。

## 衝突について

- 単キー `d` / `f` と既存の `Ctrl+D`（再生）/ `Ctrl+F`（クリア）は `event.ctrlKey` で分岐するので衝突しない。
  ただし**同じ文字に別の意味を割り当てている**ため、覚え違いは起きうる。
- テキスト入力中（input / textarea / select / contenteditable）は従来どおり無効。

  ラリー数、直前を修正、編集キャンセル。本人の追加指定待ち。
