# アイデア: スコアが増えるとできること（記録の動機づけ）

> **適用範囲: 混在**。「データが増えるほど価値が上がる機能を並べ、次に何が使えるかを見せて記録を続ける動機にする」という
> 考え方は汎用。個々の機能（ポイント単位の比較・大会単位の集計）はソフトテニス固有。

## 状況

Idea Backlog。**発散フェーズ**（2026-09-27）。候補を洗い出して、必要な試合数を実データで確かめた段階。どれも未着手。

## 目的

score の記録は運営が公開動画から手で付けていて、1試合10〜40分かかる。記録を続ける動機がほしい。
「記録が増えるとこれができる」を先に並べておき、記録するたびに次の機能に近づくのが見える状態にしたい。

## ユーザーが興味を持った点

原文（2026-09-27）:

> スコアが増えることでできる機能を考えて、スコアを増やすモチベーションにしたい。
> また、スコアを楽にする方法も併せて考えたい

> バックログにして。1.5倍速だけ実施してほしい

> 2倍速も入れて別でPRの作成をお願い

「楽にする方法」は [記録の半自動化](./2026-07-11-idea-score-recording-semiauto.md) の 2026-09-27 追記に書いた。このノートは「増えるとできること」側。

## 想定運用 / なぜこのスコープか

- 1試合の分析はほかの記録アプリにもある（[試合詳細のグラフ化](./2026-09-27-idea-match-detail-charts.md) の競合調査）。
  **記録が増えるほど価値が上がるもの**は score 機能にしか無いので、ここを伸ばすのが差別化にも記録の動機にもなる（Assumption）。
- 記録する試合を人気で選ばない方針（2026-09-27）は変えない。そのうえで、動画がある試合の中から
  **すでに記録のある選手・大会の試合を優先すると機能が早く使える**（広く集めるより深く集める）。これは選び方の案で、未決定。

## わかっていること

### 記録の量（2026-09-27 実測、公開中の `public/data/beta-matches/matches/*.json`）

- 27試合・1,165本。選手43人、うち5試合以上が5人（上松11・黒坂8・上岡7・丸山6・植田5）、3試合以上が9人。
- ペア22組、うち3試合以上が4組、5試合以上が1組。
- 大会11（大会×年）、うち3試合以上が5つ（全日本シングルス2026が6、全日本選手権2025が5）。

### 増えるとできること（候補）

| 何が増えると | できること | いつできるか |
|---|---|---|
| 同じ選手の試合数 | **「いつもの範囲」との比較**: 試合詳細に「この試合の1stサーブ得点率は、この選手のいつもの範囲より高い」と出す。詳細ページと成長分析がつながる | 5人は今すぐ（5試合以上）。公開の許可がある選手に限る（ADR-004） |
| 同じ選手の試合数 | スタイルのプロフィール（レーダーチャート） | [プレースタイル](./2026-07-11-idea-player-style-profiling.md) の Phase 1 は着手可能 |
| 同じ組み合わせの対戦 | 「この2人の過去の対戦では、デュースを◯◯が取っている」 | 同じ対戦が2試合以上 |
| 総試合数 | **サイト全体との比較** | [成長のヒントの見せ方](./2026-08-04-idea-growth-hint-self-vs-population.md) の再検証条件（データが増えたら）。当時16試合・717本 → 今27試合・1,165本 |
| 総試合数 | 名場面・サイト記録がより特別になる（「記録済み100試合で最長」） | 増えるほど自然に効く |
| 1大会の試合数 | **大会単位の読み物**（「全日本シングルス2026の記録6試合では、サーブ側の得点率は◯%」）。大会インサイトやSNSに流せる | 5大会は今すぐ（3試合以上） |
| 総試合数（数百） | ソフトテニスそのもののデータ記事（「サーブ側は有利か」「ファイナルゲームで何が起きるか」）。検索流入にもなる | パイロット分析の再検証が前提 |

### 動機づけの見せ方（案）

`/matches` の上部などに「記録27試合。あと3試合で黒坂選手の『いつもの範囲』を出せます」のように、
**次に使える機能と、あと何試合かを出す**。運営自身の動機になり、見る人にも「データが育っている」ことが伝わる。

## 課題・未解決

- 各機能のしきい値（「いつもの範囲」は5試合でよいか、大会単位は3試合でよいか）は仮。統計の扱いなので実装前に確認が要る。
- 「いつもの範囲」を公開ページに出せるのは公開の許可がある選手だけ（ADR-004）。許可の範囲の確認。
- 「あと何試合」の表示を公開ページに出すか、運営向けだけにするか。
- サイト全体比較の再検証（split-half 安定性チェック）はまだ実行していない。

## 目指したい方向性
