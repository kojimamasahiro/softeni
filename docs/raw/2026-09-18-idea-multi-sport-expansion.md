# アイデア: 同じ仕組みを他の競技へ広げる

## 状況

Idea Backlog。**発散フェーズ**（2026-09-18 起票）。下地づくり（wiki の適用範囲の印）だけ着手済み。
対象競技・URL 構成・運用体制は未決。

## 目的

利益を増やす。固定費のほとんどが Claude の利用料で、サーバー費はほぼかからない。
仕組み（PDF 取り込み → 構造化 → 事実照合 → 静的ページ生成 → SEO）は競技に依存しない部分が多いので、
**追加費用はほぼ Claude の作業分だけで、広告の載るページ数を競技の数だけ増やせる**。
Claude の費用を「維持費」から「売り物を増やす投資」に変える、という位置づけ。

## ユーザーが興味を持った点

- 「なんでもいいから利益を増やす方法を考えて」→ 案を出したうえで
  「固定費はこのclaudeの費用が一番高くほとんどを占めている」「他に今までなかった別の角度からのアイデアはない？」
- 別角度の案（B-1〜B-5）のうち、このアイデア（B-2）について「B-2に関しても進めたい」。
- 「まずはA-1（wiki の圧縮）に合わせて他に適用しやすい形にしてほしい」
  → wiki を圧縮するついでに、他競技へ持ち出せる部分を見分けられる形にする、と解釈した（Assumption）。

## わかっていること（2026-09-18 時点）

- **データの形は競技に依存しない**: 大会（`TournamentIndexEntry`）→ 年度 → 種目（`categories[]`。
  `doubles` / `singles` / `team` × 性別 × 年代）→ 試合（`matches`）。
- **ソフトテニス固有の依存**:
  - `src/` と `lib/` に文字列「ソフトテニス」が **65ファイル・209か所**ある（title・description・FAQ 等）。
    他競技へ広げるなら、まず競技名を設定値に寄せる必要がある。
  - score 機能（ポイント単位の記録・成長分析・名場面検知）はソフトテニスのルール前提。展開対象から外すのが自然。
  - STリーグ、連盟（`federations.json`）、ランキングの配点（`data/ranking-config.json`）は競技ごとに作り直し。
- **学校スポーツの枠組みは共通**: インターハイ・全中・高校選抜・インカレは多くの部活競技にある。
  高校/中学/小学生/大学カテゴリ、進路（出身中学→高校→大学）、会期中 SEO はそのまま使える可能性が高い（Assumption）。
- wiki 35ページに初回の適用範囲の印を付けた: 汎用 10・学校スポーツ共通 5・ソフトテニス固有 7・混在 13
  （[docs/wiki/index.md](../wiki/index.md)）。ページ冒頭だけを見た判定なので Assumption。

## 課題・未解決

- **どの競技にするか**。候補の仮説: バドミントン（シングルス/ダブルス/団体で種目構成がほぼ同じ）、卓球、
  硬式テニス。**競合サイトの有無と検索需要は未調査**。次の一手はこの調査。
- **URL 構成**: 同一ドメインの別パス / 別ドメイン / 別リポジトリ。SEO（ドメイン評価の共有）と
  コード共有の手間がトレードオフ。決めるときは ADR。
- **データ入手**: その競技の大会結果が PDF で公開されているか、PDF の様式がどれだけ揃っているか（取り込み skill の再利用可否）。
- **運用量**: 大会期間中の日次更新が競技の数だけ増える。Claude の費用も増えるので、
  [ローカル LLM 代替](./2026-08-14-idea-local-llm-skill-replacement.md) や、決まった手順の作業を安いモデルで回す案とセットで考える。
- 「他に適用しやすい形」の解釈がユーザーの意図と合っているか（Assumption のまま）。

## 候補競技の調査（2026-09-18・ユーザー関心はピックルボール）

ユーザーの言葉: 「気になっているのはピックルボールではあるが、競技の需要・競合・データの手に入りやすさを総合判断したい」。

出典はすべて Web 検索と公式サイトの閲覧（2026-09-18 時点）。数値は各社の発表をそのまま引用したもので、
当方で検算していない（Assumption）。

### ピックルボール

- **需要（強い）**: 国内競技人口 **33万人**、前年（約4.5万人）から**約7倍**。潜在層1,189万人、認知率13.1%、
  テニス経験者の72.5%が関心（株式会社ピックルボールワン「日本のピックルボール市場調査2026」）。
  ソフトテニスの登録会員数（約40万人）に並ぶ規模まで1年で来ている。
- **競合（多い・資本が入っている）**: pickle-one.com（市場調査をPRTIMESで配信・大会情報）、pikura.app、
  randaall.com、pickle-times.com、pickleballnavi.jp、picklenavi.com、テニスベアのピックルボール面。
  いずれも「ルール・始め方・大会情報」の情報記事型。当サイトが得意な**結果アーカイブ型は手薄**だが、
  下記のとおり素材が無い。
- **データ入手性（悪い・ここが決定的）**:
  - 統括団体が分かれている（japanpickleball.org と pickleball-japan.org）。
    japanpickleball.org の「大会一覧」は**開催案内・要項の記事だけで、結果・ドローのページが見当たらない**
    （2026-09-18 に閲覧。一覧の最新は2026-06-16）。
  - 公式のレーティングは **DUPR**（世界共通・アプリ）。連盟は DUPR を推奨しており、
    **「選手の戦績を束ねる」層はすでに DUPR が持っている**。日本人ランキングを出す第三者サイトも既にある
    （ratings.pickleball-tools.com）。ソフトテニスに DUPR 相当が無いこととの最大の違い。
  - 高体連・中体連の枠組みが無い（授業・部活の導入事例は数校レベル）。
    **当サイトの強い面（学校ページ・都道府県ページ・進路・歴代・「{学校名} {大会名} {年}」のロングテール）が丸ごと使えない。**
- **判定**: 需要の伸びは本物だが、**この仕組みの強みが効かない**。いま作るなら結果アーカイブではなく
  情報記事型になり、それは既存の競合と同じ土俵で、当サイトの資産（PDF取り込み・事実照合・静的生成）を使わない。

### バドミントン

- 需要: 学校スポーツとして大きい（インターハイ・全中・選抜）。
- データ入手性（良い）: 全国高体連バドミントン専門部が結果を掲載。**BIRDSCORE（birdscore.live）が
  インターハイ・選抜の個人戦/学校対抗のドローと結果を HTML で公開**しており、PDF を読むより取り込みが軽い可能性がある。
- 競合（強い）: iezo.net が**「バドミントン部の強い高校ランキング（都道府県別）」を既に持っている**
  （当サイトが soft tennis で作った強豪校ランキングと同型）。zutto-sports・スポ速の速報型もいる。
- 判定: 仕組みはほぼそのまま使えるが、**当サイトの差別化点が先に埋まっている**面がある。参入するなら
  「選手個人の通算戦績・進路」など、まだ誰も束ねていない層に絞る必要がある（未調査）。

### 卓球

- データ入手性: インターハイの結果は公開されている。
- 競合（最も強い）: 卓球王国 WEB・卓球レポート（バタフライ）という専門メディアが、特設ページで
  ベスト8・準決勝レベルまで日次で書いている。加えて iezo・zutto-sports。
- 判定: メディアが厚く、後発の勝ち目が薄い。

### 硬式テニス

- **未調査**。ソフトテニスと選手・大会の構造が近く、候補としては残る。

## 総合判断（2026-09-18 時点の推奨）

**ピックルボールは「今は見送り、条件つきで監視」を推す。**

理由: この仕組みの利益は「結果PDF → 構造化 → 選手・学校の記録ページ → 固有名詞のロングテール検索」で出ている。
ピックルボールには (1) 束ねるべき公開結果が無く、(2) 戦績を束ねる役は DUPR が既に持ち、(3) 学校の枠組みが無い。
需要の伸びは当てはまるが、**伸びているのは「やってみたい人」であって「結果を調べたい人」ではない**（Assumption）。

監視する条件（どれかが起きたら再検討する）:

- 高体連・中体連・国体のいずれかがピックルボールを採用する
- 統括団体が大会結果・ドローを継続的に公開し始める（japanpickleball.org の大会ページに結果が付く）
- 日本の大会が DUPR 外の共通エントリー基盤に集約され、ドローが機械で読める形で出る

**先に確かめるべきは「他競技へ行くか」ではなく「どの層が空いているか」**。低コストの検証案:

1. ピックルボールで実際に検索されているのが情報系か結果系かを SERP で確認する（「ピックルボール 大会 結果」等の上位10件の型を数える）。
2. バドミントンで「選手名（高校生）」を SERP で引き、当サイトがソフトテニスで取れているような**個人の戦績ページが存在しないか**を数える。
   空いていれば、仕組みの移植先としてはバドミントンが最有力になる。
3. どちらも1〜2時間で終わり、コードは書かない。

## バドミントンの選手名 SERP 調査 と ソフトボールの下調べ（2026-09-18）

ユーザーの依頼: 「バドミントンの選手名SERP調査からやって」「個人ではなくチームになるがソフトボールも気になった」。

### 方法

- インターハイ2026（和歌山）個人戦の決勝ラウンド出場者を BIRDSCORE（`birdscore.live`）から取得し、
  そこから辿れる県協会PDF・全中PDFに載っている選手を加えて **9名** を Google で検索（非ログイン・`num=20&hl=ja`）。
- 上位層3名（全国優勝・準優勝クラス）、中間層3名（全国大会に出るが優勝経験なし）、県レベル3名。
- 標本が9件と小さいので「傾向の確認」まで。ソフトテニスで行った40件の無作為抽出とは水準が違う（Assumption）。

### 結果: バドミントンは「圏外」がひとつも無い

| 層 | 例 | SERP の中身 | 圏外 |
|---|---|---|---|
| 上位 | 萩原駿希（埼玉栄） | Wikipedia・時事・サンスポ・badspi・SMASH and NET.TV・日本協会公式YouTube | 0/3 |
| 中間 | 阿波芽衣咲、五十田敦晴、星野結衣 | **badspi の選手別タグページ**、朝日新聞・地方紙、公式YouTube、全中PDF、学校サイト | 0/3 |
| 県レベル | 平泉那紬、黒瀬和奏、小島羽奏 | **県協会（saibad）の大会結果PDFが1ページ目を占める**、学校の部活ページ、地方紙 | 0/3 |

ソフトテニスの実測（無作為40件で圏外72.5%、掲載時は全件3位以内）とは**正反対**。

読み取れること:

- **空白が無い**。ソフトテニスで当サイトが取れている「誰も答えていない選手名クエリ」に相当する層が、バドミントンには見当たらない。
- 競合の型が3つある: (1) **badspi（BADMINTON SPIRIT）が選手別タグページを持つ**＝当サイトの選手ページと同じ枠を既に押さえている、
  (2) **県協会がPDFを大量に公開**しており、そのPDF自体が名前クエリで上位に出る、
  (3) 日本バドミントン協会公式が試合動画（BIRD'S EYE）を大量に出している。
- 勝てるとすれば「PDFは読みにくい・1大会1枚で通算が見えない」を突く形（PDF群を選手単位に束ねる）。
  ただし**ソフトテニスのときのような順位の空白ではなく、既に順位が付いている相手からの奪取**になる。
- **費用の観点で逆行する**: 県協会PDFの量はソフトテニスより桁違いに多く、取り込みの作業量＝Claude の費用が増える。
  「ほぼ同じ費用でページを増やす」という B-2 の前提が崩れる。

データ入手性は良い（BIRDSCORE が全国大会のドロー・スコアを HTML で公開、県協会がPDF）。問題は需要側の空白の無さ。

### ソフトボール（チーム競技）

- **データ入手性: 良い**。日本ソフトボール協会がインターハイの**イニングスコア・バッテリー・長打を選手名つきの HTML** で公開
  （`softball.or.jp/game/h_school_girl/tournament2026/`）。1回戦から決勝まで。トーナメント表は別途。
  県協会（例: 岩手）も県総体の結果・記録を公開している。
- **競合: 専門メディアと既存のチームページがある**。
  - 虹色ソフトボール／虹色トピック（`nijiirosoftball.com`）が組合せ・速報・出場校まとめを継続。YouTube・Instagram も運用。
  - **Player!（`web.playerapp.tokyo`）が高校ソフトボールのチームページ（日程・結果・メンバー）を既に持っている**。
    当サイトの学校ページと同じ枠。
  - 「歴代優勝」は **Wikipedia と ソフトボールタイムズ**が押さえており、同サイトは**優勝校ランキング**まで出している
    （当サイトが高校ソフトテニスで作った強豪校ランキングと同型）。
  - zutto-sports・スポ速の速報型も当然いる。
- **面の数が少ない**: チーム競技なので実体は「学校」中心で、選手個人のロングテールが立ちにくい
  （公式記録に名前が出るのは投手・捕手・長打を打った選手だけ）。広告の載るページ数はソフトテニスより小さくなる。

### この2競技を見ての結論（2026-09-18）

**ソフトテニスで効いている条件が、この2競技には揃っていない。**当サイトが成立したのは次の3つが重なったからだと整理できる:

1. 選手名クエリに**空白**がある（無作為40件で72.5%が圏外）
2. 一次情報が**PDFだけ**で、選手単位に束ねている所が無い
3. **専門メディアが薄い**（ソフトテニスマガジンはあるが選手別ページを持たない）

- バドミントン: 1がゼロ、3も×（badspi）。データは良いが入る隙が無い。
- ソフトボール: 2は△（HTMLで良質）、3は×（虹色・ソフトボールタイムズ・Player!）。面の数も小さい。

**次に競技を選ぶなら、上の3条件をチェックリストとして先に当てるべき**（競技名から入らない）。
確認は1競技あたり30分程度: 選手名（または学校名）を5〜10件 SERP で引いて空白率を見る → 一次情報の形式を見る → 専門メディアの有無を見る。
