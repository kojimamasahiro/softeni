# 全国中学校ソフトテニス大会 2018年度（第49回）エントリー取り込み

日付: 2026-08-30
入力: `2018_C10_40.pdf`（ユーザー提供、8ページ）
出力: `tools/secondaryschool-championship/2018/{doubles,team}-none-{boys,girls}.initialPlayers.json`
前提: 直前に取り込んだ2019年度（[2026-08-30-zenchu-2019-scanned-pdf-entries-import.md](2026-08-30-zenchu-2019-scanned-pdf-entries-import.md)）

## 入力の性質（2019年度とは別物）

- **テキストレイヤーあり**（p1で829文字）。2019年度がスキャン画像だったので同じ経路を
  想定していたが、**同じ大会でも年度で組版系統が変わる**。まず `pdfplumber` で
  文字数を数えるところから始めること。
- ページ構成も違う。**8ページで、団体戦はp7/p8**:
  p1/p2=男子個人戦1/2、p3/p4=女子個人戦1/2、**p5=結果一覧（男子個人）、
  p6=結果一覧（女子個人）**、p7=男子団体戦、p8=女子団体戦。
  2019年度の「1,2男子個人 / 3,4女子個人 / 5男子団体 / 6女子団体」で当てにいくと
  結果一覧ページを団体戦と取り違える。
- 件数は2019年度と同じ（個人 男女とも64ペア、団体 男女とも25校）。
- p8（女子団体）と各ページ見出しは**同じ文字が二重に印字されている**
  （`山山陽陽女女子子`）。座標が完全に一致するので `(top, x0, text)` で重複除去する。

## 抽出方法

`scripts/pdf-to-players/extract_tournament.py`（`zenchu` プロファイル）を素で当てると、
**3文字の都道府県（北海道・和歌山・鹿児島・神奈川）だけが列の端で切れて欠落した**
（id 9/12/19/26/28 が `prefecture: None`）。`--gap 10` で「ブロック・県」列の分裂は
直せたが、切れは列検出の投票が決めた列幅に由来するのでCLIオプションでは直らなかった。

テキスト層が素直（1行1情報、姓と名の間に全角空白）なので、**括弧のX座標を
ページごとに検出して列バンドを決める**自前パーサを書いた
（`scripts/pdf/zenchu_2018_entries.py`。座標定数は持たず、すべて `（` `）` の実測から導出）。
再実行: `python3 scripts/pdf/zenchu_2018_entries.py 2018_C10_40.pdf --out tools/secondaryschool-championship/2018`

- 左右のブロックは `（` のX座標クラスタ2つで決まる。
  氏名バンド = `（`−72〜−3、所属/県バンド = `（`+3〜`）`−1、
  番号バンド = 左が `（`−95〜−73、右が `）`+6〜+40。
- **左ブロックのX座標は男子ページと女子ページで約10pt違う**（p1は氏名82-128・
  括弧138/224、p3は氏名72-119・括弧129/218）。ページごとに検出しないと、
  女子ページで括弧が氏名バンドに、氏名が番号バンドに食い込んで件数が40件に化ける。
- 姓名分割は**全角空白で確定**する（`荒川　裕貴`）。座標計算は不要。
  唯一の例外が `北川アンナ璃咲`（7文字で欄が埋まり空白が無い）で、
  `data/players/index.json` に `北川 / アンナ璃咲` があるので確定した。
- 団体戦は「チーム名の行」＋「(ブロック・県)の行」の2行で1エントリー。番号は全角数字。

## フォントに無い文字（豆腐 □）の解決

このPDFは**一部の字をフォントが持っておらず、紙面に □ で印字されている**。
`pdfplumber` では私用領域 U+E003 として取れる（ページごとに別のフォントサブセットだが
コードポイントは同じ）。全6箇所:

| 場所 | 紙面 | 確定 | 根拠 |
|---|---|---|---|
| p1 男子個人12 | `□浦 壱経` | 辻浦 壱経 | `data/players/index.json` に実在 |
| p2 男子個人34 | `□ 歩夢`（清武） | 辻 歩夢 | 同上 |
| p3 女子個人10 | `□ 紗弥香`（昇陽） | 辻 紗弥香 | 同上 |
| p3 女子個人27 | `□ 愛`（光が丘第二） | 辻 愛 | 同上 |
| p4 女子個人55 | `□田 萌乃佳`（小城） | 辻田 萌乃佳 | 同上 |
| p8 女子団体10 | `□妻`（東海・愛知） | **逢妻**（Assumption） | 下記 |

- 個人戦の5件はすべて **辻**（二点しんにょうの異体字 U+FA53 と思われる）。
  `data/players/index.json`（18543名）に「姓の一部が欠けた形」で検索をかけると
  一意に当たる。**リポジトリの既存選手名簿は、豆腐文字を復元する辞書として使える。**
- 女子団体10 の `□妻` は選手名簿では解けない（学校名）。`data/teams/teams.json` にも
  愛知県で「妻」を含む中学校は無い。Web検索で
  [ソフトテニスマガジン・ポータルの第49回全中女子団体の記事](https://www.softtennis-mag.com/result/21207/)
  に「逢妻中学校（愛知県）が5位」とあり、**逢妻**（愛知県刈谷市立逢妻中学校）と判断した。
  `逢` も `辻` と同じ**しんにょう系の字**で、このPDFのフォントが落とす字の傾向と一致する。
  ただし出典は外部Webなので **Assumption** 扱い。誤りならここだけ直せばよい。

## 検証

- id連番: 4ファイルとも重複・欠番ゼロ（64/64/25/25）。47都道府県辞書に全件一致。
  空欄・2人目欠落・姓4文字以上ゼロ。同姓同名の重複ゼロ。
- **同一PDF内の結果一覧ページ（p5/p6）との突き合わせが最強の検証になった。**
  p1-p4（ブラケット表）から作ったエントリーと、p5/p6（1行1試合の結果一覧）を
  独立にパースして照合したところ、**男女とも64/64件が姓名・学校・都道府県まで完全一致、
  不一致ゼロ**。組版が違う2つの表が同じ内容を持つので、列の取り違えがあれば必ず出る。
  実装上の注意: 結果一覧はスコア（`④－1`）が番号に食い込むので、
  先に `[④0-9]－[④0-9]` を除去してから正規表現をかける。
- **2019年度データとの「姓+名」完全一致照合**: 男子18/128、女子28/128が一致。
  全中は3年で入れ替わるので、隣接年度でこの当たり方は妥当（2019年の照合が
  2021年度参照で男子2件しか当たらなかったのと対照的で、**参照は1年差が効く**）。
  矛盾する一致はゼロ。
- **学校名の表記ゆれを検出**: 青木吟斗・森煌大（三重）が2018年は `松阪西`、
  2019年は `西`。同一ペア・同一県なので、どちらも三重県松阪市の同じ学校とみられる。
  **各年度は紙面の印字どおりにした**（寄せていない）。
- 既知校照合: 男子個人29/58・女子個人36/53・男子団体16/25・女子団体16/25が
  2019年度＋既存全中データの既知校と一致。県の食い違いは `三和`（長崎/福島）と
  `山辺`（栃木/山形）の2件で、いずれも同名の別校（紙面にブロック名が明記されている）。
