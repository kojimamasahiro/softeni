## この年度で新しかったこと（スクリプトを3点直した）

### 1. 不戦（`R`）— 見出しの本数が数字でない

- 男子 p28 `28 浜田 ③ － R 昌平 30`（2回戦）、女子 p18 `14 松商学園 ③ － R 名護 15`（1回戦）。
- **ペアも本数もゲームも何も印字されない**（「－」の行だけ）。`score_of('R')` が None を返して
  `TypeError` で落ちていた。見出しの本数を None 許容にした。
- **元資料にオーダーが無いので `matches` は持たない**（ADR-020「持つのは元資料にある試合だけ」）。
  スキップした試合は毎回表示する。`walkover` にはしなかった——ADR-020 の `walkover` は
  「出した側のペアが分かる」前提だが、ここは**どちらのペアも印字されていない**。
- details 側はどちらも既に `retired: true` / 3-0 で入っていた。チャート（p15）の `R` と一致する
  （`lib/bracketDrawing.ts` が敗者の本数に "R" を付ける表記）。

### 2. 打ち切り時点で進行中だったゲームが印字される

男子 p34 の `3 － 0` のように、**どちらにも丸数字が無いゲーム行**がある。打ち切りの瞬間に
進行中だったゲームで、ADR-020 は決着したゲームだけを持つので `games` に入れない。
落とした行は毎回表示する（黙って捨てない）。丸数字の読み落としなら本数の数え直しで止まる。

- 実測: **2022 男子5件・女子3件。2023・2024 は0件**（ゲームを落とす変更の回帰は無い）。

### 3. 対戦の状態は「ゲームの有無」で決めてはいけない

2 の変更で `games` が空になる対戦が出た結果、**本数 `0 － 0` だけが残って `not_played` に
なってしまい**、`check:team-match-details` が「not_played なのに本数がある」で鳴った
（男子 match-35・女子 match-40）。

- **本数・決着したゲーム・進行中のゲームのどれかが印字されていれば、その対戦は始まっている**
  （`started`）。始まっていて勝者がいなければ `unfinished`。0-0 は「未実施」ではなく
  「打ち切り時点の本数」で、ADR-020 の `unfinished` の定義どおり。
- 検査が形の矛盾として捕まえてくれた。**status を導出で決めている箇所は、導出元が変わると壊れる**。

## 出典の誤記2件（直さず残した）

**男子 準々決勝 和歌山北(15)-とわの森三愛(19) 第2対戦**（p36）の第3・第4ゲーム
`3 － ⑦` と `2 － ⑤`。どちらも4点先取・デュース2点差のどちらにも当てはまらず、
2-0 / 2-1 の局面なのでファイナルゲームでもない。

- 座標を出して**列の取り違えでないことを確認**（左ポイント x=274.1・右ポイント x=321.2、
  本数の `3`/`④` は x=227.0/368.5 の別列）。テキスト層に `⑦` `⑤` がそのまま入っている。
- 本数（3-4）は丸数字の数と一致するので**対戦の勝敗には影響しない**。
- 2023 女子の `4 － ⑦` と同じ方針で**印字どおり残した**（正しい値が決められない）。

これで出典の誤記は**3件**（2023 女子1・2022 男子2）。いずれも「成立しない得点」で、
**本数の数え直しでは見つからない**（丸数字の有無は合っている）。ゲームの成立検査が効いた実例。

## 疑わしい既存データ1件（変えていない・ユーザー判断）
