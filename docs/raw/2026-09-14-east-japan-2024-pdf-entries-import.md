## 様式

- ブラケット表の左右2ブロック。1エントリー＝氏名2行＋中央行（エントリー番号・`(`・`)`）。
- 氏名は**全角スペースで埋めた7文字固定のグリッド**（`堀　　　大　晟` / `安　重　伸太郎` / `三ツ木　千花子`）。
  **先頭3文字＝姓、残り4文字＝名**で全件割れた（4文字目は常に空白）。天皇杯2016-2019の7スロットと同じ考え方。
- 都道府県・所属は、ペアで共通なら中央行に1つ、別々なら各氏名行に1つずつ入る
  （男子1 `東京 稲門クラブ` / `福井 福井県庁`、女子32 `千葉`/`学連`）。
  小さい字の所属は縦位置が中央寄りにずれることがある（男子23）ので、
  「中央行と片方の選手行に1つずつ」ならもう片方の選手に割り当てる。
- 都道府県欄は略称（`東京` `神奈川`）と `学連`。

## 抽出方法

`scripts/pdf-to-players/extract_tournament.py` は左ブロックは正しく取れたが、
**右ブロックで氏名グリッドと都道府県列が融合**して姓名・所属が崩れた（p5 右の23件中22件）。
そこで**このPDF専用の使い捨てスクリプト**（リポジトリには置いていない）で、
各ブロックの `(` `)` のx座標の最頻値を基準に「番号 / 氏名 / 都道府県 / 所属」の範囲を決めて抽出した。
