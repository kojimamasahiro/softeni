## 同じ大会でも年度で組版系統がまったく違う（エントリー取り込みと同じ）

| | ページ構成 | テキスト層 | スコアの持ち方 |
|---|---|---|---|
| 2018 | p1-4個人ドロー / **p5-6結果一覧** / p7-8団体 | あり | 勝者=丸数字④／②③、敗者=裸の数字 |
| 2019 | p1-4個人ドロー / p5-6団体 | **無し（200dpiカラーJPEG）** | 赤インクで印字。団体は**敗者のみ** |

## 2018年度: 結果一覧ページ（p5/p6）が本体

p5/p6 は「一回戦」等の見出し＋**1行1試合**で、
`1 高橋海斗・黒坂卓矢ペア（埼玉・芝東） ④－0 2 松本雅久・髙優太ペア（広島・広中央）`
の形。エントリー番号もスコアも入っているので、ブラケットの幾何を一切追わずに63試合が出る。
男女とも 1回戦32・2回戦16・3回戦8・準々決勝4・準決勝2・決勝1 = 63試合。

- 空白を除去して1つの正規表現で解く。スコアは必ず1文字（勝者④／敗者0-3）なので
  `）<敗者スコア>－<勝者スコア><次の番号>` の切れ目が一意に決まる。
- `R`（棄権）は男女とも1件も無い（ページ全体の文字集合を数えて確認）。

### 検算1: エントリー番号↔氏名（126件×2）

結果一覧の氏名・所属・県が `tools/` のステージングと一致することを全試合の両側で確認。
不一致は**フォント欠落の豆腐文字（U+E003＝辻）5箇所だけ**で、これはエントリー取り込み時に
既に判明していたもの（男12・男34・女10・女27・女55）。番号のずれはゼロ。

### 検算2: ブラケットページ（p1-p4）との突き合わせ ― 248字が全一致

p1-p4 にも同じスコアが印字されている。**結果一覧とは独立に**読んで照合したところ、
4ページ×62字 = **248字すべて一致、不一致ゼロ**。

読み方（`verify_bracket_2018`）:

- 左1-16／右17-32が**同じ行yを共有する鏡像配置**。行yはエントリー番号の文字から取る。
- ラウンドrのブロックのライン y は `(そのブロックの上端行y + 下端行y)/2`。
  スコアはそのラインの **上側の競技者は -4.8pt、下側は +4.8pt** に置かれる。
- **x座標（ラウンド列）は使わない。** 準決勝（＝ページ最終戦）のスコアだけが
  3回戦の列に置かれていて、素直に列で切ると壊れる（skillの既知の罠が実際に起きた）。
  代わりに 62スロットと62文字を |Δy| の**全体最近傍マッチング**で割り当てる。
  残差の最大は 15.4pt（p4右の1回戦で1字だけ +15.4 にずれて印字されている）で、
  行ピッチ38pt の半分より十分小さい。

## 2018年度 団体戦（p7/p8）

25校（左1-13・右14-25）。**不戦勝は 1・8・13 と 14・19・20・25**で、
1回戦の組は左 (2,3)(4,5)(6,7)(9,10)(11,12)、右 (15,16)(17,18)(21,22)(23,24)。
**2019年度もまったく同じ席順**だった（席順が年度をまたいで同じなのは、
読み取りが正しいことの傍証になる）。

- 1回戦の列（最も外側）のスコア字は上側が -8.4pt・下側が +5.3pt にあるので、
  **どの隣接2行が対戦したか**がここから決まる。あとは隣どうしを束ねる二分木。
- ユニットのラインは入力2本の中点。ここでも全体最近傍マッチング（残差最大 11.2pt）。
- 決勝のスコアは準々決勝の列に置かれる（個人戦と同じ罠）。座標を使わないので影響なし。
- 優勝は **清明学園（東京）/ 山陽女子（岡山）** で、紙面下部の「優勝 …」の印字と一致。

## 2019年度: スキャン画像を色で読む

テキスト層が無く `pdfplumber` の文字数は6ページとも0。300dpiでレンダリング（2480×3505）し、
`(R+G+B)<620` を暗部、そのうち `R-G>50 かつ R-B>50` を**赤**として分離する。
赤は紙面のブラケット帯（x 972-1500）にきれいに収まる。

### 水平線分＝ユニットのライン

`binary_opening`（1×30）で水平線だけ残して連結成分を取ると、
個人戦ページは**左右それぞれ31本**（行16＋8＋4＋2＋1）がきれいに出る。
**ユニットのライン y は入力2本の中点と 1px 以内で一致する**（天皇杯で踏んだ
「中点と仮定するとずれる」罠は、この様式では起きない）。
31本は行ピッチの半分（78.5px）ちょうどの等間隔になるので、行は偶数indexで取れる。

### 勝者は「合流点の縦線の色」で決まる ― 水平線の色ではない

最初、勝ち上がりの太い赤線を見て「赤い水平線＝勝者」と読んだが**これは誤り**。
赤は「**1つでも勝った競技者の経路**」を最後まで塗るので、2回戦で負けた競技者の
2回戦の区間も赤い。実際 1回戦の判定は正しく出るのに2回戦以降は両方とも赤率0.9超になった。

正しくは**合流点の縦線**を見る。入力ラインから出力ラインまでの縦線は、
**勝者側だけが赤く、敗者側は黒**。個人戦p1の15試合で 勝者側 0.81-0.99 / 敗者側 **0.00** と
完全に分離した。

### 丸数字を読まずに済む（が、独立検算として使える）

勝者は丸数字④、敗者は裸の数字。切り出した bbox の幅が
**勝者 22-32px / 敗者 5-16px** に完全に分離するので、
「合流の色から出した勝者」と「丸数字が付いている側」が一致するかを**全124試合で assert** している
（個人戦4ページ、不一致ゼロ）。

### 敗者の数字の値だけは辞書で持つ

値の読み取りだけは画像処理では閉じない。124字（個人戦）＋48字（団体戦）＋2字（決勝の再掲枠）を
切り出し、28×28に正規化（**アスペクト比を保ってパディング**。引き伸ばすと細い「1」が
黒い塊になって読めなくなる）して階層クラスタリングしたところ、
**4クラス（44/35/21/24）にきれいに割れた**。代表字を目視で 1/2/3/0 と同定し、
最近傍セントロイドで全字を再分類して外れた8字だけを拡大して個別確認した。
結果、クラスタに紛れていた例外は4字（b13=0, b44=3, g13=3, g14=3）。
確定した対応は `scripts/pdf/zenchu-2019-score-glyphs.json`（"p<ページ>:<x0>:<y0>" → 数字）に保存。

> **教訓**: コンタクトシートを目視で通し読みすると**行内で位置がずれて写経ミスをする**。
> 実際に girls 行3で5字ぶんずれて読んでいた。クラスタリング（機械）を正、目視は
> 「クラスタ代表の同定」と「外れ値の確認」だけに使うのが安全。

### 団体戦（p5/p6）は敗者の本数しか印字されない

赤の小さな連結成分がちょうど24個＝24試合ぶんしか無い。値は 0 か 1 で、
**幅 20-22px が「0」・9-12px が「1」**に完全に分離する（目視とも一致）。

不戦勝の行は1回戦の列を素通りするので、**線分の長さが2列ぶん（>180px）**になる。
これで不戦勝が機械的に判定でき、1回戦の組（隣接する非不戦勝どうし）も決まる。
線分のx0からラウンド列（105px間隔）を割り出し、列ごとにy順で木に対応づける。

### 決勝はページ下部の再掲枠から

個人戦の各ページ下部に、そのページの勝者の氏名と**決勝の本数**が印字される。
丸数字なら優勝（p1=男子、p4=女子）。再掲枠の氏名がエントリー番号から復元した
ページ勝者と一致することを4ページとも目視で確認した:

| | ページ勝者 | 再掲枠の氏名 |
|---|---|---|
| p1 | 12 | 野口 快・黒坂 卓矢（芝東）④ |
| p2 | 64 | 相澤 波月・赤津 優希（芝東）0 |
| p3 | 27 | 西村 麻央・大畑 璃実（下山門）0 |
| p4 | 41 | 岩元 望美・岩元 愛美（榛原）④ |

男子決勝は**芝東どうし**（12 対 64、4-0）。女子は 41 が 27 に 4-0。

## 未確定として残した仮定: 2019年度 団体戦の勝者の本数

2019の団体戦は敗者の本数しか印字されないため、

- 敗者1本 → 勝者は必ず2本（確定）
- **敗者0本 → 勝者が2本か3本か決まらない**（男女それぞれ10試合）

既存データを調べると強い規則性がある:

| ラウンド | 出現するスコア | 意味 |
|---|---|---|
| 1回戦・2回戦 | (3,0) と (2,1) のみ | 3試合すべて消化 |
| 準々決勝以降 | (2,0) と (2,1) のみ | 2勝先取 |

- 2018年度（同じ大会・両方印字あり）は**48試合すべてこの規則どおり**。
- 2021-2026年度の288試合では例外6件（98%適合）。例外はすべて 1・2回戦の (2,0) が5件と
  2021女子1回戦の (3,1) が1件。準々決勝以降に (3,0) が出た例は**ゼロ**。

ユーザー承認のうえ、この規則を当てた（`team_win_score()`）。**Assumption**。
実際に影響するのは 1・2回戦の 7試合×男女＝**14試合**で、
準々決勝以降の3試合×男女は規則の例外が全年度ゼロなので実質確定に近い。

## wiki の記述の誤り（実装と照合して修正）

`docs/wiki/data-import.md` に

> `data/tournaments/information/<大会>.json` に年度の項目が無いと公開ページに出ない
> （年度一覧は information から作られる）

とあるが、**実装はそうなっていない**。`lib/tournamentHelpers.server.ts` の
`getAllAvailableYears()` は information の年度と `loadDetailYears()`（`data/tournaments/details/<大会>/`
のディレクトリ名）の**和集合**を返す。種目ページの `getStaticPaths` も
`data/tournaments/details` を走査して作られており、information を見ていない。
したがって details を置けば年度ページは公開される。information が無いときに
欠けるのは `yearInfo`（会場・日程・label）だけ。wiki 側を訂正した。

## Compile Log（2026-09-03）

反映先: [docs/wiki/data-import.md](../wiki/data-import.md)（`zenchu_results.py` の節を新設、
および information に関する誤記の訂正）。

**取り込んだもの**

- スキャンPDF（テキスト層なし）から**結果**を読む経路が成立すること、およびその前提
  （赤インクの色分離／水平線分の連結成分／中点でラインが当たること）。
  skill が「別物の作業・要ユーザー確認」としていた領域なので、次に別大会で当たる人に効く。
- **勝者は合流点の縦線の色で決まる。水平線の色ではない**（赤は「1つでも勝った経路」を
  最後まで塗る）。これは他大会の色付きスキャンでも同じ罠になる。
- 丸数字/裸の数字を bbox の幅で分離して、色から出した勝者と突き合わせる検算。
- グリフ値の同定は**クラスタリングを正・目視は代表と外れ値のみ**にすること
  （コンタクトシートの通し読みで実際に写経ミスをした）。正規化時に
  アスペクト比を保つ必要があることも含む。
- 不戦勝を「線分が2列ぶんの長さ」で機械判定する手（不戦勝を含むブラケット全般に効く）。
- 全中団体戦のスコア規則（1・2回戦=3試合消化／準々決勝以降=2勝先取）と、その適合率。
  勝者スコアが印字されない年度を補完する根拠として再利用できる。
- 「結果一覧ページがある年度はそれが本体、ブラケットは検算に回す」という優先順位。
- information と公開の関係の訂正（実装が正）。

**意図的に除外したもの**

- 座標の実測値（行ピッチ157px、ラウンド列105px間隔、スコアのオフセット -8.4/+5.3pt 等）
  … このPDF専用。wikiは既に「年度ごとに実測し直す」方針。raw に残す。
- 優勝8件の一覧・試合数の内訳・決勝が芝東どうしだったこと … その年度限りの事実。
- 豆腐文字5箇所の内訳 … エントリー取り込みの raw に既にあり、
  wiki にも一般則（`data/players/index.json` で復元）として記載済み。
- クラスタに紛れた例外4字（b13/b44/g13/g14）の識別子 … 一度きりの作業ログ。
- 2018と2019で団体戦の席順が同一だったこと … 傍証として使っただけで、
  次の年度に一般化できる保証がない。
- `normalize-team-names.mjs` が既存インサイト本文の旧名（`清明学園` 等）を警告する件
  … 本取り込み以前から存在する状態で（`check-tournament-insights` は通る）、
  この作業とは独立の課題。切り出すなら別ノート。
