# 開催中の大会を既存ページで受ける（インターハイ2026・会期中SEO）

## 状況

**2026-08-07: `npm run build` 実機確認済み・問題なし。2026-08-15: GSC第1回チェック実施——インデックス・カニバリ（seo.md #3/#7/#10）は問題なし、強豪/ランキング系クエリは維持〜向上、ヘッドクエリ「ソフトテニス 高校」は順位悪化（詳細は[raw/2026-08-15-m4-gsc-review.md](./2026-08-15-m4-gsc-review.md)）。次回は2026年9月末の平常期チェック（[検証ランブック](../wiki/highschool-seo-m4-verification.md)参照）。**

2026-08-01 実装。インターハイ2026 の会期中（2026-07-31〜08-07、京都府）に、
「残り6日で刈り取れるものを刈る」ことを目的に実施した施策の記録。

## 出発点（ユーザーの問題意識）

> インターハイが開催されているからSEOで取りたいが、レッドオーシャンで厳しい。
> 唯一拾えているのが `/highschool/tournaments/championship/` で、「歴代」といったワードの組み合わせ。
> とりあえず、まだ少しインターハイが続くからこれをできるだけ刈り取りたい。

## わかっていたこと（着手前の実測）

会期中にもかかわらず、唯一順位が付いているハブページが**訪問者を大会公式サイトへ逃がしていた**。
2026-08-01 時点の本番 HTML を確認して判明した具体的な状態:

- title: 「…歴代優勝校・結果一覧｜2026年大会の**開催予定**（2021〜2025年）」
- 本文: 「結果が確定し次第、本ページの『年度別の記録』に追加します。最新情報は**大会公式サイト**をご確認ください」
- 収録年度: 2021〜2025年（2026 がコンテンツ上どこにも無い）
- 2026年度別結果ページ（4種目）への内部リンクが**ゼロ**
- 「最終更新: 2026年8月7日」と**未来日**を表示（`next-sitemap.config.js` の
  `clampToBuildDate` は sitemap 側だけを直しており、ページ表示側は未対応だった）

一方で、在庫（データ）は既に投入済みだった:

- 出場 244校・47都道府県・全726エントリー（男女ダブルス316/314ペア、男女団体48校ずつ）
- 女子ダブルスは 3回戦まで結果反映済み（282試合中250試合）

## 決定と理由

**新規URLは作らない。** 残り6日ではインデックスが間に合わないため、
効くのは「既にインデックスされているページの更新」だけ。3層すべて既存URLで受ける。

`seo.md` #11 で決めた「速報クエリでは farm と正面勝負しない／学校名・選手名 × 大会名の
ロングテールで拾う」方針の範囲内であり、ADR は起票しない。

| | 対象 | 狙うクエリ |
|---|---|---|
| P0 | `/highschool/tournaments/championship/` 1枚（唯一の順位保持ページ） | インターハイ2026 結果 / 途中経過 / 組み合わせ |
| P1 | 都道府県ページ 94枚（47県×男女、インデックス済み） | {県名} インターハイ 2026 |
| P2 | 学校ページ（インデックス済み） | {学校名} インターハイ 2026 |

## 実装

新規: `lib/highschoolInProgress.ts`（都道府県別・学校別の索引。モジュールスコープで1度だけ構築）

- `lib/highschoolNationalTournaments.ts`
  - `InProgressEdition` / `InProgressCategory` を追加。**上位入賞（優勝〜ベスト4）が
    未確定でも**、出場規模・進捗・現在の勝ち上がり・対戦表リンクを返す。
    完了判定は既存の `computeResultCoverage`（ADR-007）を再利用し、
    `in_progress` / `not_recorded` のみ対象にする。
  - `lastModified` を `clampToBuildDate` でビルド日に頭打ち（未来日を出さない）。
  - `getSchoolResolver` / `getPlayerResolver` を export（新モジュールから再利用）。
- ハブページ: 開催中ブロックを最上部に追加。title/description/h1 を開催中インテントへ切替。
  「開催予定」ブロックからは開催中の年を除外（同じ年を二重に出さない）。
- 都道府県ページ / 学校ページ: 開催中ブロック＋FAQ＋title/description を追加。

## 判断が入ったところ

- **「途中経過」と名乗るのは結果が1件でも入っているときだけ**。まだなら「組み合わせ」と表記する。
  未確定を確定のように見せない（ADR-007 の開示方針と同じ）。
- **現在勝ち上がり中の名前を出す上限は 32**（`ALIVE_LEADERS_MAX`）。序盤に316ペアを羅列しても
  情報にならず、テンプレ的な水増しに見えるため。ベスト32以降で名前が出る。
- `yearRange`（歴代）と `coverageRange`（収録年度）を分離した。FAQ で「歴代の結果」と
  名乗る箇所に、優勝者未確定の 2026 を混ぜないため。

## 検算（2026-08-01）

このサンドボックスはメモリ 3GB で `next build` が OOM になるため、
SSR レンダリング（`react-dom/server`）と索引の全件走査で代替した。

- 都道府県ページ: **94 / 94** に開催中ブロックが出る
- 学校ページ: **243 / 633** に開催中ブロックが出る
- 学校ページが存在しない出場校 43件はブロック内でリンク無しのテキスト表示（デッドリンク無し）
- ハブの `最終更新` 表示が `2026年8月1日`（未来日 2026-08-07 が解消）
- japan-cup / senbatsu は `inProgress: null` で従来表示のまま（回帰なし）

**残: 実機での `npm run build`。** 上記の理由でサンドボックスでは通せていない。

  現状は別校として扱われるため、学校ページに紐づかない。
