# 大会インサイト本文の機械照合（scripts/verify-story-text.mjs）

## 状況

実装済み（2026-08-01）。`npm run story:verify` で実行できる。
[過去の事実ベース5分類ストーリー](2026-08-01-idea-news-fact-based-story-categories.md) 5.
で「必須」と位置づけた一次フィルタ。

## なぜ必須なのか

試作YAML（LLMに書かせて人が確認したもの）を実データと突合したところ、**事実誤りが3件**
見つかった。船水颯人の成績を「2023年ベスト8、2024年優勝」としていたが実際は
2022年優勝・2023年準優勝・2024年優勝。上松俊貴の連続年数を3年としていたが実際は4年。

いずれも**もっともらしく、人のレビューでは素通りする**性質のもの。ADR-005の
「事実のみ・推測を含めない」を人手の注意力に依存させないために、機械で落とす。

## 設計

### 照合先は生データ（YAMLではない）

`data/tournaments/details/<tournamentId>/<year>/<categoryId>.json` を直接読む。
ストーリーYAMLを正とすると、**YAML生成スクリプト自体のバグを検出できない**。
生データに当てれば、生成スクリプトのバグとLLMの捏造を同じ仕組みで捕まえられる。

### 検証する主張の種類

| 種類 | 例 | 判定 |
|---|---|---|
| 年×成績 | 「2024年優勝」「2024年は準優勝」 | 当該年の実成績と比較 |
| 連続年数 | 「4年連続ベスト8以上」「5年連続出場」「3年連続で決勝」 | 水準語から必要成績を決めて連続年数を算出 |
| 連覇 | 「3連覇」 | 連続優勝回数と比較 |
| スコア | 「5-4」 | 該当スコアの試合の実在を確認し、一致した試合を出力に添える |
| 固有名詞 | 選手名・学校名 | エントリー全体に実在するか |
| 年 | 「2019年」 | 掲載範囲内か |

### 3値で報告する

- `OK` — 実データと一致
- `ERROR`（MISMATCH）— 実データと食い違う。**修正が必要**
- `WARN`（UNVERIFIED）— 照合できなかった。掲載範囲外の事実か捏造かを人が判断する

**「判定できないものを ERROR にしない」ことを設計上の原則にした**。正しい文まで不一致として
弾くとチェック自体が信用されなくなり、警告を読み飛ばす運用に堕ちるため。具体的には
「N年連続」の水準（何の連続か）が文から読み取れない場合、ベスト8以上と仮定して照合するが、
外れても `ERROR` ではなく `WARN` に落とす。

## 実装中に見つかった落とし穴

1. **「ベスト」という所属が実データに実在する**。素朴に部分文字列で固有名詞を探すと
   「ベスト8」がこの所属にヒットして主語を乗っ取る。→ 固有名詞を探す前に `ベスト\d+` を伏せる。
2. **実在確認をベスト8以上の集計に対して行うと誤警告が出る**。上記「ベスト」は一度も
   ベスト8に入っていないため「掲載データに見つからない」と報告された。→ エントリー全体
   （`participants`）に対して確認する。
3. **助詞を挟む書き方の取りこぼしが実際の誤りを見逃した**。「2025年も優勝しました」（実際は
   ベスト4）が `(\d{4})年(優勝|...)` にマッチせず素通りした。→ 年と成績の間の助詞を許容する。
4. **1文に複数の主語が出る**（ダブルスのペア）。候補それぞれで照合し、1人でも一致すれば OK、
   全員外れたときだけ不一致とする。

## 既知の限界

- **スコアは「その数字の試合が登場人物の関わる形で実在するか」までしか見ない**。
  どの試合を指しているかは文脈依存で機械判定できないため、一致した試合（年・ラウンド・
  対戦カード）を出力に添えて人が目視確認する前提にしている。照合ではなく手掛かりの提示。
- **ベスト8未満の成績は検証できない**。「N回戦敗退」はドロー規模に依存し年度間で比較できない
  ため、そもそも `rankScore` が `null` を返す（アイデア側の足切り根拠と同じ理由）。
  よって「2023年5回戦敗退」のような記述は素通りする。
- **主語の推定は素朴**（文中に現れた固有名詞を持ち回るだけ。形態素解析なし）。
  誤りを見逃すより過剰に報告する方に倒してある。
- **1回の実行で1大会×1種目のみ**。複数種目を束ねた記事は種目ごとに実行する。

## 検証結果

| テスト | 期待 | 結果 |
|---|---|---|
| 試作YAMLの既知の誤り2件 | ERROR | 検出 |
| 「尽誠学園4連覇」「2025年も優勝」（実際は3連覇・ベスト4） | ERROR | 検出 |
| 「東北 3年連続で決勝」（実際は2年） | ERROR | 検出 |
| 「岡崎城西 6年連続出場」（実際は5年） | ERROR | 検出 |
| 掲載範囲外の「2019年」 | WARN | 検出 |
| SNS投稿案5本（正しい本文） | 誤検知ゼロ | 全件 OK |

## 使い方

```bash
npm run story:verify -- -t zennihon-championship -c doubles-none-boys draft.md
npm run story:verify -- -t highschool-championship -c team-none-boys --text "尽誠学園は3連覇" -q
```

`-q` は OK を伏せて ERROR/WARN だけ出す。ERROR または WARN が1件でもあれば終了コード 1。
