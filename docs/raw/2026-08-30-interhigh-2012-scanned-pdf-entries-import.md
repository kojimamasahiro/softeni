# 2012年インターハイ（男女）スキャンPDFからのエントリー抽出

## 背景

ユーザーから2012年度全国高等学校総合体育大会ソフトテニス競技（北信越かがやき総体）の
記録報告書PDF 2本（`2012_C05_40.pdf`=男子 / `2012_C06_40.pdf`=女子、各14ページ）を
渡された。2013年と同じくテキストレイヤーの無いスキャンPDF
（全ページ 2152x3035px・300dpi・1bpp CCITT、`pdfplumber` の文字数ゼロ）。

手順は[2026-08-30-interhigh-2013-scanned-pdf-entries-import.md](2026-08-30-interhigh-2013-scanned-pdf-entries-import.md)
で確立したものをそのまま使ったが、**2013年と違った点が3つ**あった（下記）。

## ページ構成 — 2013年と違う（14ページ）

ページ見出しをOCRして確認した。男女とも同じ並び。

| ページ | 内容 |
|---|---|
| p2-p9 | 個人選手権（その1〜その8） … **エントリー抽出に使用** |
| p10 | 個人選手権 ベスト64 |
| p11 | 個人選手権 準々決勝以降 |
| p12 | **団体選手権（48チームの本ドロー）** … 抽出に使用 |
| p13 | 団体選手権（後半ラウンド） |
| p14 | 団体戦 決勝 |

2013年は13ページで団体戦の本ドローが p11 の1枚だった。**2012年は団体選手権が p12/p13 の
2ページに分かれている**ので、「団体戦」というOCR見出しだけで飛びつくと後半ラウンドの
ページを掴む。48チームの本ドローがどちらかは中身を見て決めること。

## 2013年と違った点(1) — 傾きが実害のある水準で、deskew が必要だった

2013年は全ページ0.35度以下で deskew 不要だったが、**2012年は最大 -0.85度**
（男子p3）。他にも -0.63度(男子p13)、-0.55度(男子p5, p12)、-0.52度、-0.46度…と
0.4度超のページが複数ある。ページ幅2150pxに対し0.85度は端から端で**約32pxのドリフト**で、
文字高30pxを超える。行クラスタリングも固定y座標での切り出しも壊れる。

そこで**ページごとに deskew を掛けてから**切り出した。角度探索は2013年の傾き実測と
同じ指標（行方向射影の一階差分二乗和の最大化）を2段階で:

1. -2.0〜+2.0度を0.05度刻みで粗探索
2. その周辺 ±0.05度を0.01度刻みで細探索

回転は `cv2.warpAffine`（`INTER_CUBIC`、余白は白）。これで以降の処理は2013年と同じに
なった。**「傾いて見える」ではなく実測値で判断する**という2013年の教訓は変わらないが、
**結論（deskew不要）は年度ごとに再判定する**必要がある。

## 2013年と違った点(2) — 氏名グリッドのピッチが狭い

構造は2013年と同じ「姓の枠3つ + 空白帯 + 名の枠3つ」だが、**寸法が違う**。

| | 姓1 | 姓2 | 姓3 | | 名1 | 名2 | 名3 | エントリー1行目のy |
|---|---|---|---|---|---|---|---|---|
| 2013年・左ブロック | 218-248 | 264-289 | 306-335 | | 399-427 | 444-471 | 488-516 | 473 |
| 2012年・左ブロック | 275-303 | 312-340 | 348-375 | | 424-452 | 460-488 | 496-524 | 550 |

枠の中心間隔が2013年の約43-44pxに対し2012年は約37px、ブロック全体も右に約57px、
下に約77pxずれている。**切り出し窓は年度ごとに実測して決め直す**こと
（2013年の窓をそのまま使うと `No.` 列や右ブロックの姓1文字目が切れる）。

エントリー間ピッチは約106px、ペア内2行間は約41pxで2013年と同じ。

## 2013年と違った点(3) — 氏名欄は「3枠」ではなく「可変の固定幅フィールド」

2012年女子 entryNo 64 に **`シュレスタ／メガ`**（大阪・淀之水昇陽、ネパール系の名前）が
あり、姓が**カタカナ5文字**。3枠モデルなら入らないが、実際には姓の領域いっぱいに
文字が圧縮されて収まっていた。

つまり正しい理解は「姓3枠+名3枠」ではなく、**「固定幅の姓フィールド」と「固定幅の名
フィールド」が空白帯で隔てられており、文字数に応じて内部で詰められる**。
姓名分割の判定基準（空白帯で切る）は変わらないので実務上の影響は無いが、
「3文字までしか入らない」と決め打ちしたコードを書くと壊れる。

同種の例: 2012年男子 entryNo 199 `船津丸／正人`、女子 entryNo 245 `アライ`（2013年）など。

## 照合 — 直前に作った2013年データを参照に加えると劇的に効く

当初は `tools/highschool-championship-2014〜2017/` だけを参照にしていたが、2012年から
見ると2年以上離れるため当たりが少ない（男子p2で6名）。**先に完成させた2013年データを
参照に加えたところ同じページで24名**に増えた。高校生は3年で入れ替わるので、
**年度を1つずつ遡り、確定した年度を次の参照に加えていく**のが効く。

最終結果:

| | 姓名完全一致 | 学校まで一致しない | エントリー数 |
|---|---|---|---|
| 2012年 男子 | **178名** | 7件 | 316 |
| 2012年 女子 | **207名** | 22件 | 320 |

- id は男子1-316・女子1-320で欠番・重複なし。47都道府県すべて出現
  （男子: 30県が6ペア + 17都道府県が8ペア = 316 / 女子: 28県が6ペア + 19都道府県が8ペア = 320）。
- 氏名・学校・都道府県の空欄ゼロ。**重複ペアも重複選手もゼロ**
  （2013年男子にあった136/277のような原典不備は2012年には無い）。
- 団体戦48チームは男子46/48・女子47/48を裏取り。裏取りできないのは
  `拓大紅陵`(千葉) `岩手`(岩手) `北海道尚志`(北海道) だけで、いずれも実在校。
- 学校名が `teams.json` に無い/県が違う指摘は男子21種・女子18種。**すべて実在校**と確認した。
  2012年は開催地が北信越（富山・石川・福井・長野・新潟）で、団体戦は男女とも
  **新潟県のみ2校**（男子: 巻・小千谷 / 女子: 北越・長岡商）。

## 2013年の未確定項目が2012年で解決したもの

2012年に同じ選手が出ているおかげで、2013年に「低信頼」として残していた読みが確定した。

- **`粉澤キララ`（2013年女子247・福島 田村）の `粉`／`紛` の判別。**
  2013年のスキャンでは左偏が `米` か `糸` か 1bpp では苦しかったが、2012年女子195で
  同一人物が **`粉沢キララ`** と印字されており、そちらは `米` の十字＋四点がはっきり読める。
  **`粉` で確定**（`澤`/`沢` は年度で表記が違うので、それぞれ印字どおりにした）。
- 2013年で確認済みだった `繪上翔`・`野外雅治`・`一政成涙`・`煤田優希`・`中村鷹子`・`青豊`
  も、2012年に同一人物・同一校で再出現して一致した。

## 異体字・表記の正規化

2013年と同じ方針（既存データの多数派に寄せる）を適用した。

- `髙→高`、`﨑→崎`（2013年でユーザーが選んだ方針(b)）
- `済々黌` → **`濟々黌`**（2012年男子253。2014-2017年データの表記に合わせる）
- `佐賀濟和` → **`佐賀清和`**（2012年女子236。同じPDF内でも女子309では `佐賀清和` と
  印字されており原典が不統一。`teams.json` と2013年は `佐賀清和`）
- `幡多農高` → **`幡多農`**（2012年男子229。他エントリーと違い「高」付きで印字）
- `茅ヶ崎北陵`（2012年男子215）… `teams.json` は `茅ヶ崎`（小書き `ヶ`）、
  リポジトリ全体でも `竜ヶ崎第一` など `ヶ` が優勢。**2013年男子311を `茅ケ崎北陵` から
  `茅ヶ崎北陵` に修正した**（`tools/highschool-championship-2013/doubles-none-boys.initialPlayers.json`、
  5箇所）。

## Compile Log

反映先: [docs/wiki/data-import.md](../wiki/data-import.md)
（「スキャンPDF（テキストレイヤー無し）のエントリー抽出」の節に追記）。

wiki に載せたもの:

- **deskew の要否は年度ごとに実測して判断する**（2013年は不要、2012年は最大0.85度で必須）。
  角度探索を粗0.05度→細0.01度の2段階にする点も含む。次に古い年度を処理するとき、
  2013年の「deskew不要」を一般則と誤読しないため
- **切り出し窓とグリッドのピッチが年度で変わる**という事実（2013年44px / 2012年37px、
  ブロック位置も約57px右・77px下にずれる）
- **氏名欄は固定枠数ではなく固定幅フィールド**で、カタカナ5文字の姓も圧縮されて入る
  （`シュレスタ／メガ`）。文字数上限を決め打ちしない根拠
- **確定した年度を次の参照に加えて年度を1つずつ遡る**という照合戦略と、その効き
  （2014-17のみで6名 → 2013年を足して24名）
- ページ構成が年度で違い、団体戦本ドローのページを見出しだけで決められない場合がある
