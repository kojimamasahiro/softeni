# インターハイ 2025 団体戦のオーダー取り込み（アウトライン化PDF）（2026-09-18）

ユーザーから令和7年度の**記録報告書**（`recordreport_504.pdf`・53ページ）をもらい、
男子 p28-31 / 女子 p47-50 から男女のオーダーを投入した。同日に入れた
[2026 のインターハイ](./2026-09-18-interhigh-team-match-order.md)と**紙面の作りは同じ**だが、
**PDFの作りがまったく違って**別スクリプトになった。

## 何が違ったか

`pdftotext` が空を返す。`pdffonts` も1行も出さない。**フォントもテキスト層も無く、
1文字が1つのベクター塗りパス**になっている（全日本社会人2022 と同じ作り。
[2026-08-20 のノート](./2026-08-20-zennihon-workers-2022-general-boys-vector-glyph-import.md)）。
一方で**列のx座標は 2026 の様式とまったく同じ**だったので、読み取りの骨格は流用できた。

踏んだ落とし穴は4つ。どれも「気付かないと静かに間違ったデータが入る」たぐい。

1. **エントリー番号だけ塗り＋線（`'fs'`）**。`'f'` だけ拾うと見出しの番号が丸ごと消え、
   details のどの試合か決められない。
2. **「打ち切り」の白い箱が下のゲーム行を覆っている**。ページをそのまま描画すると
   隠れた数字が読めず本数が合わない。**パスを1本ずつ白紙に描き直す**と読める。
   実例: 男子 上宮-岡崎城西 第1対戦。隠れていた2行（3-⑤ と 1-④）を足して印字の 2-3 に一致した。
3. **未実施の対戦は本数もゲームも印字されない**（ペアだけ）。本数を手がかりに対戦を割ると
   対戦が1つ消えて D1/D2/D3 がずれる。**区切りは氏名の行で決める**（3対戦×2人＝6行）。
   実例: 男子 羽黒-東北 は第1対戦が未実施で、本数基準だと第2・第3が D1・D2 になっていた。
4. **「一」は高さ0.8ptしかない**。高さでふるうと氏名から抜け落ちる（山本一輝→山本輝）。

## 数字の読み方

字形を正規化（160dpiで描き直し→インクの外接矩形で切る→32×32→軽くぼかす）して、
`scripts/pdf/highschool-championship-2025-digit-glyphs.json`（字形→文字）との内積で読む。
クラスタリングの順序に依存しないので再実行で結果が変わらない。

**⑥と⑧が紛らわしい**。1位と2位の差が 0.013 しかない実例が2件あり、⑧ を ⑥ と読んで
「6-6」という同点ゲームができていた。丸数字の有無は合っているので**本数の数え直しでは見つからない**。
見つけたのは新しく足した「ソフトテニスのゲームとして成立するか」の検査
（通常は4点先取・デュースは2点差、**3-3 で迎える第7ゲームはファイナルゲームで7点先取**）。

## 氏名の読み方（最終形: 字形辞書。人は一度だけ読む）

**最終的に氏名も数字と同じ字形辞書から読む**ようにした。人が漢字を読むのは辞書を作る一度だけで、
再実行も他年度も機械だけで通る。辞書に無い字形は「辞書に足せ」と報告して止まる（当て推量はしない）。

辞書の作り方:

1. 人（LLM）がページの画像から168人ぶんの氏名を読み、いったん
   `highschool-championship-2025-team-names.json` に置く。
2. 見出しの学校名・都道府県は **details のエントリー番号から分かる**ので、読まずに対応が取れる。
3. 1と2で「字形→文字」のラベルが 796 個・239文字ぶん付く。ここから**1文字につき代表1つだけ**を
   辞書に入れ、入れなかった出現を全部引き直して確かめた。
   → **255字形で796出現すべてを正しく引けた**（誤り0・際どい0）。字形が割れて代表が2つ要る字が16文字。
4. 数字26字形と合わせて `highschool-championship-2025-glyphs.json`（281字形・256種）。

`--names` は**入力ではなく照合用**として残した。辞書から読んだ結果が元の読みと食い違えば止まる。

### 人の読みを機械が直した例

目視の転記を、字形の一貫性（同じ字形を2つの字に読んでいないか）と名簿で検算したところ、
`佐々木真凛`（目視）と `佐々木真凜`（名簿）の1件が食い違った。拡大すると**名簿が正**。
168セル中この1件だけで、字数＝グリフ数も全セル一致していた。

### 採らなかった方法: 名簿への伝播だけで解く

学校名から仕込んだ対応を名簿へ伝播させると111人中96人まで自動で解けたが、**名簿に居ない選手の
セルが、たまたま条件に合う別人1件に確定してしまう**（増田汰一→丸田貴士）。
文字→字形も一対一という制約を足すと防げるが、クラスタリングが同じ字を割る分だけ誤検知が増えて
今度は解けなくなる。字形辞書にすればこの問題自体が消える（辞書に無ければ止まるだけ）。

## 出典（PDF）の誤記は1件

`highschool-championship-2025-corrections.json` で補正した（ユーザー判断 2026-09-18）。
補正は**印字が一致するときだけ**当たるので、読み取りがずれれば気付ける。当てた箇所は毎回表示する。

- 東北-須磨学園 第3対戦 3ゲーム目 `⑤ － 4` → **5-3**。
  第3ゲームなので通常のゲーム（4点先取・デュースは2点差）。5-4 は成立しない。
  ただし**どちらの数字が誤植かは決められない**（5-3 とも 6-4 とも読める。直前のゲームが `⑥ － 4`）。
  ユーザーの判断で 5-3 を採った。

### 誤記だと早合点した1件（ファイナルゲームの見落とし）

羽黒-京都光華 第1対戦 7ゲーム目 `2 － ⑦` を、いったん誤記とみなして 5-7 に補正してしまった。
**3-3 で迎える第7ゲームはファイナルゲームで7点先取**なので、`2 － ⑦` は正しい印字。
検査のルールを「4点先取・デュースは2点差」だけで書いたのが原因で、ユーザーの指摘で戻した。
ルールを直して全データ（418ゲーム）を検査し直すと、ファイナルゲーム12件・成立しないゲーム0件。

**検査が鳴ったときは、読み取り側・出典側だけでなく、検査のルール側の見落としも疑う。**

## 打ち切り時点の「途中のゲーム」は落とした

この様式は打ち切りの瞬間の途中経過も1行印字する（`2 － 1`、`4 － 4` など）。
ADR-020 の `games` は**決着したゲームだけ**（取ったのは多いほう・同点は無い）という約束なので、
丸数字の無い行は落とした。落とさないと `4-4` が入って prebuild の検査が落ちる。
**対戦の `scoreA`/`scoreB` に打ち切り時点の本数は残る**ので、「どこで打ち切られたか」は失われない。
落ちるのは途中のゲームのポイントだけ。

## 結果

- 男女それぞれ7試合・21対戦（計14試合・42対戦）。
  男子 完了17・打ち切り1・未実施3 / 女子 完了15・打ち切り6・未実施0。ゲームは計196。
- 検算はすべて一致: 見出しのエントリー番号と学校単位の本数＝details（14試合すべて）、
  対戦の勝ち数＝details、印字の本数＝ポイントの数え直し、ゲームの得点が成立する（上記2件を除く）、
  字数＝グリフ数、字形の読みの一貫性、2校に割り当てられた選手なし。
- **選手は延べ168人すべてが姓・名で結び付いた**（名前だけは0件）。
  うち11人はこの大会の個人戦に出ていない（団体戦だけ）が、他大会の出場記録で結び付いた。
- 字形辞書だけで読み直した結果が、人の読み（`--names`）と**168人すべて一致**。
- 学校の2試合目以降で前の試合と選手が重なる: 男子 6/6・女子 6/6。
- `npm run check:team-match-details` は 168試合 / 504対戦で問題なし（+14試合・+42対戦）。
