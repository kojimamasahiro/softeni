# 2023年全日本社会人PDFからのエントリー抽出（インターハイ用スクリプトの流用不可）

## 背景

インターハイ2018/2019のエントリー抽出（[2026-08-20-interhigh-2019-pdf-entries-import.md](2026-08-20-interhigh-2019-pdf-entries-import.md)）
に続けて、令和5年度全日本社会人ソフトテニス選手権大会の公式記録PDF（`2023_A05_40.pdf`）から
`data/tournaments/details/zennihon-workers/2023/` の6カテゴリ（既存は2024〜2026のみ）を追加した。
一般男子・一般女子・35歳男子・45歳男子はトーナメント表、35歳女子・45歳女子はラウンドロビン表。

## インターハイ用スクリプトが使えなかった理由

`scripts/pdf/highschool_championship_entries.py` を最初に試したが0件しか取れず、別スクリプト
`scripts/pdf/zenshakai_entries.py` を新規に書いた。レイアウトが構造的に異なるため:

- インターハイPDF: 都道府県＋所属が1つの括弧に「まとめて」入る（`（福岡　NTT西日本）`）。
- 全日本社会人PDF: 都道府県と所属が別々の列。しかも男子/女子でX座標が全体的にずれ、
  35歳の一部ページはさらに別の列構成（所属が氏名と同じ行、都道府県が別行）になる。
- ラウンドロビン表（35歳女子・45歳女子）はインターハイ側に存在しない、全く別の抽出ロジックが要る。

## 抽出ロジックのハマりどころ（このPDF固有、今後も起きうる）

- **行クラスタの代表値がズレる**: 所属(team)の文字が氏名より前の行に浮くケース（通常は後ろに
  浮く）があり、行クラスタの代表Y座標（＝最初に処理された文字のtop）が本来の氏名行より前にズレる。
  これに気づかず「代表値±6pt」で都道府県・所属を探すと、逆方向にズレた別の値を拾い損ねる。
  対策: 氏名列の文字だけを厳しいtoleranceで別クラスタ化し、そこから求めた氏名行のY座標を
  基準に、都道府県・所属は氏名行の**前後どちらにもtolerance を張った帯**で探す。
- **列境界の文字がエントリー番号列にも都道府県列にも中途半端に近い**: 姓の先頭文字がエントリー
  番号列との境界ぎりぎりに来て脱落する（`河盛由香利`→`盛由香利`）と、脱落した文字がエントリー
  番号側の帯に混入して`entry_no.isdigit()`が失敗し、ペアの組が丸ごと1つ分ズレる二次被害が出た
  （ラウンドロビン表で3組ズレて発覚）。列境界には十分なマージン（実測で最低10pt程度）を取る。
- **都道府県が3文字（神奈川/鹿児島/北海道等）だと列境界を跨ぐ**: 都道府県列を狭く取ると
  「神奈」で切れて「川」が所属側に混入する。対策は2つ組み合わせ: (1)都道府県列を47都道府県の
  最大文字数を見込んで広め(+30pt)に取る、(2)それでも起きる過不足は「都道府県が47都道府県の
  短縮表記と完全一致するか」を検証し、不一致なら末尾の余分な文字を所属側の先頭へ戻す
  補正パス（`_fix_pref_overflow`）で吸収する。
- **ラウンドロビン表は列幅がページごとに変わる**: グループ数が多いページ（45歳女子, 11グループ）
  は列を詰めるため、24組のページ（35歳女子, 8グループ）と同じ固定座標が使えなかった。
  見出し行（氏名/支部/1）の文字X座標から都度列範囲を検出する方式（`detect_rr_cols`）にした。
- **ラウンドロビン表はグループごとに見出し行（氏名/支部/所属/1/2/3/勝率/差/順位）が繰り返す**:
  この見出し行を実データ行と誤ってペアリングしようとすると即座に `entry_no.isdigit()` で
  弾かれ1行だけ読み飛ばす動きになるため、多くの場合は自己修復するが、上記の列境界の脱落と
  重なると多重にズレて実害が出た。

## 実施したこと

`scripts/pdf/zenshakai_entries.py` を新規作成。トーナメント表用に3種類の列プリセット
（`general`=一般男子・45歳男子、`female`=一般女子、`age`=35歳男子）と、ラウンドロビン表用の
自動列検出（`detect_rr_cols`）を持つ。エントリーのみ抽出（`matches`/`results`は空、方針は
インターハイと同様「捏造しない」）。

抽出結果（2023年、zennihon-workers）:

- 一般男子314 / 一般女子109 / 35歳男子89 / 45歳男子70 / 35歳女子24 / 45歳女子34
- 全カテゴリで欠番・重複エントリー番号なし。都道府県は47都道府県の短縮表記に対する
  ホワイトリスト検証で0件不一致（35歳男子の1件のみ、氏名2文字で姓/名の境界不明の既知ケース）
- `npm run check:entries` エラー0
- インターハイと同様、`scripts/pdf/details_to_initial_players.py` で
  `tools/zennihon-workers-2023/*.json`（tool入力用JSON）も作成済み
