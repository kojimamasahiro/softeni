# アジア競技大会2026 種目別日程の掲載と、会期中の取り込み方針

## 状況

2026-09-16 に公式リザルトサイト（results.asiangames2026.org）でソフトテニスの日別日程が公開された。
ユーザーの問い「どうするのがいいと思う？」に対し、3段の案を出した。

1. 会期前: 種目別の日程を大会ハブと代表選手のページに出す
2. 会期中: 結果を日ごとに取り込む。対戦相手の大半が外国選手なので取り込み範囲を決める必要がある
   - A: 日本選手が出た試合だけ（相手は名前と国だけ）
   - B: 全試合・外国選手も選手として持つ
3. 会期後: 確定・記事・OGP、杭州大会（S5）の判断

**ユーザー判断（2026-09-17）**: 「1を実装して、Aでお願い」。

## 実装で決めたこと

- データは `information` の `categories[].schedule`（開始日・決勝日・決勝時刻）。
  試合単位の進行表は持たない。「いつ見ればいいか」が分かる粒度で足りるため
- 出典・確認日は年度レコードに1つ（`scheduleSource` / `scheduleSourceUrl` / `scheduleCheckedOn`）。
  **出典が無い schedule は表示しない**
- 団体は「9/18〜20」の範囲で持つ。9/19 に試合があるかは書かない（範囲は毎日試合があるという意味ではない）
- 時刻の注記は「日本時間」ではなく「会場の現地時刻」。国外開催の国際大会に同じ部品を使うため
- 選手ページは**その選手の出場種目だけ**の日程を出す。全種目を並べると出場するように読めるため
- ハブの表は並びを 開始日 → 決勝日 → 決勝時刻 にした（女子団体が男子団体より先に来る）。
  `categories` の並びも日程順に入れ替えた
- スマホ幅で日付が「（金）」の途中で割れたので「〜」の後でだけ折り返す。決勝列がはみ出したので
  余白を詰め、`14:00〜` を `14:00`（見出し「決勝開始」）にした。選手ページ側は「決勝 14:00〜」のまま
- 方式Aの前準備として `ranking-config.json` の `excludeTournaments` に `asian-games` を先に足した
  （コリアカップ・平和カップと同じ理由。結果が0件の今なら数値が動かない）

## 方式Aの前例

コリアカップ2026（`details/international-korea-cup/2026/`）が既に外国選手を持っている:
`{"id": "KIM_HANSUL_KOR-21", "lastName": "KIM", "firstName": "HANSUL", "team": "KOR-21", "prefecture": null}`。
日本選手もローマ字（`TEMMA_RENA_JPN-1`）で入り、`participant-aliases.json` で漢字の選手に解決している。
アジア大会も同じ形にする。
