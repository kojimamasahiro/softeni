### 照合をすり抜けた3件目

`singles-none-boys` は**ゲートを通過したのに実際は誤っていた**。本文は

> 学校別では、早稲田大学が…、日本体育大学が…、法政大学が…、明治大学が…で、
> **それぞれ4年連続**でベスト8以上に入っています。

だったが、2022年追加後の実データは 早稲田=5年 / 日本体育=5年 / 明治=5年 / 法政=4年。
`story:verify -v` を見ると、この文について照合されたのは

```
[  OK  ] 法政 4年連続ベスト8
```

の**1件だけ**だった。**複数校を「それぞれN年連続」で束ねると、照合は主語を1つしか取らない。**
たまたま唯一4年連続のままだった法政が拾われたため OK になっていた。

修正後は3校を「それぞれ5年連続」、法政だけ主語を立てた別の文に分けた。分けたことで

```
[  OK  ] 日本体育 5年連続ベスト8
[  OK  ] 法政 4年連続ベスト8
```

と2件が照合されるようになったが、**早稲田・明治は依然として照合されていない**
（年×成績の個別ペアは5件ずつ OK になっているので、連続年数はそこから算術的に裏が取れる）。

**教訓: 「それぞれN年連続」で主語を束ねると、束ねた数だけ照合が漏れる。**
経年集計を複数主語で書くときは、年×成績のペアを全主語ぶん明記して裏を取れる形にしておく。
