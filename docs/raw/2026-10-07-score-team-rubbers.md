# 団体戦の対戦を score 機能で記録して details へ反映する（2026-10-07）

> 適用範囲: 混在（「記録ツールの出力を大会データへ書き戻す」流れは汎用、3対戦制・チームのエントリーはソフトテニス固有）

## きっかけ

- 実業団リーグ 2026 男子（`zennihon-business-group/2026/team-none-boys.json`）の決勝 `match-117`
  （NTT西日本 1 対 ワタキューセイモア 60、2-1）のオーダーを入れたい。元資料は YouTube の再生リストだけで、記録PDFは無い。
- 最初の案は「スコアをテキストで受け取り手で JSON にする」。ユーザーは score 機能（`/beta/matches/create`）で入力して反映する形を選んだ。
- 貼られた再生リストの URL（`list=PLOc-COKvrvbw`）は ID が通常より短く、途中で切れている可能性がある（未確認）。

## 調べたこと

- 作成画面で種目「団体」を選ぶと `game_type='team'` になり、2人目の選手を送らない（ダブルスのときだけ送る）。
- `/api/tournament-entries` は団体のエントリーも返すが、氏名が空なのでラベルが「1 」だけになっていた。
- `siteLink` は `tournament_category` と性別で団体のファイルに解決できる（`team-none-boys.json`）。
  エントリー番号の組は同じでも試合詳細の URL は score の試合 ID なので、3件並んでも衝突しない。
- スナップショット生成は `select('*')` なので、列を足せば公開 JSON にも乗る。
- 本番の `matches` に `team_rubber_order` はまだ無い（anon キーで select して 400。`round_name` は 200）。

## ユーザー判断（2026-10-07）

- 第何対戦かは DB に列を足す（`round_name` へ埋め込む案は却下）。
- 反映はスクリプトで details に書き込む（ビルド時の合成は却下）。
- 一部の対戦しか記録が無い試合は、揃うまで反映しない。

## 実装

- `docs/sql/team-rubber-order.sql`（`matches.team_rubber_order` 1〜3）。個人戦では作成画面がこの列を送らないので、未適用でも個人戦は作れる。
- 作成画面: 団体を選ぶと「対戦 *」（第1〜第3対戦）を出し、選手は2人ずつ。チームのエントリーを選ぶとチーム名・地域を2人ぶんに入れ、
  氏名は「チームの候補から選ぶ」で埋める。候補は同じチーム名・**同じ性別**の個人戦の出場選手
  （ワタキューセイモアは女子チームもあり、性別で絞らないと女子が混ざった。男子 72 → 28 人）。
- `scripts/score-team-matches.py`（`npm run score:team-matches`）。書き込みは `scripts/pdf/team_match_details.py` の差し込みを流用。
- 試合詳細・一覧・大会ページの逆引きで、回戦を「決勝 第2対戦」と出す（`formatRoundLabel`）。

## 検証

- 架空の3対戦（第2対戦だけ score 上で左右逆）を `--snapshot` で与えて、`match-117` に D1〜D3 が A＝NTT西日本の向きで入ること、
  `check-team-match-details` が通ること、再実行で「変更なし」、第3対戦を消すと「勝ち数 1-1 が親の本数 2-1 と合わない」で飛ばすことを確認。
  確認後に details は元に戻した。
- 作成画面で NTT西日本（17人）とワタキューセイモア（28人）の候補が出て、選ぶと姓・名が入ることを確認。送信はしていない（列が未適用）。

## 実データでの反映（2026-10-08）

- 男子決勝 `match-117` の3対戦を score で記録し、`npm run score:team-matches -- --write` で反映。
  D1 広岡・林 3-4 竹田・池口 / D2 本倉・上松 4-1 阪本・星野 / D3 矢野・内田 4-0 金山・山本（親の 2-1 と一致）。
  12人とも姓・名で結び付いた。`check-team-match-details` は問題なし、再実行は「変更なし」。
- 大会ページの対戦詳細に第1〜第3対戦とゲームが出ること、「スコア詳細のある試合」に「決勝 第N対戦」が3件並ぶことを確認。
- 対戦詳細の注記は「公式記録にオーダーがある試合は」のままで、動画から記録した今回の出典と合っていない（未対応）。
