# アイデア: チーム一覧（/teams）から小学生・中学生のチームページへリンクする

## 状況

Idea Backlog。**未着手（2026-09-13 起票）**。ユーザー要望:「チーム一覧にも小中学生もリンクさせたい」。

## 目的

`/teams` の行から、小学生カテゴリ・中学生カテゴリのチームページへ辿れるようにする。
現在のリンク解決（TeamLink 規則・D-025、`src/pages/teams/index.tsx` の `TeamCell`）は
(1) STリーグ集計 `/teams/[teamId]` → (2) 高校の学校ページ → (3) 名前のみ、の3段で、
2026-08-12 以降に作った中学・小学生のページは含まれていない。

## わかっていること（2026-09-13 実測）

`data/teams/teams.json` の `count>=2`（4,380行）に、`(正規化した名前, 都道府県)` で当てた。
正規化は NFKC＋空白除去で、`normalizeJa` とは厳密には同じでない（**Assumption**: 本実装では数件ずれうる）。

| | 行数 |
|---|---|
| 掲載行 | 4,380 |
| STリーグにリンク | 59 |
| 高校の学校ページにリンク（STリーグ以外） | 865 |
| 中学生のチームページに当たる | 338（ページは343） |
| 小学生のチームページに当たる | 295（ページは298） |
| **新たにリンクが付く行**（STリーグ・高校のどちらにも当たらない） | **594** |
| 中学生と小学生の両方に当たる | 15（`男塾` `綾瀬チャレンジ` `スマイリー` 等のクラブ） |
| 高校と、中学生か小学生の両方に当たる | 24 |
| 追加後もリンクが無い行 | 2,862 |

- 中学・小学生のページは**性別を URL に入れない**（男女1枚）ので、高校のような男女リンクの併記は要らない
- 小中のページは両方とも `/[category]/[prefectureId]/[teamId]/` 形式。索引は `data/{secondaryschool,primaryschool}/index.json` の
  `teams[].name` / `prefectureId` / `id`

## 課題・未解決

- **複数カテゴリに当たる行の出し方**（39行）。同じチーム名で「小学生の部」「中学生の部」を持つクラブや、
  高校と同名の系列中学がある。案:
  - 優先順位で1つに決める（ST → 高校 → 中学 → 小学）
  - 名前の後ろにカテゴリのラベル付きリンクを並べる（「中学生」「小学生」）。高校の男女併記と同じ見せ方
  - 後者のほうが情報は落ちないが、行が長くなる
- 男女切替（すべて/男子/女子）との関係。小中のページは男女共通なので、どのタブでも同じリンクを出せばよい（**Assumption**）
- 同名チームの誤リンク。都道府県まで一致させるので低いが、`prefecture` が null の行は当てない
- 日本体育大学の行にリンクが無い件（mapping ページを見ていない）も同じ `TeamCell` の修正で直せる。
  [2026-09-13-idea-nssu-team-page-and-university.md](./2026-09-13-idea-nssu-team-page-and-university.md)
- `public-pages.md` の `/teams` 節の数値（3,861件・557チーム・701リンク）が実データ（4,380行・865行）と
  ずれている。実装時に更新する

## 目指したい方向性

小さい変更で効果が大きい（リンク付き行が 924 → 約1,500）。複数カテゴリの出し方だけ決めれば着手できる。
推奨は「ラベル付きリンクを並べる」（高校の男女併記と揃う）。

## 追記（2026-09-14）: 実装した

ユーザーが推奨案（**ラベル付きリンクを並べる**）を選び、実装した。`src/pages/teams/index.tsx`。

- `TeamRow` に `j`（中学生）・`e`（小学生）を追加。索引は `data/{secondaryschool,primaryschool}/index.json` から
  `normalizeJa(name)::prefectureId` で作る（高校と同じ照合）
- リンク先が1つでラベル不要なら名前をリンク、それ以外はラベルを並べる。小中と並ぶ高校は「高校男子」「高校」
- 同時に、`team-name-mappings.json` のキーも `s`（/teams/[teamId]）の解決に使うようにした（STリーグ優先）。
  これで日本体育大学の行にリンクが付いた
- dev サーバーで確認: `スマイリー`→中学生・小学生、`昇陽`→高校女子・中学生、`横芝中学校`→名前リンク、`日本体育大学`→/teams/nssu/
- 課題に書いた `public-pages.md` の数値のずれは、節に「要再計測」と注記した（数値の取り直しはしていない）
