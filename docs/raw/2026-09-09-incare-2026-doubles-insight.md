## 踏んだ落とし穴: 主語が対戦相手に乗り移る

女子ダブルスの第1段落を最初こう書いた。

```
2026年の女子ダブルスは中谷さくら・前田梨緒が優勝しました。決勝は吉木理彩・岩田愛美に5-4、
準決勝は江口咲礼紗・西村ひよに5-0です。前回の優勝は2025年で、2連覇になります。
```

`check-tournament-insights.mjs` が落ちた。

```
[ERROR ] 江口咲礼紗/吉木理彩/岩田愛美/西村ひよ 2連覇
        — 実データは 江口咲礼紗=連続優勝0回 / 吉木理彩=連続優勝0回 / ...
```

照合は本文を `[\n。]` で切り、固有名詞の出てこない文には**直前の文の主語を持ち越す**
（`verify-story-text.mjs` の `carried`）。3文目に主語が無いため、2文目に出た**対戦相手**が
主語として引き継がれていた。

主語を明記して解消:

```
2026年の女子ダブルスは中谷さくら・前田梨緒が優勝しました。中谷さくら・前田梨緒は2025年も
優勝しており、2連覇になります。決勝は吉木理彩・岩田愛美に5-4、準決勝は江口咲礼紗・西村ひよに5-0です。
```

### 同じ誤りが `-c` の渡し方で ERROR にも 未検証 にもなる

上の誤った1文だけを取り出して、条件を変えて照合した（同一テキスト・同一データ）。

| 条件 | 結果 |
|---|---|
| `-c` に全6種目 | 一致11 / 不一致0 / **未検証1** |
| `-c doubles-none-girls` のみ | 一致11 / **不一致1（ERROR）** / 未検証0 |
| `-c doubles-none-girls -y 2026` | 一致11 / **不一致1（ERROR）** / 未検証0 |

**種目を並べるほど誤りが `未検証` に化けて見えにくくなる。** 主語の候補集合が広がって
判定できなくなるため。PROMPT.md の「種目はカンマ区切りで全種目を指定する」は
年×成績の取り違えを防ぐための指示で、**主語の誤りに対しては逆に働く**。

最初の `story:verify`（全6種目）が「一致103 / 不一致0 / 未検証0」だったのに
`check-tournament-insights.mjs`（種目単位）で落ちたのはこれが理由。
**最終ゲートは後者**であることが実例で確認できた。

## 照合が見ない部分の自己確認

skill の「照合は捏造を防ぐが集計ロジックの取りこぼしは防がない」に従い、
機械が見ない2つの断定を手で確かめた。

- 「このペアでの優勝は当サイト収録範囲では初めて」…
  過去の優勝は 2023年 片岡暁紀・黒坂卓矢 / 2024年 橋場柊一郎・菊山太陽 / 2025年 片岡暁紀・黒坂卓矢。
  川﨑康平・黒坂卓矢の組では初。**黒坂個人は2023・2025も優勝しているので、
  「黒坂が初優勝」と読まれない書き方にした**
- 「片岡暁紀は2026年は出場記録がありません」… 2026年の6種目すべての `participants` に不在

## 副産物: wiki の記述の訂正

`tournament-insights.md` の落とし穴に「所属単位の経年集計も書かない——生成YAMLに
所属単位の経年kindが無く、自分で数えた値になるため」とあったが、
**`school-best8-streak`（学校・所属が4年以上連続ベスト8以上）と `school-both-events` は実装済み**。
今回の YAML でも `school-best8-streak` が12件出ており、それを使った
「日本体育大学が…4年連続」の段落は照合15/15一致で通った。

書けないのは**自分で数えた値**、とくに**所属単位の「優勝」連続**（対応 kind が無い）。
元の記述の例「◯◯はこの種目で4年連続で優勝している」がまさにこれに当たるので、
理由の書き方が広すぎただけと判断し、訂正の形で残した（2026-08-30 の記述、社会人2026 の作業時）。
