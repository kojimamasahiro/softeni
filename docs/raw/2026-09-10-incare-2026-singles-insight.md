## 今年の筋: 決勝の顔合わせが両種目ともダブルスと繋がっていた

生成YAMLの `title-won` に `related: counterpart` が張られていて、そこから筋が取れた。

- **男子**: ダブルス決勝は川﨑康平・黒坂卓矢が植田璃音・安達宣に5-2。
  そのあとシングルス決勝で**植田璃音が川﨑康平に4-0**。同じ大会で相手を入れ替えて再戦した形
- **女子**: 前田梨緒は中谷さくらと組んだダブルスで優勝したが、

skill の「主役は1組に絞る／今年何が起きたかから書く」に沿って、両種目ともこの1点を第1〜2段落に置いた。

## 踏んだ落とし穴: 公開ゲートは `未検証` も不合格にする

上の筋を書くには**他種目（ダブルス）の決勝スコア**に触れることになる。
`story:verify` は次のように分かれた（同一テキスト・同一データ）。

| 条件 | 結果 |
|---|---|
| `-c singles-none-boys` 単独 | 一致44 / 不一致0 / **未検証1**（`スコア 5-2（黒坂卓矢・川﨑康平・植田璃音）`）|
| `-c` に全6種目 | 一致45 / 不一致0 / 未検証0 |

前日のノートの教訓（「最終ゲートは種目単位」）に従い単一種目を正としたが、
**`未検証1` のまま公開して `check-tournament-insights.mjs` に落とされた**。

```
- data/tournament-insights/zennihon-university/2026/singles-none-boys.json: 照合に失敗
[ WARN ] スコア 5-2（黒坂卓矢・川﨑康平・植田璃音） — 該当する試合が見つからない
一致 44 / 不一致 0 / 未検証 1
```

原因は `verify-story-text.mjs` が **UNVERIFIED でも終了コード1を返す**こと
（`scripts/verify-story-text.mjs:605-609`）で、`check-tournament-insights.mjs` は
`result.status !== 0` をそのまま「照合に失敗」にしている（`:81-82`）。

skill と wiki には「`WARN` は照合できなかったもので、人が判断する」とあるが、
**それは対話的に叩いたときの話で、prebuild のゲートに人の判断は入らない**。
ここが読み違えやすい。

**解消**: 他種目の事実からスコアを落とし、対戦の事実と勝者だけにした。

```diff
-そちらは川﨑康平・黒坂卓矢が5-2で勝っていました。
+そちらは川﨑康平・黒坂卓矢が勝っていました。
```

女子も同様（`中谷さくらと組んで5-4で勝っていました` → `中谷さくらと組んで勝っていました`）。
固有名詞（黒坂卓矢・中谷さくら）自体は落とさずに済んだ。前者はシングルスにもベスト8で
出ているため照合対象に在り、後者も名前としては通った。

## 工程5（OGP画像）の実測

`--changed` が拾ったのは意図どおり2件だけ。

```
--changed: 更新された種目 2 件を対象にします
    zennihon-university/2026/singles-none-boys
    zennihon-university/2026/singles-none-girls
```

`git status` は**新規PNG2枚と索引の2行追加のみ**で、既存PNGの削除・差し替えは0件。
skill が警告する「全件 `--apply` で313枚が別ハッシュになる」事故は起きていない。

反映確認（dev サーバ、`autoPort` で 64826）:

```
og:image = /og/tournaments/zennihon-university-2026-singles-none-{boys,girls}-{2d3d7d16,8c429f40}.png
twitter:card = summary_large_image   # 両種目とも
```

## 照合が見ない部分の自己確認

- **天間麗奈（優勝）と天間美嘉（ベスト8）は別人**。ともに日本体育大学で紛らわしいが、
  `participants` の `id` が別（`天間_麗奈_日本体育大学_日本学連` / `天間_美嘉_…`）。
  **関係を推測して書かない**ようにした。天間美嘉は2025年シングルス優勝者なので、
  取り違えると「連覇」を誤って書きうる
- 同様に女子には**岩元望美**と**岩元愛美**（ともに神戸松蔭大学）が実在する。
  どちらも本文には使っていない
- 「植田璃音の優勝は当サイト収録範囲では初めて」…
  YAML の `isFirstTitle: true` / `titleCount: 1` に基づく。**選手個人**についての記述なので、
  ダブルスとの取り違え（前日ノートの「黒坂が初優勝と読まれない書き方」）は発生しない
