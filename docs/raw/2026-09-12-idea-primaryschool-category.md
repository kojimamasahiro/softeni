# アイデア: 小学生カテゴリの公開ページ（/secondaryschool 型の横展開）

## 状況

方針決定済み・実装前（2026-09-12）。対象大会・呼称・ページ構成・掲載閾値まで確定した。
実測は `npm run primaryschool:measure`（`scripts/measure-primaryschool-scale.mjs`）で再現できる。

中学カテゴリ（[secondaryschool.md](../wiki/secondaryschool.md)）の横展開だが、
中学が高校の設計をそのまま持ち込まなかったのと同じで、小学生にも固有の差がある。

## 目的

小学生の大会データが `details/` にあるのに、大会ハブ以外の受け皿が無い。
中学・高校と同じく「県 → 団体」の軸で受けられるようにする。

もう一つの目的は**進路の接続を下へ伸ばすこと**。中学カテゴリが持っている「中学→高校」に
「小学→中学」が繋がると、当サイトにしか無い**小→中→高の3段接続**が成立する。

## ユーザーが興味を持った点

- 「中学カテゴリのように小学校カテゴリを作りたい。どう思う？」（発端）
- 「全日本小学生選手権大会のみを対象にしようと思う」——スコープを自分で絞る判断。
  実測するとこの絞り込みは正しく、捨てた2大会は進路レコードの2%しか持たないのに
  データ品質の問題はほぼ全部そちらにあった
- 呼称について「『小学生』がいいのでは？」——「小学校」を採らない判断

## 決まったこと（2026-09-12）

1. **対象大会は全日本小学生選手権大会のみ**（`zennihon-primaryschool`、2019・2022-2025 の5年）
2. **呼称は「小学生」**。「小学校」は使わない（閾値5の298団体のうち学校と呼べるものはほぼ無く、
   実体はクラブ・少年団）
3. **中学と同じ「チーム」扱い**。男女を1ページにまとめ、性別を URL に入れない
4. **「出場選手」節も横展開する**（中学チームページと同じ構成）
5. **掲載閾値は出場延べ5**（`/teams/[teamId]` の noindex 閾値・中学と揃える）

6. **URL は `/primaryschool/`**（`/secondaryschool/` `/highschool/` と揃える）。
   表示テキストはすべて「小学生」で、URL の綴りだけが英語の学校区分語になる

## 想定運用 / なぜこのスコープか

### 対象を全日本小学生選手権だけにする理由

リポジトリには小学生の大会が7件（うちデータありは4件）あるが、足す価値が無い。

| 指標 | 全日本のみ | ＋全国小学生大会＋県大会 |
|---|---|---|
| 大会×年 | 5 | 9 |
| 県が欠けている出場 | **0件** | 1121件 |
| 表記ゆれ（同県内・正規化で重なる） | **1.0%（7件）** | 9.0% |
| 括弧書きを含む団体名 | **0件** | あり |
| 閾値5の団体数 | 298 | 541 |
| 進路（小→中）レコード | **1340** | 1365 |

- **足しても進路は2%しか増えない**（1340 → 1365）のに、県欠落1121件と表記ゆれ9.0%が付いてくる
- 県欠落は全国小学生大会2024に集中（1018件）。同じファイル内で付いている選手と付いていない選手が
  混在しており、取り込み時の欠落
- 全国小学生大会2025は**部分取り込み**。2024は34種目・延べ3244なのに2025は12種目・延べ1934で、
  各学年の1st〜5thブロックのうち1stと予選しか入っていない
- 県大会を足すと**県別分布が歪む**。閾値5の上位が 秋田19 / 宮城18 に変わるが、これは強さではなく
  **その2県だけ県大会のデータを持っているから**。中学がブロック大会を集計から外した理由
  （北海道65対福岡4）と同じ構図

**副作用として、中学が必要とした仕掛けが丸ごと不要になる。** 中学は全中＋県対抗だけだと閾値5が
158団体まで落ちるためブロック大会を「掲載判定にだけ使う」例外を入れたが、小学生は1大会だけで
閾値5が298団体・47県非空になる。対象大会が1つなので集計/判定の二重基準もいらない。

## わかっていること

すべて `npm run primaryschool:measure` で再現できる（2026-09-12 実測）。

### 規模（採用スコープ・閾値5）

- **298団体 / 47県すべて非空 / 県あたり中央値6・最小4**
  （中学280団体・高校289団体と同オーダー）
- ページ数は入口1＋県47＋団体298 = **346枚**（中学343枚とほぼ同じ）
- ページの厚み: 出場延べ中央値9（中学8）・出場年数中央値4・掲載選手数中央値7
- **94%（279/298）に進路が付く**（1団体あたり中央値3件）

### 男女を1ページにまとめる根拠

閾値5の298団体のうち**263団体（88%）が男女両方に出ている**。男女別URLにすると561ページになるが
中身は半分ずつに割れる。中学（男女どちらか片側にしか出ない団体が大半）より強い理由がある。

### ダブルスのペア所属一致率 71.23%

| カテゴリ | ペア所属一致率 |
|---|---|
| 全日本小学生選手権 | **71.23%** |
| 全中 | 0.00% |
| 中学ブロック大会 | 18.65% |
| 都道府県対抗中学生 | 38.89% |
| インターハイ | 0.00% |

**当サイトで唯一、団体を主語にして事実が書けるカテゴリ**（「◯◯ジュニアが優勝」が成立する）。
高校が「学校が主役」の設計にできたのは混成ペア0%だからだが、中学ではそれが全中でしか成り立たず、
`sns-story-platform.md` の「学生カテゴリは学校を主役にする」方針も中学では実質使えていない。

### 県の出場枠が揃っている

**5年 × 男女の10ファイルすべてで、47都道府県が全部出場し、全県4ペア・開催県のみ8ペア。**

4ペアに満たないのは沖縄県だけで、**沖縄県も5年すべて・男女すべてに出場している**（出場していない年は無い）。
ペア数は 2019 男4/女4 ・ 2022 男3/女2 ・ 2023 男4/女3 ・ 2024 男2/女4 ・ 2025 男3/女3。
10ファイル中6つで4ペアに満たない。これが**実際の出場ペア数なのか、取り込みの取りこぼしなのかは未確認**。

中学が「県対抗は47県が同じ枠数だから公平に比べられる」と言おうとして、実測すると19/20/21・
開催県だけ40で崩れ、県別ポイントごと廃止した（[secondaryschool.md](../wiki/secondaryschool.md)
「県別ポイントは廃止した」）経緯があるが、**全日本小学生選手権では本当に成立する**。
サイト内で最も規則正しいデータ。

ただし中学が廃止した理由のうち「**配点が Assumption**」は生きている。ポイント化・順位づけはせず、
「開催県以外は全県4ペア枠」という事実を注記したうえで**ベスト8以上の実績を列挙する**のが、
検算できる事実のまま出せる上限。

### 名寄せはほぼ要らない

表記ゆれは**1.0%（7件）**だけで、括弧書きを含む団体名は0件。出典が JSTA 単一で5年間表記が
安定しているため。中学（9.9%・全中は略称／ブロックPDFは正式名称という出典差が原因）とは
状況が違う。

```
徳島   アイビージュニア(8)      ≒ アイビーJr(2)
愛知   朝日Ｓ．Ｔ．Ｃ(10)       ≒ 朝日STC(1)
福岡   カブトの森Ｊｒ．(10)     ≒ カブトの森ジュニア(6)
兵庫   龍野ジュニア(8)          ≒ 龍野J(1)
和歌山 Ｌ．Ｃ．Ｃ．(5)          ≒ Ｌ.Ｃ.Ｃ(2)
大分   犬飼町スポーツ少年団部(2) ≒ 犬飼町スポ少部(2)
千葉   Unitejunior(2)           ≒ UniteJunior(4)
```

### 進路（小学 → 中学）

- 氏名ユニーク 小学3208 / 中学3625、**氏名一致1344 → 年差1〜6年で採用1340**
- **県一致93%**（中学→高校は42%）。地元の中学へ進むため、[ADR-014](../adr/ADR-014-pathway-name-match.md)
  が乗っている「氏名が実質的に一意」という前提は小→中のほうが強く成り立つ
- 逆引き（中学チームページ → 出身クラブ）は**掲載中学チーム343枚のうち279枚（81%）**に付く。
  レコード計1100件。中学→高校の逆引きが高校111グループ止まりだったのと比べて格段に当たる
- 上位: 清明学園中学校30 / 昇陽中学校24 / 周南クラブ19 / 京都光華中学校17 / LIBERTA13

## 目指したい方向性

中学は「ツリーを作ってから進路を足した」が、大学カテゴリで「ツリーではなく進路接続を先に」へ
転換済みで、小学生はその判断がもっと強く当てはまる（進路が既存中学ページの81%に付く）。

### Step 0: 下ごしらえ

- alias 7件を `data/tournaments/team-name-aliases.json` に追加。中学と違い大会スコープは
  不要と見込むが、`龍野J` `朝日STC` が他カテゴリに出ないかは確認する
  （中学で「この県では高校に出ていない ≠ 全国で出ていない」を踏んでいる）
- `scripts/normalize-team-names.mjs --scope=all` → 再測定
- 単独で価値がある（大会ハブと選手ページが同時に直る）

### Step 1: 進路（小学 → 中学）

新規URLをほとんど作らずに、既存の中学チームページ279枚に「出身クラブ」節が付く。

- `scripts/build-primaryschool-pathways.mjs`（`build-secondaryschool-pathways.mjs` と同型）
- `lib/secondaryschoolFeederClubs.ts`（`lib/highschoolFeederSchools.ts` と同型）
- 採用条件は ADR-014 と同じ「氏名一致＋年差」、年差1〜6年（小4で最後に出場→中3で初出場が最長）
- ADR は新設せず **ADR-014 に「小→中へ適用した」節を追記**する。決定の変更ではなく適用範囲の拡張
- ここで **小→中→高の3段接続**が初めて成立する

### Step 2: ツリー

`/primaryschool/`（1）＋ `/[prefectureId]/`（47）＋ `/[prefectureId]/[teamId]/`（298）= 346枚。

中学からそのまま持ち込むもの:

- 性別を URL に入れない（男女両方に出る団体が88%）
- 大会軸のページを作らない（[ADR-010](../adr/ADR-010-retire-result-articles-consolidate-to-hub.md)。
  全日本小学生選手権の大会ハブが既にある）
- ランキングページ・県別ポイントを作らない
- teamId は `build-secondaryschool-index.mjs` の `stripForSlug` / `applyLoanwords` / pykakasi
  キャッシュを踏襲。長音は `ou` / `uu` を残す規約も同じ
- スラッグ衝突は名寄せの取りこぼしを検出する仕掛けとして使う

中学から変えるもの:

- 中学校 / 地域クラブ のラベル分けをしない（中学でも2026-08-13に取りやめ済みだが、
  小学生はほぼ全部クラブなので最初から不要）
- ブロック大会の「掲載判定にだけ使う」例外ルールが不要

## 課題・未解決

- **小学生（9〜12歳）の実名を団体ページに列挙すること**。「出場選手」節を横展開する判断は
  2026-09-12 に済んでいるが、閾値5の団体で中央値7人・氏名 × 地域が1枚に集まる形になるので、
  公開後に見え方を確認しておきたい。大会ハブでは既に公開済みなので新規露出ではない
- **teamId のローマ字読みの精度**。pykakasi の誤読は中学で実際に起きている
  （`昇陽`→`noboruyou` 等）。小学生はクラブ名が中心で固有名詞の比率が高いので、
  公開前に298件を目視する必要がある
- **`龍野J` `朝日STC` 等が他カテゴリに出ていないか**の確認（alias の大会スコープ要否）
- **`npm run build` の完走確認**
- **沖縄県が4ペアに満たない年がある理由**（10ファイル中6つ）。出場していない年は無いので「欠場」ではない。
  実際の出場ペア数がそうなのか、こちらの取り込みが落としているのかを結果PDFで確認する。
  「開催県以外は全県4ペア枠」と注記するなら、ここを確かめずに書けない

## 追記（2026-09-12・同日の確認3件）

### 訂正: 沖縄県の「欠場」は誤りだった

初稿で「沖縄県が2022・2024・2025に一部欠場」と書いたが**誤り**。沖縄県は5年すべて・男女すべてに
出場している。正しくは「4ペアに満たない年がある」で、本文の該当箇所と
`docs/wiki/data-model.md` の行も訂正済み。

### alias の大会スコープは必要だった（7件中2件が他カテゴリにまたがる）

表記ゆれ7件それぞれが、どの大会に出ているかを全 `details/**` で数えた結果。

| alias 候補 | 出現する大会 | 判定 |
|---|---|---|
| アイビージュニア ≒ アイビーJr | 小学生大会のみ | スコープ不要 |
| カブトの森Ｊｒ． ≒ カブトの森ジュニア | 小学生大会のみ | スコープ不要 |
| 龍野ジュニア ≒ 龍野J | 小学生大会のみ | スコープ不要 |
| 犬飼町スポーツ少年団部 ≒ 犬飼町スポ少部 | 小学生大会のみ | スコープ不要 |
| Unitejunior ≒ UniteJunior | 小学生大会のみ | スコープ不要 |
| **朝日Ｓ．Ｔ．Ｃ ≒ 朝日STC** | 全日本小学生・全国小学生・**全中5件**・**都道府県対抗中学生1件**・**全日本社会人3+3件** | **要確認** |
| **Ｌ．Ｃ．Ｃ． ≒ Ｌ.Ｃ.Ｃ** | 全日本小学生・**中学近畿ブロック2件**・**全日本シニア3件**・**全日本社会人3+1件** | **要確認** |

**朝日STC は中学カテゴリの未解決案件と直接ぶつかる。** [secondaryschool.md](../wiki/secondaryschool.md)
「スラッグ衝突は名寄せの取りこぼしを検出する仕掛けとして使う」に、
`朝日`（愛知、`asahi-2`）を**意図的に統合していない**（同県に `朝日STC` があり、素の名前が学校と
クラブのどちらを指すか判別できないため実在確認が要る）と書いてある。小学生側で無スコープの alias を
入れると、この保留中の判断を迂回して中学・社会人のデータを書き換えてしまう。

`Ｌ．Ｃ．Ｃ．` も同様に4カテゴリ（小学・中学・シニア・社会人）にまたがる。

なお、この2件は**全角半角と区切り記号の揺れ**（`Ｓ．Ｔ．Ｃ` と `STC`）なので、
alias ではなく `scripts/normalize-team-spacing.mjs` 側で扱うべき可能性がある。中学では
`ＵＴＣ`/`UTC` をこの方法で解消している（ただし全角ピリオド `．` が絡むケースは未確認）。

### teamId は先に生成して目視した（閾値5の298件）

`.venv` の pykakasi で298件のスラッグを生成し、中学の `stripForSlug` / `applyLoanwords` /
`slugify` をそのまま当てた結果（生成スクリプトは scratchpad・未保存）。

- **県内スラッグ衝突は0組**。中学は14件衝突し、うち5件が未統合ペアの発見に繋がったが、
  小学生では衝突による取りこぼし検出は効かない
- **読みリスクの分布**: 漢字を含む286 / カタカナのみ6 / 英数のみ6。中学と同じく大半が漢字含み
- **`小学校` `小` で終わる団体は0件**。`stripForSlug` の学校種別接尾辞の規則は
  小学生版では実質不要（「小学生」という呼称の決定を実測が裏づけた形）
- **スラッグ長の中央値15文字**（中学は平均10文字）。20文字超が39件、最長34文字の
  `sugitojuniortenisusportsshounendan`（杉戸ジュニアテニススポーツ少年団）

確認できた**誤読の実例**:

- `市場ジュニアクラブ`（徳島）→ `shijoujuniorclub`。**`ichiba` が正しい**。
  同じ徳島の `市場中学校` は中学側で `ichiba` に override 済みで、同じ地名（阿波市市場町）
- `長命ケ丘JST`（宮城）→ `choumeikeokajst`。`ケ` を "ke"、`丘` を "oka" と分けて読んでいる。
  `choumeigaoka` が正しい
- `南都田スポ少`（岩手）→ `nantotasuposhou`。読みの確認が要る
- 正しく読めている例もある: `羽合スポ少`（鳥取）→ `hawaisuposhou`

**規約側で決める必要があるもの**（個別 override ではなく `stripForSlug` / `LOANWORDS` の問題）:

  持たないため。`渋川スポ少`→`shibukawasposhou` として中学で override 済みの前例あり
- **`テニス`（単独）が5件**。中学の `stripForSlug` は `ソフトテニス` だけを落とすので
  `tenisu` が残る（`堺市テニススポーツ少年団`→`sakaishitenisusportsshounendan`）。
  落とすか `tennis` に寄せるかの判断が要る
- **`倶楽部` 1件**（`登別子ども軟庭倶楽部`→`...nanteikurabu`）。`LOANWORDS` はカタカナの
  `クラブ` しか見ていない
- **長音でないダッシュの混入2件**: `吹揚クラブスポ－ツ少年団`（`スポ－ツ` の3文字目が U+FF0D 等で
  長音 U+30FC ではない）、`Ｓｈｉｎｇｕ-ＪＳＴ`。前者は**データ側の誤字**で、
  正規化でも表記ゆれ検出でも拾えていない

## teamId の目視確認を仕分けた（2026-09-13）

298件を端から眺めるのは現実的でないので、**既存カテゴリ（高校 `teams.json` 765件 / 中学
`index.json` 343件 / 高校の手動 `team_id_map.json` / 中学の override）の読みと突き合わせて、
確認不要なものを機械的に外す**ようにした。生成は `npm run primaryschool:teamid-todo`
（`scripts/build-primaryschool-teamid-todo.mjs`）、出力は
[raw/2026-09-13-primaryschool-teamid-review.md](./2026-09-13-primaryschool-teamid-review.md)。

仕分けは、団体名から「地名らしい先頭部分」を取り出して（`ジュニア` `クラブ` `スポ少` `STC`
などの末尾を剥がす）、その読みを既存マスタと照合する。

| 区分 | 件数 | 内容 |
|---|---|---|
| A. 最優先 | **0** | 同じ地名がマスタにあり読みが食い違う。ほぼ確実に誤読 |
| B. 要確認 | **149** | マスタに無いか、前方一致どまりで裏づけにならない。出場延べの多い順 |
| C. 確認不要 | **110** | 地名が完全一致、または前方一致＋残りの読みも ID と一致 |
| D. 対象外 | **36** | 地名部分に漢字が無い。pykakasi の誤読は起きない |

**目視が要るのは 298 → 149件**（override 済み3件を除く295件のうち）。

### 前方一致だけでは証拠にならない

当初は「地名がマスタ名の前方に一致し、ID も同じ読みで始まる」で確認済みとしていたが、
`桜ジュニア` の `桜`(sakura) が高校 `桜井`(sakurai) に前方一致する類の偽陽性が混ざる。
**残りの読みまで一致するか**を見るようにした（`倉敷`+`南` = `kurashiki`+`minami` =
高校 `倉敷南`=`kurashikiminami`）。

このとき、既存マスタの名前は ID 生成時に学校種別の接尾辞が落ちている
（`芳賀中学校`→`haga`、`稲城第三中学校`→`inagidaisan`）ので、
照合の前に名前側からも同じ語を落とす必要があった。これを入れて C が 91→110 に増えた。

### A が実際に効くことは確認済み

`市場ジュニアクラブ`（徳島）の pykakasi 読み `shijou` が、中学の `市場中学校=ichiba` と
食い違うのを、この仕分けだけで検出できた（override 済みなので現在の A は0件）。
