# Primary School Pages（小学生カテゴリ）

小学生カテゴリ（`/primaryschool`）の公開ページ方針と仕様。
検討の経緯・実測値は [raw/2026-09-12-idea-primaryschool-category.md](../raw/2026-09-12-idea-primaryschool-category.md)。
中学カテゴリは [secondaryschool.md](./secondaryschool.md)、URL 一覧は [public-pages.md](./public-pages.md)。

## 「小学校」と呼ばない

掲載閾値5の298団体のうち、`小学校` / `小` で終わる団体は**0件**。実体はクラブ・スポーツ少年団で、
`ジュニア` を含むものが138、`クラブ` が82、`少年団`／`スポ少` が60ある。

したがって公開ページの文言はすべて**「小学生」**で、団体は「団体」と呼ぶ。URL の綴りだけが
`/primaryschool/` と学校区分語になっているが、これは `/secondaryschool/` `/highschool/` と
揃えるため（2026-09-13 決定）。

中学が「学校ではなくチーム」と呼び替えた（クラブが4割）のと同じ判断を、比率がさらに極端な形で
適用している。

## 対象大会は全日本小学生選手権だけ

`zennihon-primaryschool`（2019・2022-2025 の5年）のみ。リポジトリには他に
全国小学生大会・県大会が4件あるが**足さない**。

| 指標 | 全日本のみ | ＋全国小学生大会＋県大会 |
|---|---|---|
| 県が欠けている出場 | **0件** | 1121件 |
| 表記ゆれ（同県内・正規化で重なる） | **1.0% → 0.4%** | 9.0% |
| 閾値5の団体数 | 298 | 541 |
| 進路（小→中）レコード | **1338** | 1365 |

- **足しても進路は2%しか増えない**のに、県欠落と表記ゆれが付いてくる。県欠落は
  全国小学生大会2024に集中（1018件・同一ファイル内で混在＝取り込み時の欠落）
- 全国小学生大会2025は**部分取り込み**（2024は34種目/延べ3244、2025は12種目/延べ1934）
- 県大会を足すと**県別分布が歪む**。閾値5の上位が 秋田19 / 宮城18 に変わるが、これは強さでなく
  **その2県だけ県大会データを持つから**。中学がブロック大会を集計から外した理由と同じ構図

**副作用として、中学が必要とした仕掛けが丸ごと不要になった。** 中学は全中＋県対抗だけだと
閾値5が158団体まで落ちるためブロック大会を「掲載判定にだけ使う」例外を入れたが、
小学生は1大会だけで閾値5が298団体・47県非空になる。集計と判定の二重基準がいらない。

## 47都道府県が毎年すべて出場する

**5年 × 男女の10ファイルすべてで47都道府県が出場し、開催県以外は全県4ペア枠。**
4ペアに満たないのは沖縄県だけで、沖縄も5年・男女すべてに出場している（欠場年は無い）。
ペア数は 2019 男4/女4 ・ 2022 男3/女2 ・ 2023 男4/女3 ・ 2024 男2/女4 ・ 2025 男3/女3。

中学が県対抗でやろうとして19/20/21・開催県40で崩れた「同じ土俵での県比較」が、
ここでは原理的に成立する。**それでも順位づけはしない**——中学が県別ポイントを廃止した理由の
うち「配点が Assumption になる」がそのまま当てはまるため。

**沖縄が4ペアに満たないのは実際の出場ペア数**（2026-09-13 確認。取り込み漏れではない）。
各ファイルのペア合計を見ると、**開催県と沖縄以外は5年×男女の10ファイルすべてで例外なく4ペアちょうど**で、
取り込みで行が落ちたのなら欠けが特定の1県に5年間・男女とも集中することはない。

なお**公開ページには「全県4ペア枠」と書いていない**（書けるのは「毎年47都道府県すべてが出場している」まで、
という初稿の判断を維持している）。書く場合は沖縄の例外に触れる必要がある。

## ルーティング

| URL | 内容 | 件数 |
|---|---|---|
| `/primaryschool/` | 入口。47都道府県への導線＋大会ハブ・中学カテゴリへの案内 | 1 |
| `/primaryschool/[prefectureId]/` | 都道府県ページ | 47 |
| `/primaryschool/[prefectureId]/[teamId]/` | 団体ページ（男女1枚） | 298 |

計346ページ。中学（343ページ）とほぼ同じ規模。

大会軸のページは作らない（全日本小学生選手権は既存の大会ハブ
`/tournaments/junior/zennihon-primaryschool/` に集約。[ADR-010](../adr/ADR-010-retire-result-articles-consolidate-to-hub.md)）。
ランキングページ・県別ポイントも持たない。

**性別を URL に入れない。** 閾値5の298団体のうち**263（88%）が男女両方に出ている**ので、
男女別にすると561ページになるが中身は半分ずつに割れる。中学が1枚にまとめた理由（薄さ）より
強い根拠がある。

- `prefectureId` は `data/prefectures.json` の `id`
- `teamId` はローマ字スラッグ。県内で一意であればよい

### teamId の作り方

中学の `stripForSlug` / `applyLoanwords` / `slugify` と pykakasi キャッシュをそのまま踏襲する。
長音は `ou` / `uu` を残す規約も同じ。中学との差は2点だけ:

1. **学校種別の接尾辞を落とす規則を持たない**（`小学校` で終わる団体が0件のため不要）
2. **競技名に `軟庭` を、外来語に `倶楽部` を足した**（`登別子ども軟庭倶楽部` の1件のため。
   `軟庭`＝軟式庭球は `ソフトテニス` `テニス` と同じく当サイトでは自明）

**`テニス` 単独も競技名として落とす**（中学は `ソフトテニス` だけを落としていた）。
小学生の団体名には `堺市テニススポーツ少年団` のように `テニス` 単独が5件あり、
落とさないと `tenisu` が残る。落としても県内衝突は増えない。

**`スポ少` と `スポーツ少年団` は統一しない。** 前者32件・後者19件あるが、これは表記ゆれではなく
**別々の団体がそれぞれ自分で名乗っている名前の違い**（同一団体の揺れは犬飼町の1件だけで、
それは alias で寄せた）。中学の「団体が選んだ名前の英語綴りを推測すると誤る」原則に従う。

#### 読みの上書きは「地名部分の読み」（中学との違い）

`data/primaryschool/team-reading-overrides.json` は **teamId 全体ではなく地名部分の読み**を持つ。

```json
{ "大用ジュニアクラブ": "ooyuu" }
```

と書くと `大用` の読みだけが差し替わり、残り（`ジュニアクラブ`）は通常どおり英語綴りへ寄せて
連結される → `ooyuujuniorclub`。中学の `team-id-overrides.json`（値が teamId 全体）とは
意味が違うのでファイル名を変えてある。

目視確認リストは `npm run primaryschool:teamid-todo`（出力は
[raw/2026-09-13-primaryschool-teamid-review.md](../raw/2026-09-13-primaryschool-teamid-review.md)）。
298件を端から眺めずに済むよう、既存カテゴリ（高校 `teams.json` / 中学 `index.json` / 両者の
手動 override）の読みと突き合わせて確認不要なものを外す。2026-09-13 時点で
A 読みが食い違う0 / B 要確認149 / C 確認不要110 / D 漢字なし36。

**前方一致だけでは証拠にならない**（`桜`(sakura) は高校 `桜井`(sakurai) に前方一致する）ので、
残りの読みまで ID と一致するかを見る。既存マスタ名は ID 生成時に学校種別の接尾辞が
落ちている（`芳賀中学校`→`haga`）ため、照合前に名前側からも落とす必要がある。

#### 上書きの値は「地名列の読み」であって地名の漢字部分ではない

2026-09-13 に2件で取りこぼした。上書きは地名列**全体**の読みを置き換えるので、
地名列にカタカナや英字が含まれていればその読みも書く必要がある。

| 団体 | 地名列 | 誤 | 正 | 結果 |
|---|---|---|---|---|
| 七城オネスティー（熊本） | `七城オネスティー` | `shichijou` | `shichijouonesuteii` | `shichijouonesuteii` |
| 洋野NSTC（岩手） | `洋野N` | `hirono` | `hironon` | `hirononstc` |

漢字部分だけを書くと、残りが URL から丸ごと落ちる（`七城オネスティー` → `shichijou`）。
同型の団体は他に `横浜PSC`（地名列 `横浜P`）`羽合STスポ少`（`羽合ST`）`白石ST協会`（`白石ST`）などがあり、
上書きを書くときは目視リストの**「地名」列をそのまま読み下す**こと。

## 都道府県ページ

役割は**「県内にどの団体が収録されているか」の一覧**。順位づけはしない。

- 県内団体を出場回数の多い順に並べ、団体名から各団体の戦績ページへ内部リンクする
- 掲載閾値5未満の団体は表示しない旨を注記する
- 同じ県の中学ページ（`/secondaryschool/[prefectureId]/`）へ相互リンクする。
  `prefectureId` は小学・中学で共通で、中学の県ページは現状47県すべて存在する

## 団体ページ

- 男女を1ページにまとめる（上記の理由）
- 「当サイト収録の最高成績」→「進路」→「大会成績（年度別）」→「出場選手」の順。
  中学チームページと同じ構成
- 選手名は `resolvePlayerId()` が `data/players/index.json` の `count>=5` で解決できたときだけ
  `/players/{id}/results` へリンクする（デッドリンク防止）
- 構造化データは `SportsTeam` と `BreadcrumbList`
- チーム成績（`results`）は**所属が1つに定まるときだけ**計上する。全日本小学生は
  ペアの所属一致が71%で、残り29%の混成ペアは団体の成績にしない

### 進路（小学 → 中学）と、中学ページからの逆引き

このカテゴリの差別化の核。これが入って **小 → 中 → 高の3段接続**が成立する。
生成は `scripts/build-primaryschool-pathways.mjs`。

採用条件は [ADR-014](../adr/ADR-014-pathway-name-match.md) と同じ「氏名一致＋年差」で、
年差だけ **6年**（小4で最後に出場 → 中3で初出場が最長。中学→高校は5年）。
**県の一致もペアの継続も要求しない。**

2026-09-13 実測: 採用1338件（ペア継続406・県一致841・氏名一致のみ91）。
**ペア継続または県一致が93%**で、氏名一致のみに頼るのは **6.8%**（中学→高校は41%）。
小学生は地元の中学へ進むため、ADR-014 の最大の懸念がここでは大きく下がる。

- **団体ページ側**: 298ページ中 **278（93%）**に進路節が付く。レコード1063件のうち
  **816件（77%）**が中学チームページへリンクする（残りは掲載閾値未満の中学で名前だけ）
- **中学ページ側の逆引き**（`lib/secondaryschoolFeederClubs.ts`）: 中学チームページ343枚のうち
  **270枚（79%）**に「出身クラブ」節が付く。出身クラブの延べ587件のうち
  **438件（75%）**が小学生団体ページへリンクする

**掲載閾値によるフィルタは生成側でしない**（中学版との違い）。絞ると中学ページの節から
選手が消えるため。閾値5で絞るとレコードの19%・節が付く中学チームの35枚が落ちる。
表示側がリンクの有無だけを出し分ける。

## 生成と運用

```
npm run primaryschool:build        # 索引と進路をまとめて生成
npm run primaryschool:measure      # 規模の再測定（対象大会の絞り込みの妥当性も出る）
npm run primaryschool:teamid-todo  # teamId の目視確認リストを再生成
```

`prebuild` に組み込み済み。**必ず `scripts/normalize-team-names.mjs --scope=all` の後に流すこと**
（名寄せ前に流すと表記ゆれのぶん団体が分裂する。[ADR-013](../adr/ADR-013-scoped-team-name-aliases.md)）。

生成物:

- `data/primaryschool/index.json` — 都道府県集計と団体一覧
- `data/primaryschool/pathways.json` — 進路（掲載閾値で絞っていない）
- `data/primaryschool/team-reading-overrides.json` — 地名部分の読みの手動上書き
- `data/primaryschool/team-name-romaji-cache.json` — pykakasi の永続キャッシュ
