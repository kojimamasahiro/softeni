# 団体戦のオーダーの取り込み

> **適用範囲: 混在**。検算の考え方（既存データとの突き合わせ・出典の誤記の扱い・状態の決め方）は汎用。
> 様式（インターハイ・高校選抜の記録PDF）と3対戦制・4ゲーム先取の規則はソフトテニス固有。
> **2026-09-23 に [data-import.md](./data-import.md) から分けた。** 分ける前の全文は
> [raw/2026-09-23-wiki-archive-data-import.md](../raw/2026-09-23-wiki-archive-data-import.md)。

団体戦の対戦ごとの記録（オーダー）を公式記録から `details` の `matches` へ入れるときの知見。
データの形は [data-model.md](./data-model.md) と [ADR-020](../adr/ADR-020-team-match-rubber-details.md)、
手順はスキル `team-match-order`、PDF の読み取り全般は [pdf-import.md](./pdf-import.md)。
年度ごとの実施記録は ADR-020 の Related Files にある。

## 手順と守ること

```
python3 scripts/pdf/<大会>_team_matches.py PDF --pages <範囲> --details <team-*.json> [--write]
npx prettier --write <team-*.json>   # 差し込んだ部分は1行のままなので必須
npm run check:team-match-details
```

- **取り込みスクリプトが無出力で exit 0 なら、成功ではなく起動していない**。
  `if __name__ == '__main__': main()` が落ちている（共通部分の切り出しで実際に消えた）。
  `--help` を打てば1秒で切り分けられる。

- **ファイル全体を書き直さず、各試合の末尾に差し込む**（再シリアライズすると Prettier の折り返しが変わり、
  触っていない entries まで数千行の差分になる）。再実行は冪等。
- 書き込み前に「勝ち数＝既存の本数」「同じ選手が2校に割り当てられない」を確かめ、崩れたら止まる。
  **既存データとの食い違いで止まるので、本数の検算にもなる**。
- 選手の結び付けは「同じ氏名・同じ学校の個人戦の出場記録」。**学校名の表記が違うと結び付かず名前だけになる**。
  チームの統合は人が判断する（ADR-019）ので、スクリプトでは吸収しない。
- インターハイは**見出し行に左右のエントリー番号が印字されている**ので番号で直接対応する。
  ゲームごとのポイントは `games` へ。**ポイントは10以上になる**（実測 `⑫ － 10`。変換表は⑳まで持つ）。

## インターハイの様式

- **年度で変わるのは収録範囲・氏名の組み方・打ち切りの書き方の3つ**。列の x 座標は 2021〜2026 で同じで、
  アウトライン化の年度を除けば `highschool_championship_team_matches.py` は無改修で通る（2021 で確認）。
  - **収録範囲**: 2021・2024〜2026 はベスト8以降の7試合だけ（詳細は4ページ）、
    2019・2022・2023 は1回戦から全47試合（24ページ・1ページ2試合）。
    **2019 は男女1冊の「記録報告書」**（テキストPDF。アウトライン化は2025だけ）。
    **2018 年以前はそもそも記録が無い**ので探さなくてよい（2026-09-19 に確認）。
    **範囲は人の指定を鵜呑みにせず、見出し（【１回戦】(1) など）を1ページずつ棚卸しして決める**
    （2022 女子・2021 男女は指定より1ページ早く始まっていて、どちらも2試合落ちるところだった）。
  - **氏名**: 1つの語（2019・2024・2026）か1文字ずつの語（2021・2022・2023）。行ごとに欄の中の語を x 順に連結し、
    **姓と名は欄の境界（x=141・456）で分ける**。どちらの欄も均等割り付けなので
    **文字の間隔では分けられない**（姓の中の間隔のほうが広い例がある）。
  - **打ち切り**: 「打ち切り」の印字はあてにしない（ある対戦と無い対戦がある）。
    **勝者は本数の丸数字の有無で決める**。**本数を印字しない年度（2023）**では、印字が無いときだけ
    ゲームから数えて `scoreA`/`scoreB` を埋める（ADR-020 の `unfinished` は「途中の本数」を持つ）。
    印字がある年度は印字を正とし、数え直しは検算に回す。
- **対戦の塊は氏名の行で切る**（「－」では切れない）。**2019 は未実施・打ち切りの対戦にゲーム行を
  1行も印字せず**、氏名と「打ち切り」だけを出すので、「－」で切ると3対戦が2つの塊になる（男子10試合）。
  氏名は**どの年度でも3対戦×2人＝6行**あり、**対戦の中は約10pt・対戦の間は約82pt**（`NAME_GROUP_GAP`）。
  そのうえで端の扱いに2つ注意が要る。
  - **見出し行の学校名も氏名の欄に入る**ので、塊の上端は「見出しの y + 10」で切る
    （忘れると 2022 は全試合で「playersA が3人」）。
  - **氏名の行には必ず両校の選手が並ぶ**。片側だけの行はページの飾り
    （2024 男子 p18 の「トーナメントへ戻る」が4つ目の塊になっていた）。
- **対戦の本数は氏名の帯（±15pt）から拾う**。塊全体から拾うと見出しのすぐ下の紛れ込みを取る
  （2023 男子 p14 の左の本数欄に単独の `4` があり、第1対戦が `4-4` になった）。
- **ゲーム行の区切りの文字は揺れる**。同じページの中でも全角ハイフン `－` ではなく長音符 `ー` の行がある
  （2019 男子 p47 に1行）。落とすと本数の数え直しが合わない。`DASHES` で受ける。
- **本数は印字されているのにポイントが印字されていないゲームがある**（2019 男子 p36 の第7ゲーム。
  行は「－」だけ）。**本数の印字を正**とし、`games` には印字されたゲームだけを入れる。
  差が「－」だけの行数に収まるときだけ許し、毎回表示する。prebuild の検査にも
  `GAMES_NOT_PRINTED`（ファイル＋matchId＋対戦の位置）で同じ例外を足す。
- **進行中のまま打ち切られたゲームは `games` に入れない**（どちらにも丸数字が無い行。2022 に8件）。
  ADR-020 は決着したゲームだけを持つ。ただし**落とした行は毎回表示する**。
- **対戦の状態を「ゲームの有無」で決めてはいけない**。進行中のゲーム1つだけで打ち切られると
  `games` が空になり、本数 `0 － 0` だけが残る（未実施ではなく打ち切り）。
  **本数・決着したゲーム・進行中のゲームのどれかがあれば、その対戦は始まっている**と判定する。
  `not_played`（何も印字されない）は本数の数え直しの検査から外す。
- **不戦の試合はオーダーを持たない**。見出しの本数が数字でなく `R` と印字され、ペアも本数もゲームも無い。
  `matches` を入れない（`walkover` にもしない——ADR-020 の walkover は出した側のペアが分かる前提）。
  **見出しの本数は数字でないことがある**、と思って読む。
- **同名の別人が2校に出ることがある**（ペアが別で複数回戦とも一貫していれば別人）。取り違えの検査を
  氏名だけで緩めず、取り込みは `--same-name`、prebuild は `check-team-match-details.mjs` の
  `SAME_NAME_DIFFERENT_PEOPLE`（ファイル＋氏名）で通す。

## 検算と出典の誤記

- **`not_played` の数＝2-0 で決着した試合の数**（3対戦制で、未実施の第3対戦にもペアは印字される様式）。
  合わなければ塊の対応か行の切り出しが崩れている。高校選抜 2023 で男子 12＝12・女子 10＝10。
- **見出しの本数は既存データの検算になる**。1回戦から載る年度なら47試合ぶん、
  ベスト8以降だけの年度でも7試合ぶん効く（2021 男子の準々決勝で本数の誤りが1件出た）。
  **3対戦制なので、既存データの本数の和が4以上なら既存が誤り**（インターハイ 2019 男子で2件、
  高校選抜 2024 女子で1件。トーナメント表は敗者の本数しか印字しないため、
  勝者を 3 と決め打ちした跡に見える）。**オーダーの無い年度にも同じ誤りが残っている可能性がある**——
  和が4以上かどうかは PDF が無くても確かめられる。
  ただし**和が4未満でも本数が誤っていることがある**（高校選抜 2021 女子で `0 － 2`、
  出典は `0 － ③`。勝者の本数が少なく入っていた）。**和の検査だけでは足りず、
  オーダーの勝ち数との突き合わせが要る**。
  これまでに本数の誤り2件と**ブラケットのずれ**（2回戦の勝者が逆で、3回戦に上がる学校まで違っていた）
  が見つかっている。詳細ページとトーナメント表の2か所で読みが一致することを確かめてから直し、
  **直した内容は必ず報告する**。**投入後は「学校の次の試合に同じペアが出ているか」も裏取りになる**。
- **出典の誤記は、当てる値が決まらないなら印字どおり残して報告する**（補正ファイルを作らない）。
  分からないものを埋めると、後から「出典の誤記」か「こちらの判断」か区別できなくなる。実測3件。
  **値が出典の別の場所で決まるときは補正ファイルに理由つきで足す**。ゲームのポイントは
  `--corrections` の `corrections`、**見出しの本数・エントリー番号・学校名は `headers`**
  （2019 男子 p30 の本数 `1 － ②`、p36 の相手が `名護 40` と印字されているが中身は 北科大 39）、
  **勝者の丸数字の抜けは `rubbers`**（高校選抜側。キーは `<details のファイル名>|<matchId>`）。
  補正した試合は毎回表示する。**補正は「印字が前提と一致するときだけ当て、違えば止まる」**——
  当てはまらない補正が残った場合も止める（出典が差し替わったのに補正が残る事故を防ぐ）。

## 高校選抜の様式

- **高校選抜には出典が2種類あり、様式が違う**。どちらかは `information` の `sourceUrl` で分かる。
  - **JSTA 記録・Excel 様式**（2020〜2022・2024・2025）: `highschool_senbatsu_team_matches.py`。
    **出典元が違っても様式が同じことがある**（2020 は愛知県高体連の PDF だが中身は同じ様式）。
    1ページに左右の山が収まり、ペアと本数が同じ行。**年度によって男女が別冊**
    （2022・2025 は1冊2ページで `--page 1`／`2`、2024 は男女別 PDF で `--page 1` を2回）。
  - **JSTA 機関誌『ソフトテニス』様式**（2023）: `highschool_senbatsu_kikanshi_team_matches.py`。
    **1種目が左右2ページ**に分かれ（`--pages 左,右`）、**ペアの行と本数の行が別**
    （氏名の約2pt下が本数。左右は本数の行の「－」の x で分ける）。
    **決勝は右ページの左上**に「決勝 <学校> ② － 0 <学校>」の見出しつきで置かれ、
    その本数が検算になる。左右の山をまたぐのは決勝だけ。
  ページ指定の前に `pdfinfo` でページ数を見て、`pdftotext -layout` で見出しを棚卸しする。
- **機関誌様式でだけ効く注意が4つ**。
  **縦の位置は行の中心で比べる**（氏名10.1pt・エントリー番号14.9pt。上端どうしだと約7pt ずれて
  初戦の中間判定が全件外れる）／**学校名も都道府県も1文字ずつ別の語**なので
  エントリー行は**高さ13pt超の数字**で見つける（**ページ下端の柱も数字**なので y<800 で捨てる）／
  **学校単位の本数が氏名の行に紛れ込む**ので氏名から数字を捨てる／
  **`・` は語の中に含まれる**（`大翔・豊田` が1語）ので、側ごとに語を空白でつないでから `・` で割る。
- **未実施を空欄でなく `0 － 0` と印字する出典がある**（高校選抜 2021 女子。**同じ PDF でも
  男子ページは空欄**で、7件ずつちょうど対応した）。素直に読むと `unfinished` になるが、
  1ゲームも行われていないので `not_played` が正。`--zero-as-not-played` で倒す。
  **出典ごとの性質なのでフラグ**（既定は off）で、**他の2対戦だけで勝敗が付いている試合に限る**——
  決着していない試合の `0 － 0` は**本当に 0-0 で打ち切られた対戦**かもしれないので止める。
- **勝者の丸数字が抜けることがある**（高校選抜 2024 男子・2021 女子で各1件。`3 － 4` のように
  両側に丸が無い）。
  **丸が無くても打ち切りとは限らない**——4ゲーム先取なので `4` に届いていれば決着済み。
  **学校単位の本数と他の対戦から勝者が一意に決まるなら補正する**（決まらないなら印字どおり残す）。
  `unfinished` にしてしまうと勝ち数が本数と合わず、取り込みがそこで止まる。

## インターハイ（アウトライン化された年度）

- インターハイには**文字がアウトライン化された記録報告書**の年度がある（`pdftotext` が空・`pdffonts` も空・
  1文字＝1つの塗りパス）。列の x 座標は同じなので骨格は流用でき、
  `highschool_championship_team_matches_outlined.py` が読む。この様式でだけ効く注意が4つ:
  **エントリー番号は塗り＋線（`'fs'`）**で、`'f'` だけ拾うと消える /
  **「打ち切り」の白い箱が下のゲーム行を覆う**ので、パスを1本ずつ白紙に描き直してから読む /
  **未実施の対戦は本数もゲームも印字されない**ので、対戦の区切りは氏名の行（3対戦×2人＝6行）で決める /
  **「一」は高さ0.8pt**しかなく、高さでふるうと氏名から抜ける。

## ゲームの得点と字形辞書

- **ゲームごとのポイントがある様式では「ゲームとして成立する得点か」も見る**。
  **4点先取・デュースはちょうど2点差**だが、**3-3 で迎える第7ゲームはファイナルゲームで7点先取**
  （`2 － ⑦` は正しい印字。4点のルールだけで見ると誤検知する）。丸数字の有無が合っていると
  本数の数え直しでは見つからない誤りが出る（**⑥と⑧は字形が近い**）。
  この検査は**出典の誤記でも鳴る**ので、止めずに報告する。
- **アウトライン化PDFは字形辞書（字形→文字）で読む**。数字も氏名も同じ辞書を引くので、
  人が漢字を読むのは**辞書を作る一度だけ**。**辞書に無い字形は止める**（当て推量はしない）。
  辞書は「人が一度読んだ氏名」＋「details から分かる見出しの学校名」でラベルを作り、
  **1文字につき代表1つ**だけ入れて、入れなかった出現を全部引き直して確かめる。
- **出典の誤記は補正ファイルで直す**（印字が一致するときだけ当て、当てた箇所を毎回表示する）。
  読み取り側の誤りと取り違えないよう、拡大して確かめてから足す。
