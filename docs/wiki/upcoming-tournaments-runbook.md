### M1. アジア競技大会日本代表予選会2025 の順位データを入れる

**なぜ**: `data/tournaments/details/asian-games-qualifier/2025/singles-final-boys.json` と
`singles-final-girls.json` は `results` 4件すべてが `rank.kind: null` で、**優勝者が記録されていない**。
そのため大会ハブの「歴代優勝者」表に**2022年しか出ない**。
「今回の日本代表予選を誰が勝ち抜いたか」は、アジア大会に関心を向けてもらううえで最も強い事実なのに、
サイトはそれを持っていない状態になっている。

**入る値**（決勝リーグの勝敗・ゲーム差から一意に決まる。追記7で算出済み）:

| | 1位 | 2位 | 3位 | 4位 |
|---|---|---|---|---|
| 男子 | 上松俊貴 3勝0敗 | 矢野颯人 2勝1敗 | 丸山海斗 1勝2敗 | 植田璃音 0勝3敗 |
| 女子 | **宮前希帆** 2勝1敗 | 長谷川憂華 2勝1敗 | 岩倉彩佳 1勝2敗 | 天間麗奈 1勝2敗 |

**女子の順位は当初「長谷川憂華が1位」と書いていたが誤り**（ゲーム差で並べたため）。
ソフトテニスのリーグ戦は勝数 → **直接対決** → ゲーム差の順で決まり、
宮前は長谷川に 4-3 で勝っている。**そもそも順位は `results[].roundrobin.rank` として
既にデータに入っており、自力で計算し直す必要はなかった**（計算し直した結果、
入っている値のほうが正しかった）。

**影響調査の結果（2026-08-25 実施）**: 当初「ランキングのポイントが動く」と書いたが**これは誤り**。
実際に影響するのは別の箇所だった。詳細は
[raw 追記10](../raw/2026-07-26-idea-tournament-metadata-platform.md)。要点:

- **影響しない**: ブラケット描画（`lib/bracketLayout.ts` は `results[].roundrobin` を読み、
  `tournament` を一切見ない）／結果カバレッジ（`stage:'knockout'` 限定・`'ongoing'` しか見ない）／
  Elo（`matches` 駆動）／**年度ランキングのシーズンポイント**（`disciplines: ['doubles']` のみで、
  この予選会はシングルスなのでそもそも対象外）
- **影響する**: `lib/playerStats/facts.ts:190` の `isKnockoutSinglesDoublesMixed` が
  `placement.kind === 'winner'` で **true に転ぶ**（リーグ戦しか出ていなくても）。
  結果として決勝/準決勝**進出率の分母・分子**が動く。あわせて
  `singlesBestBySeason`（ダブルス順位表の**同点タイブレーク**）も動く
  ——`asian-games-qualifier` は `ranking-config.json` の `tierOverrides` で **major（重み100）**
- **真の問題は roundrobin ではなく、2025年が1大会を3カテゴリに分割していること**。
  `singles-tournament-*` が既に `best8` を持つため、決勝リーグに `winner` を足すと
  **同一大会が「ベスト8」と「優勝」の2エントリーに二重計上される**

**したがって単純な `winner` 追加はしない。** 採る方針は「最終成績は決着したカテゴリだけが持つ」
（下の M1 実施内容）。

**実施内容（2026-08-26 完了）**: 規約「段階分割された大会では、最終成績は決着したカテゴリだけが持つ」
（[data-model.md](./data-model.md)）に沿って投入した。

| カテゴリ | 変更 |
|---|---|
| `singles-final-*` | 1位 優勝 / 2位 準優勝 / 3位・4位 ベスト4 |
| `singles-semifinal-*` | 決勝リーグへ進めなかった4名 → ベスト8 |
| `singles-tournament-*` | 準決勝リーグへ進んだ8名の `best8` を解除 |

進出者の判定は**順位データではなく「次のカテゴリの entries に居るか」**で行った
（女子準決勝リーグ グループAの順位が決勝進出者と矛盾しているため。
[open-questions.md](./open-questions.md) に記録）。
検査 `npm run check:placements` を新設し、投入後 0 件・負のテストで検知することを確認済み。

### M2. 進出率の分母から `placement: unknown` を外す

**なぜ**: M1 だけでは二重計上が解けなかった。`lib/playerStats/facts.ts:190` の
`isKnockoutSinglesDoublesMixed` は `appearsInKnockout`（knockout の試合に出たか）でも true になるため、
順位を外したエントリーも分母に残る。実測で上松俊貴の分母は **31 → 32 と増えた**。

そして調べる過程で**より大きい既存バグ**が出た。進出率の分母に入っている 42,819 エントリーのうち
**764件（1.78%）が `placement: unknown`** ＝結果が分からないのに「決勝に行けなかった」と数えられている。
**そのうち 748件は `zennihon-workers/2026`＝2026-08-29 開幕でまだ開催されていない大会**（組み合わせのみ投入済み）。

つまり**未開催の大会の出場者の進出率が、いま既に不当に下がっている**。
「開催前の大会を出す」方針を採った以上、組み合わせのみのデータは今後**増える**。

**影響の実測**:

| | 値 |
|---|---|
| 進出率を持つ選手 | 16,693 |
| 分母が減る選手 | 764（4.6%） |
| うち分母が0になり進出率が出せなくなる | 35 |
| 変化幅 | 中央値 0.00pt / 90%点 0.00pt / 99%点 16.67pt / 最大 50.0pt |

大きく動くのは分母 2→1・3→2 の少出場者だけで、主力層は 1pt 前後。

**実施内容（2026-08-26 完了）**: `lib/playerStats/aggregators/reachRates.ts` に除外を1行追加し、
`ENGINE_VERSION` を 1.6.0 → 1.7.0 へ。実装場所を `facts.ts` ではなく `reachRates.ts` にしたのは、
`isKnockoutSinglesDoublesMixed` の意味（ノックアウト個人戦の出場か）を変えないため。
なお `reachRates.ts` のコメントには最初から「placement=unknown は分母から除外」と書かれており、
**仕様は正しく実装だけが漏れていた**。

実測の効果——上松俊貴の分母は **32 → 31（M1適用前と同じ）**、決勝進出は 21 → 22。
サイト全体では 764人（4.6%）の分母が減り、うち35人は分母0。中央値の変化 0.00pt。
除外の内訳は `zennihon-workers/2026` が748件（未開催・開催後に自動で戻る）、
`asian-games-qualifier/2025` が16件。テストは 33 passed / 0 failed。

## やらないと決めたこと

| 項目 | 理由 |
|---|---|
| `isMajorTitle` の変更 | `resolveTier()` / 主要タイトル数 / **Elo の K値** / ニュースの注目選手ピック / 実績の並び順に効く。変更すると全選手のランキングが静かに動く。国際大会を「主要」扱いしたくなったら**別フラグ**を立てる（その判断は ADR 相当） |
| 日本代表名簿を当サイトが名乗ること | 予選会データはシングルスのみで、団体・混合の選考は別経路。**当サイトのデータからは導出できない**。連盟の公式発表を待つ |
| 過去の国際大会の全面的な遡り | S5（前回1件）だけを例外として検討する |
| 「これから開催」の独立ページ化 | まず既存面で効果を見る。良さそうなら独立させる |
| `BreadcrumbList` の二重出力の修正 | **別セッションで対応中**（この計画には含めない） |
| 予選会2025を1カテゴリへ統合する | 2022年と同じ形にすれば根本解決だが、**スキーマに「フェーズ」の概念が無い**。2025年はラウンドロビンが2段あり統合すると `group` が衝突する。既存6ページのURLも消える |
