# Secondary School Pages（中学カテゴリ）

中学カテゴリ（`/secondaryschool`）の公開ページ方針と仕様。
検討の経緯・実測値は [raw/2026-08-12-idea-juniorhigh-category-pages.md](../raw/2026-08-12-idea-juniorhigh-category-pages.md)。
高校カテゴリは [highschool.md](./highschool.md)、URL 一覧は [public-pages.md](./public-pages.md)。

## 高校カテゴリと構成が違う理由

**高校の設計をそのまま横展開していない。** データの形が違うため。2026-08-12 の実測:

| 論点 | 中学 | 高校 | 結論 |
|---|---|---|---|
| ダブルスペアの所属一致 | 全中0.00% / ブロック18.65% / 県対抗38.89% | IH 0.00% | 中学は「学校が主役」が全中でしか成立しない |
| 掲載閾値5のチーム種別 | 学校125 / **クラブ114** / 不明41 | 学校22 / クラブ2 | 中学は4割がクラブ。「学校」と呼べない |
| 1チームあたりの収録 | 中央値8件 | — | 男女で割ると32%が5件未満になる |
| 収録大会 | 全中4年＋ブロック1年＋県対抗2年 | 6年×3大会 | 中学は歴代表が組めない |

ここから来る4つの差:

1. **性別を URL に入れない**。男女別ページにすると432ページ中32%が5件未満、1ページにまとめると280ページで0%
2. **「学校」ではなく「チーム」**。見出し・description に学校前提の語を使わない
3. **大会軸のページを作らない**。全中は既存の大会ハブ（`/tournaments/junior/secondaryschool-championship`）へ寄せる。
   新設すると ADR-010 が避けた重複を自分で作る
4. **順位づけをするページ・節を持たない**。ランキングページも県別ポイントも作らない
   （県別ポイントは一度実装したが 2026-08-12 に廃止。下記「県別ポイントは廃止した」）

## ルーティング

| URL | 内容 | 件数 |
|---|---|---|
| `/secondaryschool/` | 入口。47都道府県への導線＋全中ハブ・進路への案内 | 1 |
| `/secondaryschool/[prefectureId]/` | 都道府県ページ | 47 |
| `/secondaryschool/[prefectureId]/[teamId]/` | チームページ（男女1枚） | 280 |

計328ページ。高校（529ページ）より小さい。

- `prefectureId` は `data/prefectures.json` の `id`（`aichi` 等）
- `teamId` はローマ字スラッグ。生成は pykakasi、読みが誤るものは
  `data/secondaryschool/team-id-overrides.json` に手で書けば優先される（高校の `team_id_map.json` と同じ運用）。
  **県内で一意であればよい**ので衝突は少ない

#### 長音は `ou` / `uu` を残す（高校に合わせる・2026-08-12 決定）

`昇陽` は `shoyo` ではなく **`shouyou`**、`京都光華` は `kyotokoka` ではなく **`kyoutokouka`**。

パスポート式（`Tokyo` `Kyoto` のように長音を省く）のほうが URL としては読みやすいが、
**高校側の自動生成 765件のうち39%が `ou`/`uu` を含む**（`shimonosekikouka` `myoujou` `asahikawakou`）ため、
サイト全体の一貫性を優先して `ou` 側に揃えた。手で override を書くときもこの流儀に従うこと。

**注意: 高校側の手動上書き（`team_id_map.json` 30件）はこの規約に従っていない。**
`soyo`（相洋）`hoyatomo`（早鞆）`okayamasozan`（岡山操山）`shohei`（昌平）は長音省略、
`nishijouyou`（西城陽）`kousei`（甲西）`kagoshimashou`（鹿児島商）は長音あり、と混在している。
中学側で `相洋中学校` を **`soyo`** にしているのはこの例外に合わせたもの（同じ学校名で
高校 `soyo` / 中学 `souyou` と割れるのを避けるため）。**同名の学校が高校側にある場合は
`team_id_map.json` を先に確認すること。**

### teamId の作り方（`stripForSlug` / `applyLoanwords`）

ローマ字化の前に、URL に不要な部分を落として外来語を英語綴りへ寄せる。平均10文字に収まる。

1. **括弧書きを落とす**。ただし括弧書きは本来**データ側で消すべき**もので、
   スラッグ生成での除去は保険。2026-08-12 に全8種を alias で整理済み
   （`(拠)`＝拠点校の注記、`（熊野クラブ）`＝別称の併記）。
   新しい大会データを入れたら `participants[].team` を `/[（(].*?[）)]/` で grep して確認すること
2. **設置者接頭辞を落とす**（`江別市立江別第一中学校` → `ebetsudaiichi`）。
   これが無いと `ebetsushiritsuebetsudaiichichuugakkou` と地名が2回出て読めない
3. **競技名を落とす**（`浜頓別ソフトテニス少年団` → `hamatonbetsushounendan`）。当サイトでは自明なため
4. **学校種別の接尾辞を落とす**（`中学校` / `中学` / `中` / `中等教育学校`）。
   高校側が `to_romaji` で「高等学校」「高校」を落としているのと同じ規約
5. **外来語を英語綴りへ**: `クラブ`→club / `ジュニア`→junior / `ユース`→youth /
   `スポーツ`→sports / `センター`→center / `チーム`→team。
   pykakasi は `クラブ` を `kurabu` と読むが、`MKクラブ`→`mkkurabu` のように英字と読みが混在して落ち着かない

いずれも**落として2文字未満になる場合は落とさない**（`南中学校` → `南` を潰さない）。

**対象を限定している点が2つある**:

- **外来語の変換は一般名詞だけ**。`日野フレンズ`→`hinofurenzu`、`レペゼン千葉`→`repezenchiba` のような
  固有名詞はローマ字のままにする。団体が選んだ名前の英語綴りを推測すると誤る（`ガナドール`は
  ganador かもしれないが断定できない）ため。`少年団`(shounendan) `協会`(kyoukai) も日本語なのでそのまま
- **クラブ名そのものは落とさない**。`野木`（中学校）と `野木クラブ`（地域クラブ）は別団体なので、
  落とすと衝突する

### スラッグ衝突は名寄せの取りこぼしを検出する仕掛けとして使う

**県内でスラッグが衝突したら、それは同一チームが分裂している可能性が高い。**
2026-08-12 に実際、`松山`（埼玉県、`matsuyama-2`）が衝突として現れ、
`松山中学校` と別チームのまま残っていたことが判明した。ここから同型を洗い出すと18件あった。

修正の内訳:

- **7件は中高一貫型**（`松山` `相洋` `和歌山信愛` `奈良育英` `土佐女子` `下田` `三本木`）。
  素の略称が高校も指すため `tournamentPrefix` で中学校の大会に限定した
- **11件は中学の大会にしか出ていない**（`高田` `向陽` `高瀬` `中央` `上宮学園` ほか）。
  **こちらも `tournamentPrefix` で限定する必要があった**。当初 scope 無しで入れたところ、
  *他県の*同名高校（岩手の高田高校、和歌山の向陽高校など）まで中学校名に書き換わった。
  「この県では高校に出ていない」は「全国で高校に出ていない」を意味しない
- **5件は全角半角の揺れ**（`ＵＴＣ`/`UTC` 等）で `normalize-team-spacing.mjs --scope=all` を流して解消
- **1件はアポストロフィの揺れ**（`M’ｓ` U+2019 と `M's` U+0027）。NFKC では畳まれないので alias で寄せた

**残る2件は意図的に統合していない**: `朝日`（愛知、`asahi-2`）と `野木`（栃木、`nogi-2`）。
同じ県に `朝日STC` `野木クラブ` `野木STC` があり、素の名前が学校とクラブのどちらを指すか
名前からは判別できない。実在確認が要る。

### 短縮形が衝突したときは元の名前に戻す

県内で同じスラッグになった場合、`-2` を付けるのではなく**短縮前の名前でローマ字化し直す**。
そのほうが読める URL になるうえ、**衝突自体が名寄せの取りこぼしを示す信号**になる。

実際、2026-08-12 の生成では14件が衝突し、うち5件が
`名寄市立名寄中学校` と `名寄中学校` のような**設置者接頭辞つき／なしの未統合ペア**だった。
既存の `teamCore()` は接尾辞しか落とさないため、これらは名寄せ候補に上がっていない。

**ただし接頭辞を落として機械的にマージしてはいけない。** 同じ条件で拾えるグループ46件の中に
`岩見沢市立光陵中学校` と `伊達市立光陵中学校`、`東松山市立松山中学校` と `松山市立松山中学校` のような
**別の市の別の学校**が含まれる。既存パイプラインが接頭辞を落としていないのは正しい。
本物の取りこぼし（約30件）は人手レビューで潰すこと。

なお掲載チームが0件の県はページを作らない（現状は該当なし）。

## 対象大会と掲載閾値

対象は `scripts/build-secondaryschool-index.mjs` の `TOURNAMENTS`:

- 全国中学校体育大会（全中）`secondaryschool-championship`
- 都道府県対抗全日本中学生大会 `zennihon-secondaryschool-versus`
- 全日本中学生クラブ選手権プレ大会 `zennihon-secondaryschool-club-pre`
- 9ブロック大会 `secondaryschool-{block}-block`

**掲載閾値は出場延べ5件**（`/teams/[teamId]` の noindex 閾値と揃えてある）。
閾値なしだと990チームの7割が薄いページになる。

### ブロック大会は掲載判定にのみ使う（集計には使わない）

- **含める理由**: 全中＋都道府県対抗だけだと閾値5を満たすのが158チームまで落ち、
  京都・宮崎・山梨・沖縄が1チームしか残らず都道府県ページが成立しない。
  含めると280チーム（高校289と同等）で最少の県でも2チーム
- **集計に使わない理由**: ブロック大会の県別出場チーム数は**北海道65に対し福岡4**。
  北海道が単独で1ブロックなのに対し福岡は九州7県で分け合うためで、実力差ではない
- 高校の「地区大会をカテゴリ機能に統合しない」決定（[highschool.md](./highschool.md)）と矛盾しない。
  高校は6年×3大会あるので掲載判定に地区大会が不要なだけで、「集計を歪めるから使わない」原理は共通

「2026年度のブロック1年分で水増しされる」懸念は実測で否定済み。閾値5の280チームのうち
ブロックのみは48件（17%）で、63%は全国大会にも出ている。

## 都道府県ページ

役割は**「県内にどのチームが収録されているか」の一覧**。順位づけはしない。

- 県内チームを 中学校 / 地域クラブ / その他 の3見出しに分けて並べる。
  **分けるのは実態が違うからで、優劣ではない**
- チーム名から各チームの戦績ページへ内部リンクする
- 掲載閾値5未満のチームは表示しない旨を注記する

### 県別ポイントは廃止した（2026-08-12）

当初は都道府県対抗の成績をポイント化して47県を順位づけ、「県対抗は全県が同じ枠数で出場するので
公平に比べられる」ことを中学カテゴリ固有の差別化として押し出していた。**これは取りやめた。**

理由は2つ:

1. **配点が Assumption だった**（優勝10・準優勝7…はユーザー未確定の初期値）。
   根拠の弱い数字を公開順位として出すことになる
2. **実装が説明と食い違っていた**。ポイントは全中・都道府県対抗・クラブ選手権プレの**合算**で、
   「47県が同じ枠数」が成り立つのは都道府県対抗だけだった。実測すると県あたりの出場延べは
   全中で2〜40（**20倍差**）、クラブ選手権プレは**26県しか出ていない**。
   合算では20〜68（3.4倍差）で、公平な比較になっていない
3. 都道府県対抗単体でも完全な同数ではない（19/20/21、**開催県の三重だけ40**）

順位づけをやめると、このカテゴリに残るものが**すべて検算できる事実**になる
（どのチームが収録されているか／そのチームの成績は何か／その中学から誰がどこへ進学したか）。

データ自体は `details/` に残っているので、必要になれば
「順位づけせず都道府県対抗の実績だけ列挙する」形で戻せる。その場合、
ベスト8以上の実績がある県は30/47・1県あたり中央値2件（2026-08-12 実測）。

## チームページ

- 男女を1ページにまとめる（上記の理由）
- 「当サイト収録の最高成績」→「進路」→「大会成績（年度別）」→「出場選手」の順
- 選手名は `resolvePlayerId()` が `data/players/index.json` の `count>=5` で解決できたときだけ
  `/players/{id}/results` へリンクする（デッドリンク防止。高校の `getPlayerResolver()` と同じ規約だが
  カテゴリ間でロジックは共有しない）
- 構造化データは `SportsTeam` と `BreadcrumbList`

### 進路（中学 → 高校）と、高校ページからの逆引き

このカテゴリの差別化の核。**中学と高校の両方を名寄せ済みで持っているサイトにしか作れない。**
生成は `scripts/build-secondaryschool-pathways.mjs`。

採用条件（誤マッチを出さないためのゲート）:

1. 中学の最終出場年 < 高校の初出場年
2. **ペア継続**（中学で組んだペアが高校でも同じ2人）または**県一致**のいずれか
3. 同姓同名の疑いがある氏名を除外（「中学側で同一年に3チーム以上へ出現」＝別人が混在している証拠）

**県をまたぐ単独一致は採用しない**。2026-08-12 実測で追跡候補560件のうち採用323件
（ペア継続96・県一致227）、不採用は県またぎ224件・同姓同名0件。
掲載チームに紐づいたのは184件／83チーム。越境進学を取りこぼすが、
誤った進学先を出すほうが害が大きいため。ページにもこの限界を注記する。

**逆引き（高校ページ→出身中学）も同じデータから作る**（`lib/highschoolFeederSchools.ts`、2026-08-12 追加）。
`/highschool/[gender]/[prefectureId]/[teamId]` に「{高校名}の選手の出身中学」節を出す。
新規URLは作らない。実測で**高校575校のうち81校（14%）**に付き、1校あたり中央値1件・最大12件。
2件以上あるのは40校。

- 高校の学校ページは**男女別**なので、進路レコードに `highschoolGender` を持たせて出し分ける。
  `mixed` は男女どちらのページにも出す（[highschool.md](./highschool.md) の規約に合わせる）
- 中学チームページへのリンクは掲載閾値を満たす中学のみ。満たさない中学は名前だけ出す（デッドリンク防止）
- 上位は系列校の内部進学が占める（`昇陽`←`昇陽中学校` 12件、`明徳義塾`←`明徳義塾中学校` 8件）。
  複数の中学から集まっている高校（`岡崎城西`←3中学、`東北`←3中学）のほうが読み物としては面白い

## 生成と運用

```
npm run secondaryschool:build   # 索引と進路をまとめて生成
```

`prebuild` に組み込み済み。**必ず `scripts/normalize-team-names.mjs --scope=all` の後に流すこと**。
名寄せ前に流すと表記ゆれのぶんチームが分裂する（[ADR-013](../adr/ADR-013-scoped-team-name-aliases.md)）。

生成物:

- `data/secondaryschool/index.json` — 都道府県集計とチーム一覧
- `data/secondaryschool/pathways.json` — 進路
- `data/secondaryschool/team-id-overrides.json` — teamId の手動上書き（読み誤りの修正用）

規模の再測定は `npm run juniorhigh:measure`（`scripts/measure-juniorhigh-scale.mjs`）。

## 未対応・課題

- `teamId` のローマ字読みの精度。pykakasi は `昇陽`→`noboruyou`、`明徳義塾`→`akinorigijuku` のように
  誤ることがある。**2026-08-12 に出場の多い22件を override 済み**だが、残り258件は未確認。
  確認用リストは [raw/2026-08-12-secondaryschool-teamid-review.md](../raw/2026-08-12-secondaryschool-teamid-review.md)
  （`npm run secondaryschool:build` の後に再生成すると最新の ID になる）。
  URL は一度公開すると変えにくいので、残りも公開前に見ておきたい
- 設置者接頭辞つき／なしの未統合ペア（`名寄市立名寄中学校` と `名寄中学校` 等、約30件）。
  スラッグ衝突として検出できているが未処理。誤って別校を統合しないよう人手レビューが要る
- 学校と同地名クラブ（`今市ジュニア`/`今市中学校` 等35グループ）の実在確認
- `函館市拠点校部活動（巴中学校）` の表記。括弧内が実際の学校名で外側が制度名のため、
  他の括弧書きのように機械的に落とせない。地域移行にともなう新しい参加形態で、
  正しい表記は出典（大会要項）の確認が要る。現状は2件で掲載閾値未満のためページは無い
- `npm run build` の完走確認（作業環境で時間内に終わらず未実施）
- GSC での効果測定
