# Secondary School Pages（中学カテゴリ）

> **適用範囲: 学校スポーツ共通**。カテゴリの作り方（掲載閾値・進路・順位づけをしない方針）は
> 他競技でも使える。大会名・チーム名の扱いはソフトテニス固有。
> **2026-09-18 に現在の仕様だけへ圧縮した。** 実測値・経緯・個別事例は
> [raw/2026-09-18-wiki-archive-secondaryschool.md](../raw/2026-09-18-wiki-archive-secondaryschool.md)。

中学カテゴリ（`/secondaryschool`）の公開ページ方針と仕様。
高校カテゴリは [highschool.md](./highschool.md)、URL 一覧は [public-pages.md](./public-pages.md)。

## 高校カテゴリと構成が違う理由

**高校の設計をそのまま横展開していない。** データの形が違うため（2026-08-12 実測）:
ダブルスのペアが同じ所属で組まれるのは全中だけ、掲載チームの4割が学校でなく地域クラブ、
1チームあたりの収録が薄い（男女で割ると3割が閾値未満）、収録年数が足りず歴代表が組めない。

ここから来る4つの差:

1. **性別を URL に入れない**（男女別にすると3割が薄いページになる）
2. **「学校」ではなく「チーム」と呼ぶ**。見出し・description に学校前提の語を使わない
3. **大会軸のページを作らない**。全中は大会ハブ `/tournaments/junior/secondaryschool-championship` に集約（ADR-010）
4. **順位づけをするページ・節を持たない**。ランキングも県別ポイントも作らない

## ルーティング

| URL | 内容 | 件数 |
|---|---|---|
| `/secondaryschool/` | 入口。47都道府県への導線＋全中ハブ・進路への案内 | 1 |
| `/secondaryschool/pathways/[gender]/` | 高校別の出身中学 | 2 |
| `/secondaryschool/[prefectureId]/` | 都道府県ページ | 47 |
| `/secondaryschool/[prefectureId]/[teamId]/` | チームページ（男女1枚） | 293 |

計343ページ。掲載チームが0件の県はページを作らない（現状は該当なし）。

**`/secondaryschool/pathways/[gender]/` だけ男女別 URL**。カテゴリの他は男女をまとめるが、
このページは**高校が主語**で、高校の学校ページが男女別だから内容が原理的に重ならない。
**高校起点**にしているのは、検索需要が高校名に偏るのと、この向きでしか強豪校の越境集約が見えないため。
中学起点の見え方は各チームページが担当する。性別なしの URL は作らない。

## teamId の作り方

`prefectureId` は `data/prefectures.json` の `id`。`teamId` はローマ字スラッグ（pykakasi）で、
**県内で一意であればよい**。読み誤りは `data/secondaryschool/team-id-overrides.json` に書けば優先される。

- **長音は `ou` / `uu` を残す**（`昇陽`→`shouyou`）。高校側の自動生成の39%が `ou`/`uu` を含むため、
  サイト全体の一貫性を優先した。**ただし高校の手動上書き（`team_id_map.json` 30件）はこの規約に従っていない**
  （`soyo` `shohei` などの長音省略と `nishijouyou` などが混在）。**同名の学校が高校側にあるときは
  `team_id_map.json` を先に確認すること**（中学の `相洋中学校` を `soyo` にしているのはこの例外に合わせたもの）。
- ローマ字化の前に落とすもの（`stripForSlug`）: 括弧書き / 設置者接頭辞（`江別市立`）/ 競技名 /
  学校種別の接尾辞（`中学校` `中` `中等教育学校`）。**落として2文字未満になるなら落とさない**。
- 外来語は英語綴りへ（`クラブ`→club、`ジュニア`→junior 等）。**一般名詞だけ**で、`日野フレンズ` のような
  固有名詞はローマ字のまま（団体が選んだ綴りを推測すると誤るため）。**クラブ名そのものは落とさない**
  （`野木` と `野木クラブ` は別団体）。
- 括弧書きは本来**データ側で消すべき**もので、スラッグ生成での除去は保険。新しい大会データを入れたら
  `participants[].team` を `/[（(].*?[）)]/` で grep して確認する。

### スラッグの衝突は名寄せの取りこぼしの信号として使う

県内で衝突したら `-2` を付けず、**短縮前の名前でローマ字化し直す**。そのほうが読める URL になり、
衝突自体が「同一チームが分裂している」信号として使える（実例あり）。

**接頭辞を落として機械的にマージしてはいけない。** `岩見沢市立光陵中学校` と `伊達市立光陵中学校` のような
**別の市の別の学校**が同じ条件で拾えてしまう。既存パイプラインが接頭辞を落とさないのは正しく、
本物の取りこぼしは人手レビューで潰す。中高一貫校など、同じ略称が高校も指す場合は
`tournamentPrefix` × `prefecture` のスコープ付き alias で分ける（[ADR-013](../adr/ADR-013-scoped-team-name-aliases.md)）。
**「この県では高校に出ていない」は「全国で高校に出ていない」を意味しない**ので、スコープ無しの alias を入れない。

## 対象大会と掲載閾値

対象は `scripts/build-secondaryschool-index.mjs` の `TOURNAMENTS`: 全中 `secondaryschool-championship` /
都道府県対抗 `zennihon-secondaryschool-versus` / 全日本中学生クラブ選手権プレ `zennihon-secondaryschool-club-pre` /
9ブロック大会 `secondaryschool-{block}-block`。

**掲載閾値は出場延べ5件**（`/teams/[teamId]` の noindex 閾値と揃えてある）。閾値なしだと7割が薄いページになる。

**ブロック大会は掲載判定にのみ使い、集計には使わない。** 含めないと閾値を満たす県が足りず都道府県ページが
成立しない。集計に使わないのは、ブロックの出場枠が地域で大きく違い（北海道は単独、福岡は九州7県で分け合う）
実力差ではないため。高校の「地区大会をカテゴリ機能に統合しない」決定と原理は同じ。

## 都道府県ページ

役割は**「県内にどのチームが収録されているか」の一覧**。順位づけはしない。

- 県内チームを**出場回数の多い順**に1つのリストで並べ、各チームの戦績ページへリンクする
- 掲載閾値未満のチームは表示しない旨を注記する
- チーム一覧の前に「全国大会での成績（ベスト8以上）」節を置く
- **中学校 / 地域クラブ で見出しを分けない**。分類（`lib/clubTransition.ts`）は下限カウントで
  16%が判定不能になるため、見出しの構造には使えない。分かるときだけチーム名の横に小さなラベルを添える。
  この分類は全中ハブの**地域移行トラッカー**のためのもので、そちらでは下限に意味がある

### 都道府県の全国大会での成績

全中と都道府県対抗で、その県のチーム・選手がベスト8以上に入った記録を**大会ごとに**列挙する。
小学生版と見た目は共通（[primaryschool.md](./primaryschool.md)）。

- **県同士を比べない**（47県の比較表は作らない）。**ベスト8以上だけ**。
  該当が無ければ「収録範囲では、ベスト8以上の記録はありません」と書く
- **全中と県対抗は混ぜない**（収録年数も出場枠の決まり方も違う）
- **ブロック大会とクラブ選手権プレは不採用**（ブロック優勝が県の最高成績「優勝」に見える／
  1回・26県だけで県の成績として読めない）
- **所属が混成のペアも数える**（県が1つに定まるとき）。チームの成績とは数え方が違う
- 並び・データの置き場所は小学生版と同じ（成績上位順→年度降順、11件目以降は `<details>`、
  `index.json` の `achievementTournaments` / `achievementsByPrefecture`。`prefectures[]` には入れない）

**県別ポイント（47県の順位づけ）は 2026-08-12 に廃止した。** 配点が Assumption だったことと、
合算していた3大会で県あたりの出場延べが20倍違い公平な比較にならなかったため。
2026-09-13 に「順位づけせず大会ごとに列挙する」形で戻したのが上記の節で、**ポイントの復活ではない**。

## チームページ

- 男女を1ページにまとめる
- 「当サイト収録の最高成績」→「進路」→「出身クラブ」→「大会成績（年度別）」→「出場選手」の順
- 選手名は `resolvePlayerId()` が `data/players/index.json` の `count>=5` で解決できたときだけ
  `/players/{id}/results` へリンクする（デッドリンク防止。カテゴリ間でロジックは共有しない）
- 構造化データは `SportsTeam` と `BreadcrumbList`

### 進路（中学 → 高校）と高校ページからの逆引き

このカテゴリの差別化の核。**中学と高校の両方を名寄せ済みで持っているサイトにしか作れない。**
生成は `scripts/build-secondaryschool-pathways.mjs`。

採用条件（[ADR-014](../adr/ADR-014-pathway-name-match.md)）:

1. **中学の最終出場年 < 高校の初出場年 <= 中学の最終出場年 + 5**（`MAX_YEAR_GAP`）
2. **同姓同名として検出された氏名を除外**（同一大会・同一年・同一種目に別チームで2人以上＝別人が確定）

**県の一致もペアの継続も要求しない**（緩和済み）。確度は `basis`（`pair` > `pref` > `name`）に残す。
**UI には出さない**が、誤りを追うときと `name` だけ除外するときに使う。

> **この緩和は「氏名が実質的に一意」という前提に乗っている。** 同姓同名の検出数が増えたり
> 誤りの指摘が来たら条件を戻す。戻し方と監視項目は ADR-014 の Consequences。

**逆引き（高校ページ→出身中学）も同じデータから作る**（`lib/highschoolFeederSchools.ts`）。
高校の学校ページの「進路」節の h3「出身中学」に出す（隣は「進学先大学」。[university.md](./university.md)）。新規 URL は作らない。

- 高校の学校ページは男女別なので、進路レコードの `highschoolGender` で出し分ける。`mixed` は両方に出す
- 中学チームページへのリンクは掲載閾値を満たす中学のみ。満たさなければ名前だけ出す

### 出身クラブ（小学 → 中学の逆引き）

小学生カテゴリの進路データ（`data/primaryschool/pathways.json`）を中学名で引き直したもの。
生成は `scripts/build-primaryschool-pathways.mjs`、表示は `lib/secondaryschoolFeederClubs.ts`。
**新規 URL は作らず**既存のチームページに節を足す。これで**小 → 中 → 高の3段接続**が成立している。

- 採用条件は ADR-014 と同じ「氏名一致＋年差」で、年差だけ **6年**。
  **小→中は中学→高校より確度が高い**（ペア継続か県一致が9割超。小学生は地元の中学へ進むため）
- 高校版と違い**性別で分けない**（チームページが男女1枚のため）
- **掲載閾値で絞らない**（絞ると節から選手が消える）。クラブ名へのリンクは小学生カテゴリの
  団体ページが実在するときだけ張る
- 中学と県が違う出身クラブには県名を添える（越境が見えるようにするため）

## 生成と運用

```
npm run secondaryschool:build   # 索引と進路をまとめて生成
```

`prebuild` に組み込み済み。**必ず `scripts/normalize-team-names.mjs --scope=all` の後に流すこと**。
名寄せ前に流すと表記ゆれのぶんチームが分裂する（[ADR-013](../adr/ADR-013-scoped-team-name-aliases.md)）。

生成物: `data/secondaryschool/index.json`（都道府県集計とチーム一覧）/ `pathways.json`（進路）/
`team-id-overrides.json`（teamId の手動上書き）。規模の再測定は `npm run juniorhigh:measure`。
