# ADR-014: 進路（中学→高校）の採用条件を「氏名一致＋年差5年以内」に緩和する

## Status

Accepted。決定日: 2026-08-12。現状仕様: `docs/wiki/secondaryschool.md`「進路（中学 → 高校）」。

**これは同日に一度決めた「県をまたぐ単独一致は採用しない」を明示的に覆す。**
実装は `scripts/build-secondaryschool-pathways.mjs`。

## Context

進路データは氏名の一致だけで中学と高校をつなぐ。誤った進学先を出すと信頼を損なうため、
当初は**「県一致 または ペア継続」を必須**にしていた。

この条件だと追跡候補560件のうち採用323件で、**246件を落としていた**。
落としていたのは「県をまたぐ単独一致」＝越境進学と同姓同名の誤マッチが混ざった層。

問題は、この層を丸ごと捨てると**越境進学が構造的に見えなくなる**こと。
強豪校が県外から選手を集めるのはこの競技の実態であり、
「高校別の出身中学」ページ（2026-08-12 新設）の中心的な価値がそこにある。

### 緩和の可否を実データで検証した

**検証1: ペア継続を正解データにする。**
中学で組んだペアが高校でも同じ2人で出ている96名は、同一人物であることが確定している
（ペア単位の一致は誤マッチ率が実質ゼロ。`news-context-blocks.md`、IH2026で名前セットの重複0件）。
この96名に「氏名一致＋年差以内」だけを当てて、正解と同じ高校を選ぶか試した。

**結果: 96/96 で正解（100%）。**

**検証2: 同姓同名の基礎率。**
「同一大会・同一年・同一種目ファイルの中に、同じ氏名が別チームで2人以上いる」＝
ドローの中で同時に存在しているので別人が確定する。この条件で収録全大会を走査すると、
**該当する氏名は29件しかなかった**。緩和で追加される候補244件のうち該当は**1件**。

**検証3: 旧条件が落としていたものの中身。**
ペア継続で確定した96名のうち **22.9%（22名）が県またぎ**。
つまり旧条件は、確度が最も高い層ですら2割強を「県が違う」という理由だけで
落としかねない設計だった（実際にはペア継続で救われていた）。

### 検証の限界（これは Assumption として残る）

- **検証1の標本は偏っている**。ペア継続する名前は「2人とも一致した」名前なので、
  もともと珍しい氏名に寄っている。曖昧な氏名に対する精度は測れていない
- **検証2の29件は下限**。同じ大会に居合わせなかった同姓同名は検出できない
- 緩和後、氏名一致のみで採用された162件のうち**112件は完全に単独**
  （同じ中学→高校に他の裏付けが無い）。ここに誤りが混ざっていても気づけない

## Decision

**採用条件を次の2つだけにする。**

1. **中学の最終出場年 < 高校の初出場年 <= 中学の最終出場年 + 5**（`MAX_YEAR_GAP = 5`）
   最長は「中学1年で最後に出場 → 高校3年で初出場」で、中2・中3・高1・高2・高3 と数えて5年。
   これを超える一致は進学のタイミングとして成立しない
2. **同姓同名として検出された氏名を除外する**

**県の一致もペアの継続も要求しない。**

### 同姓同名の判定を「疑い」から「証拠」に変える

旧判定は「中学側で同一年に3チーム以上へ出現する氏名」で、実測 **0件/2,956人**。
何も捕まえておらず、県一致ゲートを外した後の安全弁として機能しない。

新判定 `buildHomonymSet()` は**同一大会・同一年・同一種目ファイル内に同じ氏名が別チームで2人以上**。
同じデータで**29件**を検出する。収録全大会を走査する（中学・高校に限らない。
世代をまたいで同じ氏名が使われていれば進路の追跡でも誤マッチの原因になるため）。

### `basis` に確度を残す

`pair`（ペア継続）> `pref`（県一致）> `name`（氏名一致のみ）。
**UIには出さない**（2026-08-12 ユーザー判断）が、後から誤りを追うために必要。

## Alternatives

- **年差3年にする**: 当初の案。「中3で最後に出場 → 高3で出場」しか想定していなかった。
  中1・中2で最後に出場するケースを落としてしまうため不採用（5年に修正）
- **確度ラベルをUIに出す**: 読者が判断できるようにする案。
  表示が煩雑になるのと、そもそも「単独の氏名一致」が半数近くを占めるので
  ラベルが実質「推定」ばかりになる。不採用（ページ冒頭の注記で限界を書く方針にした）
- **県またぎは採用するが件数だけ示して個票は出さない**: 最も保守的。
  それだと越境進学が見える化されず、緩和する意味がない。不採用
- **旧条件を維持する**: 越境進学を丸ごと落とす。
  「高校別の出身中学」ページの中心的な価値を捨てることになる。不採用

## Consequences

| | 緩和前 | 緩和後 |
|---|---|---|
| 進路レコード | 184件 | **346件** |
| 中学チーム | 83 | **112** |
| 高校グループ（高校×性別） | 88 | **111** |
| 複数の中学から集めている高校 | 16校 | **41校** |
| 県をまたぐ進学 | 16名（9%） | **178名（51%）** |

- 利点: 越境進学が見えるようになった。`朝日丘中学校（愛知）→ 広島翔洋（広島）5名` のように
  **ペア継続で確定した1名を含む越境グループ**が現れ、残り4名の氏名一致を裏付けている
- **リスク: 県またぎが9%→51%に跳ねた**。検証1の越境率（22.9%）を大きく超えており、
  **氏名一致のみの162件に誤マッチが含まれている可能性が高い**。
  内訳は「確定者が同じ組にいる」5件 /「他の氏名一致者と相互裏付け」45件 / **完全に単独 112件**
- 影響: 各ページの注記を「県一致かペア継続のみ掲載」から
  「同姓同名の別人が含まれている可能性がある」に書き換えた（3ページ＋lib）
- **監視**: 次のどれかが起きたら条件を戻すか、`basis` で表示を絞ること
  - `buildHomonymSet()` の検出数が増える（氏名が一意という前提が崩れた合図）
  - 誤った進学先の指摘が来る
  - 古い年度を遡及投入して年差が広がり、`MAX_YEAR_GAP` の除外が増える
- 戻し方: `build-secondaryschool-pathways.mjs` の採用判定に `prefMatch || viaPair` を
  戻すだけ。`basis` を持っているので、生成物を捨てずに `name` だけ除外する形でも絞れる
